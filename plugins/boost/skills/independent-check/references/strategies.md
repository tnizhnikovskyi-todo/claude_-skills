# Карточки стратегий критика

Выбирай 2 (в `--deep` 3–4) **разные по природе** карточки, подходящие к
артефакту. Вставляй текст карточки в промпт критика целиком.

| ID | Карточка | Когда брать |
|---|---|---|
| S1 | **Краевые входы.** Перебери пустые, единичные, повторяющиеся, граничные (0, 1, максимум, отрицательные), неупорядоченные, None/False входы. Для каждого мысленно выполни код построчно и сравни с CONTRACT | Почти всегда |
| S2 | **Контракт построчно.** Разбей CONTRACT на отдельные требования. Для каждого найди место, где оно выполняется. Требование без места — кандидат | ТР, спеки, бизнес-логика |
| S3 | **Противник / доступ.** Ты пользователь без прав или с чужими данными. Найди путь, где проверка прав/владельца не выполняется: соседний метод, другой вход, `sudo()`, обход через параметр | Контроллеры, API, права |
| S4 | **Состояние и последовательность.** Ищи ошибки, которые проявляются только при повторе, порядке вызовов, накоплении (одна сущность дважды в списке, повторный вызов, частичный сбой посередине, гонка) | Циклы, транзакции, склад, деньги |
| S5 | **Числа и представление.** Округление, float vs decimal, переполнение, единицы измерения, часовые пояса, кодировки, сравнение строк/дат | Деньги, даты, количества |
| S6 | **Обратный ход.** Начни с результата: какие выходы невозможны по CONTRACT? Может ли код их выдать? Построй вход, который к ним ведёт | Алгоритмы, преобразования |
| S7 | **Скептик архитектуры.** Решение верно, но не та задача? Нарушены ли неявные требования (производительность на реальных объёмах, необратимость, совместимость)? | Планы, архитектура, миграции |

Идея карточек — из `arena-skill` (MIT), набор и формулировки свои.
