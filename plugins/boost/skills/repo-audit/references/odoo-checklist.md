# Чек-лист аудита модуля Odoo 19

Читать при аудите модуля Odoo (`__manifest__.py` в корне папки). Это
подсказки, где искать; находка всё равно требует конкретного случая.

## Карта

- `__manifest__.py`: `depends` (лишние модули? модуль используется в коде?),
  `data` (все ли XML/CSV перечислены, порядок: security раньше видов),
  `demo`, `assets`, `license`, `version` формата `19.0.x.y.z`.
- `security/ir.model.access.csv`: строка на каждую модель `_name` (иначе
  модель недоступна или открыта шире нужного); группы не пустые без причины.
- `ir.rule`: мультикомпания (`company_id in company_ids`), записи
  пользователя.
- `controllers/`: `auth='public'`/`'none'`, `csrf=False`, `sudo()`,
  чтение параметров запроса без проверки, возврат лишних полей.
- `models/`: `create`/`write`/`unlink`-переопределения, `sudo()`,
  `self.env.cr.execute` (SQL-инъекции через f-строки/`%`), `search` в цикле,
  `compute` без `@api.depends` или с неполными зависимостями.
- `data/`: `ir.cron` (что делает, на скольких записях, есть ли лимит),
  сервер-экшены, `noupdate`.
- `views/`: поля/кнопки, ссылающиеся на несуществующие методы; `tree`
  вместо `list` (18+); `attrs` (удалён в 17+).
- `tests/`: есть ли тест на деньги, права, импорт, cron.

## Типичные долги Odoo

| Признак | Что предложить |
|---|---|
| Поле-копия + `onchange`/`write` для синхронизации с партнёром | `related=` |
| Пересчёт итогов в `write`/`create` | `compute` + `@api.depends`, `store=True` при поиске |
| Проверка в `write` с `raise UserError` | `models.Constraint` (`CHECK`/`UNIQUE`) или `@api.constrains` |
| `_sql_constraints` в коде под 19 | атрибут `models.Constraint` |
| `search([...])` / `search_count` внутри цикла по записям | один `_read_group` / `read_group` или `mapped` |
| `sudo()` в публичном контроллере без фильтра по владельцу/токену | убрать `sudo()` или ограничить домен и поля |
| Две модели с одинаковым хелпером (форматирование, расчёт) | один миксин или функция в `tools`, путь назвать |
| Абстрактный «сервис»/«стратегия» с одной реализацией | влить в модель |
| Метод, на который нет ссылок ни в Python, ни в XML, ни в cron | удалить (после grep по `name="..."` и `code`) |
| Поле без использования в видах, коде, отчётах | удалить (с миграцией, если `store=True` и есть данные) |
| Зависимость в `depends`, которая не используется | убрать из `depends` |
| Секрет/токен в коде или `data/*.xml` | `ir.config_parameter` / переменная окружения |
| `except Exception: pass` вокруг записи данных | убрать или логировать и перевыбросить |
