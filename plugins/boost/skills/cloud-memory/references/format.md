# Формат memory/

## Запись

Файл `memory/YYYY-MM-DD-<slug>.md`. `slug` латиницей через дефис, 2–5 слов.
Если в тот же день уже есть такой slug, добавь `-2`.

```markdown
---
type: bugfix
date: 2026-11-02
tags: [odoo, sale, import]
status: active
summary: Дубли партнёров при импорте: сравнение VAT без нормализации пробелов
supersedes: 2026-10-20-partner-dedup.md   # необязательно
---
**Симптом:** при импорте CSV создаются дубли `res.partner`.
**Причина:** `_find_partner` сравнивает `vat` как есть; в CSV есть пробелы.
**Фикс:** нормализация в `td_import/models/partner.py::_norm_vat`, коммит `a1b2c3d`.
**Как проверить:** тест `test_import_vat_spaces`.
```

### Поля frontmatter

| Поле | Обязательно | Значения |
|---|---|---|
| `type` | да | `decision` решение и его причина; `bugfix` корневая причина бага и фикс; `discovery` неочевидный факт о коде/окружении/API; `convention` договорённость/правило проекта |
| `date` | да | `YYYY-MM-DD`, дата записи (или обнаружения) |
| `tags` | да | 1–5 коротких тегов: модуль, подсистема, тема |
| `status` | да | `active` действует; `open` гипотеза или нерешённый вопрос; `superseded` заменено другой записью (укажи какой); `obsolete` больше не актуально (код удалён и т.п.) |
| `summary` | да | одна фраза до ~120 символов, она же строка индекса |
| `supersedes` / `superseded_by` | нет | имя файла другой записи |

Статусы взяты по мотивам task-observer (`open/actioned/declined/superseded/parked`)
и упрощены под память проекта.

### Тело

Короткие поля жирным: для `decision` **Что / Почему / Альтернативы / Где**;
для `bugfix` **Симптом / Причина / Фикс / Как проверить**; для `discovery`
**Факт / Где / Как узнали**; для `convention` **Правило / Откуда**.
До ~15 строк. Код не копировать, ссылаться на файл, функцию, коммит.

## INDEX.md

```markdown
# Память проекта

- 2026-11-02 bugfix [odoo,import] Дубли партнёров при импорте: VAT без нормализации → 2026-11-02-partner-vat-spaces.md
- 2026-10-28 decision [deploy] Деплой только по вторникам 14:00, после бэкапа → 2026-10-28-deploy-window.md
- ~~2026-10-20 decision [import] Дедуп по имени~~ → заменено 2026-11-02-partner-vat-spaces.md
```

- Новые строки сверху: хук берёт начало файла (≈6 КБ, примерно 40–60 строк),
  старое при переполнении обрезается первым.
- Одна строка на запись, до ~150 символов.
- Когда индекс перерастает ~60 строк, предложи пользователю перенести
  `obsolete`/`superseded` строки в `memory/INDEX-archive.md` (не подмешивается).

## HANDOFF.md

Перезаписывается целиком, до ~40 строк, шаблон в `SKILL.md`. Только
текущее состояние незаконченной работы. Хук берёт ≈3 КБ.

## Лимиты хука

Переменные окружения (для `settings.json` → `env`):
`CLOUD_MEMORY_INDEX_MAX` (байт, по умолчанию 6000),
`CLOUD_MEMORY_HANDOFF_MAX` (байт, по умолчанию 3000). Строки не режутся
посередине; однострочные `<private>…</private>` маскируются на всякий случай.
