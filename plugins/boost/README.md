# boost

Наш плагин: компактные скиллы, адаптированные по итогам разбора внешних
репозиториев (см. `../../roadmap.md`, `../../synthesis.md`).

## Установка

```text
/plugin install boost --marketplace tnizhnikovskyi-todo/claude_-skills
```

## Как попадает к сотрудникам

Публикуется в маркетплейсе организации `todoltd/claude-methodology-marketplace`
как внешний плагин (`external-plugins.txt`). Правки делаются здесь, затем
переносятся туда PR-ом без папки `evals/`, с поднятой `version`.

## Состав

Обновляет главная сессия после слияния веток `build/*`.

| Скилл | Что делает | A/B (с / без) | Задача roadmap |
|---|---|---|---|
| `interview-me` | Уточнение задачи по одному вопросу с догадкой, пересказ с «Out of scope», работа только после явного «да» | +1.00 на 3 кейсах; на ясной задаче не срабатывает | 1.2 |
| `source-check` | Версия → официальный источник → цитата с URL, иначе `UNVERIFIED` (Odoo 19 и библиотеки) | +0.33 на 2 кейсах; ссылки и цитаты есть во всех прогонах со скиллом и ни в одном без | 1.3 |
| `cloud-memory` | Память проекта в git (`memory/`): индекс и handoff подмешиваются на старте, запись решений/багов/находок без секретов | 5/5 кейсов против 1/5; перенос между сессиями проверен вручную | 2.1 |
| `lean-change` | Минимальное полное изменение: лестница «нужно ли → есть в репо → стандарт платформы/Odoo 19 → минимум», без срезания валидации, строка «не проверено / риск» | +0.27 в среднем; в 4–5 раз меньше кода на задачах с соблазном переусложнить | 2.3 |
| `repo-audit` | Аудит репозитория/модуля: находки из 4 частей, группы важности, вердикт. Только чтение | +0.23 в среднем; находит не больше базовой модели, но даёт формат и ранжирование | 2.4 |
| `odoo-model-map` | Карта аддонов Odoo по строкам и XML: `_inherit`/`_inherits`, comodel, `related`/`depends`, вью и `inherit_id`, права и `ir.rule`, блок «где не искал»; stdlib-скрипт `odoo_map.py` (код не импортирует) | +0.11 в среднем (+0.27 и +0.17 на 2 из 3 кейсов); на негативе не срабатывает; в 1.5–2 раза дороже ответа | 2.5 |
| `automation-audit` | Аудит настройки Claude Code для репозитория: профиль (в т.ч. Odoo 19), раздел «Уже есть» без дублей, облако (setup-скрипт, `SessionStart`, `enabledPlugins`), по 1–2 рекомендации с «Подтверждено» и «Цена». Только чтение | +0.36 в среднем (+0.75 на копии `pilot/`, +0.25 на Python-сервисе); на негативе не срабатывает | 4.3 |
| `skill-feedback` | Записывает поправку к скиллу в `observations/` (ожидали / получили / предложение, статусы, `repeat_of` → барьер, `siblings_checked`); сами скиллы не правит; процедура еженедельного ревью | +0.45 в среднем; без скилла Claude сразу правит скилл и в 2 из 3 случаев пишет пароль в файл | 5.1 |

Отказ: `independent-check` (2.2). На 8 кейсах, включая самопроверку
своего решения через историю, прирост 0: по явной просьбе «проверь своё
решение независимо» модель и без скилла пересматривает вывод и находит те
же ошибки. Скилл в 4–5 раз дороже. Код в ветке `build/independent-check`
как архив, отчёт в `reports/independent-check.md`.

## Хуки

Только у `cloud-memory`, оба молчат, если в проекте нет `memory/`:

- `SessionStart`: подмешивает `memory/INDEX.md` (до 6000 байт) и
  `memory/HANDOFF.md` (до 3000 байт); ~10 мс, без сети.
- `Stop`: показывает пользователю напоминание, если `memory/` не
  закоммичена. Сам ничего не коммитит.

## Правила для скиллов этого плагина

- **Узкий триггер.** `description` срабатывает только на явную просьбу или
  ясно описанную ситуацию. Никаких «используй в любой сессии».
- **Компактность.** `SKILL.md` до ~150 строк; подробности в `references/`,
  которые грузятся по необходимости.
- **Без сети и чужих установщиков.** Никаких `curl | bash`, `npx pkg@latest`,
  телеметрии.
- **Хуки только в `hooks/`** и только если без них никак; хук обязан быть
  быстрым и молча ничего не делать, если в проекте нет его данных.
- **Облако.** Должно работать в эфемерной облачной сессии.
- **Язык.** Тексты скиллов по-русски (код, имена и команды как есть).
- **Проверка.** У каждого скилла есть eval-кейсы в `evals/<скилл>/`
  (см. `evals/README.md`); без положительной разницы с базовым прогоном
  скилл не включаем.
