Я реализовал слияние интервалов. Сделай независимую проверку решения: есть ли ошибки относительно требований?

**Требования**
- `intervals`: список кортежей `(start, end)` целых чисел, гарантированно `start <= end`; интервалы замкнутые `[start, end]`; список может быть пустым и неупорядоченным.
- Вернуть отсортированный по `start` список непересекающихся интервалов (кортежей), покрывающих те же точки.
- Касающиеся интервалы сливаются: `[(1, 2), (2, 3)] -> [(1, 3)]`. Интервалы `(1, 2)` и `(3, 4)` не сливаются (целые точки не важны, только пересечение/касание).
- Входной список не изменяется.

**Решение**
```python
def merge_intervals(intervals):
    result = []
    for start, end in sorted(intervals):
        if result and start <= result[-1][1]:
            if end > result[-1][1]:
                result[-1] = (result[-1][0], end)
        else:
            result.append((start, end))
    return result
```

**Мои заметки:** `sorted` возвращает копию, вложенные интервалы не уменьшают конец, пустой вход даёт `[]`. Мне кажется, всё верно, но хочу независимый взгляд.
