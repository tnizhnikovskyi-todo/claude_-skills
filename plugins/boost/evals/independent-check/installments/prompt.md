Я написал разбивку суммы на платежи для графика рассрочки. Проверь решение независимо (independent check), есть ли ошибки относительно требований.

**Требования**
- `total`: сумма в гривнах, `float` с не более чем двумя знаками после запятой (например `100.10`, `0.29`, `1.15`), `total >= 0`.
- `n`: число платежей, целое `>= 1`, иначе `ValueError`.
- Вернуть список из `n` сумм (до копейки). Сумма платежей **точно** равна `total`.
- Платежи отличаются не больше чем на 0.01, более ранние не меньше поздних.

**Решение**
```python
def split_installments(total, n):
    if n <= 0:
        raise ValueError("n must be positive")
    cents = int(total * 100)
    base, rest = divmod(cents, n)
    return [(base + (1 if i < rest else 0)) / 100 for i in range(n)]
```

**Мои заметки:** работаю в копейках, так что ошибок округления нет; остаток раскидан на первые платежи, разница не больше копейки. Проверил на 100.00 / 3 → [33.34, 33.33, 33.33]. Всё сходится.
