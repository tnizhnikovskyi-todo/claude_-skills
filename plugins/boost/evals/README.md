# Проверка скиллов (A/B)

Используем встроенную команду Claude Code `claude plugin eval`. Она
прогоняет кейсы с плагином и без него (baseline) и показывает разницу.

```bash
claude plugin eval plugins/boost --case '<скилл>/*' --runs 3 --no-publish
```

Формат кейсов (`case.yaml` или `prompt.md` + `graders/*.md`) смотри в
`claude plugin eval --help` и документации Claude Code (агент
`claude-code-guide`).

## Структура

| Папка | Чья | Что |
|---|---|---|
| `general/` | задача 0.2 | Общий набор реальных задач (код Odoo 19, ТР, дискавери, ревью, исследование, баг). Показывает влияние плагина целиком |
| `<скилл>/` | чат, который делает скилл | Кейсы конкретного скилла: где он должен сработать, где НЕ должен, и что улучшает |
| `results/` | не коммитим | Результаты прогонов (`.gitignore`) |

## Практика `claude plugin eval` (выяснено на первой волне)

- **Имя кейса.** `--case` сравнивается с полем `name`, а не с путём.
  Пиши `name: <скилл>/<кейс>` во frontmatter `prompt.md` / в `case.yaml`.
  Классы символов (`[ab]*`) в фильтре не работают.
- **Инструменты.** Write, Edit, Bash, WebFetch закрыты, пока не дан
  `--allow-tools`. Иначе кейс «не создал файл» проходит из-за окружения.
  Для Bash нужна песочница (`bubblewrap`, `socat`); в облачном образе их
  нет.
- **Фикстуры.** `scaffold_script` лежит внутри папки кейса и запускается
  только с `--scaffold`. `context.add_dirs` агенту не виден.
- **Грейдеры.** В regex нет `(?i)`, нужен `flags: i`; есть
  `match: not_contains`. У `tool_used` с `max: 0` обязательно `min: 0`.
  `match: count:N` не документирован, не используй. У `llm` есть
  `focus: last_message | trace | files | {source: file, path}`; на большом
  trace судья видит только начало, лучше целиться в файл.
- **Судья.** По умолчанию haiku. На длинных русских отчётах с таблицами
  он даёт ложные FAIL: используй `--judge-model sonnet`.
- **Негативный контроль.** Проверяй кейс копией с
  `append_system_prompt` с заведомо плохим поведением: главные грейдеры
  должны упасть.
- **Полезные флаги:** `-j 4`, `--trust-plugin`, `--keep-temp`,
  `--json <файл>`.
- **Многоходовые сценарии** проверяются только через
  `context.history_file` (это `--resume <файл>`). Хватает минимального
  `.jsonl` с репликами user/assistant (`uuid`/`parentUuid`/`sessionId`);
  настоящий транскрипт не коммитить (служебные данные окружения). Кейс с
  историей CLI гоняет в одном плече: базу снимать копией плагина без
  `skills/`. `plugins: []` в кейсе плагин НЕ отключает.
- **Потолок стоимости.** Лимит `--max-cost-usd` считай на ОБА плеча: если
  плечо «с плагином» его съест, базовое плечо молча не запустится (нет
  ключа `without`, при этом `partial: false`), а прогоны, где платные
  грейдеры пропущены по лимиту, получают 0. Такие прогоны не считаются,
  их перезапускают.
- **Цена.** Судья sonnet: 4 кейса × 3 прогона × 2 плеча ≈ $5.5. Прогоны с
  историей и субагентами в 3–4 раза дороже обычных.
- **Общая фикстура** для нескольких кейсов: `_fixture/` рядом с кейсами, в
  `setup.sh`: `cp -r "$(dirname "$0")/../_fixture/addons" .`.
- **YAML.** `description` с «: » бери в кавычки.
- **Копии истории.** Рядом с `history_file` eval создаёт `<sessionId>.jsonl`
  и папку `<sessionId>/`: добавляй их в `.gitignore` кейса.
- **База для кейсов с историей:** копия плагина без проверяемого скилла и
  его агентов, `--ablation none`, тот же судья.
- **Общий набор `general/`.** Регрессионный уровень (14 кейсов) база
  проходит почти на 1.0. Уровень `hard` (`odoo19-api-traps`,
  `odoo19-sales-traps`) база проходит на 0.755: модель стабильно ошибается
  только на фактах Odoo 19, которых не знает (`partner_id.mobile`,
  `partner_id.title` удалены в 19.0). На нём мерить `source-check` и
  Context7.

## Правила

- **Минимум 3 кейса на скилл:** 2 где он должен помочь, 1 где не должен
  срабатывать (проверка триггера).
- **Грейдеры проверяют результат, а не слова.** Например: «вопрос задан до
  начала правок», «указан источник с URL», «найдена заложенная ошибка».
- **Без клиентских данных** в кейсах.
- **Отчёт.** Итог прогона (таблица с/без, стоимость, вывод) пишется в
  `reports/<slug>.md` в корне репозитория.
- **Бюджет.** По умолчанию `--runs 3`, `--max-cost-usd 5` на скилл; больше
  только с согласия пользователя.
