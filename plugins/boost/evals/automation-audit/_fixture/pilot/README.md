# Workshop

Модули Odoo 19 для сервисной мастерской.

| Модуль | Что делает |
|---|---|
| `td_workshop` | Заказ на ремонт: клиент, устройство, техник, запчасти и работы, скидка, статусы, мастер закрытия, напоминание о просрочке |
| `td_workshop_sale` | Коммерческое предложение из заказа на ремонт |
| `td_workshop_portal` | Публичная страница `/repair/<id>` со статусом ремонта |
