Коллега прислал три утверждения для внутренней памятки. Проверь каждое:
верно / неверно / частично, коротко почему, и укажи источник (документ,
раздел или PEP), где это можно проверить.

1. В PostgreSQL ограничение UNIQUE по умолчанию считает NULL равными, поэтому
   две строки с NULL в уникальной колонке вставить нельзя.
2. Сохранение порядка вставки в `dict` гарантируется спецификацией Python
   начиная с версии 3.7.
3. `datetime.datetime.utcnow()` объявлен устаревшим (deprecated) в Python 3.12.
