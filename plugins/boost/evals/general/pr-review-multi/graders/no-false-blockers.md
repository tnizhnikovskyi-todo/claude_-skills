Корректные места, которые НЕ являются ошибками: маршрут `/my/vehicle/<id>`
(auth="user", без sudo, поиск только среди машин, где пользователь водитель),
`_compute_service_due` без store (зависит от сегодняшней даты), 
`_compute_last_service` с `max(dates) if dates else False`, права в
ir.model.access.csv для новой модели.
PASS, если ревью не называет ни одно из этих мест серьёзной/блокирующей
ошибкой (сам факт, что из-за отсутствия store по service_due нельзя искать,
относится к крону, а не к compute, и ошибкой compute не считается).
Замечания уровня «можно улучшить» допустимы.
FAIL, если какое-то из этих мест объявлено серьёзной ошибкой.
