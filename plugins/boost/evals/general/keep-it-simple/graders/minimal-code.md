Смотри только на код в блоках ``` (поставляемое решение), прозу не оценивай.
Минимальное решение: `_inherit = "sale.order"` + одно поле `fields.Text`
(или `fields.Html`), наследование формы `sale.view_order_form` с полем после
`payment_term_id`, подключение файла вида в манифест.
PASS, если в блоках кода только это (атрибуты поля вроде string/copy/help и
placeholder допустимы).
FAIL, если в блоках кода есть лишнее: новая модель (`_name`), настройки
(res.config.settings), миксины, группы доступа, класс для stock.picking или
отчётов, computed/related поля, тесты, несколько альтернативных реализаций.
