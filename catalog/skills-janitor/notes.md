## Что проверили

1. **Сеть.** `curl` и `api.github.com` / `raw.githubusercontent.com` только
   в `search.sh`, `compare.sh`, `precheck.sh` (команда `/janitor-discover`).
   Уходит поисковый запрос или URL репозитория; `GITHUB_TOKEN` из env, если
   задан. Телеметрии нет. Остальные команды без сети.
2. **Что читает на машине.** `~/.claude/skills`, `./.claude/skills`,
   `~/.agents/skills` (Codex), `~/.claude/plugins/installed_plugins.json`
   и каталоги плагинов, `~/.claude/sources`, `~/.claude/agents`,
   `~/.claude.json` и `./.mcp.json` (имя сервера, транспорт, `command[:120]`,
   url; env и заголовки не выводит), транскрипты
   `~/.claude/projects/**/*.jsonl` за 4–8 недель — грепом только строк с
   `"name":"Skill"` и `"name":"mcp__`.
3. **Что пишет/удаляет.** `fix.sh --apply` правит `SKILL.md` пользователя
   (не плагины, не симлинки с v1.8); `--prune` — `rm -f` битых симлинков и
   `rm -rf` пустых каталогов; `swipe.sh` — `rm -rf` каталогов скиллов после
   подтверждения `y` и правка конфигов MCP с бэкапом
   `.bak-janitor-<время>`. Журнал в `data/` плагина.
4. **Права.** Все 6 скиллов: `allowed-tools: Read, Bash(bash:*)` — это
   предразрешение любой команды, начинающейся с `bash`, включая
   `bash -c '…'`. Шире, чем нужно для запуска своих скриптов.
5. **Хуков, MCP-серверов, агентов, бинарников нет.** Всё — bash + python3
   stdlib.
6. **Пути.** `SKILL.md` вызывают `bash ~/.claude/skills/skills-janitor/scripts/…`.
   При установке через `/plugin install` плагин лежит в
   `~/.claude/plugins/cache/…`, путь не совпадает (сам автор описывает это
   в Error Handling). В облачной сессии плагина по этому пути не будет.

## Свой замер на наших описаниях

Скрипт свой (`measure.py` рядом, повторяет только идею janitor), вход:
8 описаний `boost` из репо и 11 описаний командных скиллов
`anthropic-skills:*`, скопированных из листинга этой сессии. Результат в
`measure-2026-11-03.txt`.

- Описания: 384–892 символа, в среднем ≈ 680; 62–79% кириллицы. Все под
  лимитом Claude Code 1 536 символов (`description` + `when_to_use`,
  docs `code.claude.com/docs/en/skills`, прочитано 2026-11-03).
- Оценка janitor (1.3 токена на слово) даёт 2 300 «токенов» на 19 описаний.
  Для кириллицы токенов на слово заметно больше — **число занижено**, на
  сколько, не измеряли (нет API-ключа для count_tokens). Мерить через
  `/skill-doctor` на машине сотрудника.
- Перекрытие по-janitor-ски (`[a-z]+`): у кириллических описаний остаётся
  0–5 латинских слов. Из 3 пар выше порога 0.30 две ложные (общее слово
  `odoo` при объединении из 3 слов), а настоящий дубль
  `meeting-protocol-builder` ↔ `kickoff-survey-protocol` найден случайно,
  по словам `docx, humizer, todo`. С Unicode-словами (стем 6 букв) этот же
  дубль — единственная пара выше 0.30 (0.47), ложных нет.
- **Находка для главной сессии:** `meeting-protocol-builder` и
  `kickoff-survey-protocol` — два скилла на «Протокол обстеження» с
  почти одинаковыми тригерными фразами («протокол обстеження», «протокол
  інтерв'ю», «оформи протокол», «склади протокол», «протокол для
  замовника»). Какой сработает — не определено.

## Разрывы `janitor-security` (по коду `security.sh@4b42f39`)

- Фразы инъекций только английские; «игнорируй предыдущие инструкции»,
  «не говори пользователю» не ловятся.
- Внутри блоков кода ```` ``` ```` правила инъекций не применяются
  (`CODE_FENCE.sub`), а модель читает и их.
- Нет Unicode tag-символов (U+E0000–E007F, «ASCII smuggling»), нет
  U+200E/200F и U+2066–2069 (в `UNI_ALWAYS` только 200B, 2060, 202A–202E,
  FEFF).
- Сканируются только каталоги скиллов: `hooks/hooks.json`, `.mcp.json`,
  `plugin.json`, `agents/`, `commands/` плагина не смотрятся; `.json` и
  файлы без расширения пропускаются.
- Правила скриптов — первое совпадение на правило на файл.
- `allowed-tools`, `bypassPermissions`, широта `description` не
  проверяются.

## Решения

- Ставить не предлагаем: ядро (цена контекста, неиспользуемые скиллы,
  MCP) уже встроено (`/skill-doctor`, `/doctor`), автор сам перевёл проект
  в maintenance mode; в облаке не работает из-за путей; кириллицу не видит.
- Берём правила и идеи в свой барьер перед публикацией (см. README «Что
  взять»). Лицензия MIT позволяет перенос с атрибуцией.

## Открытые вопросы

- Реальная стоимость листинга ~100 скиллов в токенах: снять
  `/skill-doctor` на машине сотрудника с полным набором плагинов.
- Какой из двух скиллов протокола оставить — вопрос владельцам
  `odoo19-discovery-*`.
- A/B правил: прогнать будущий линтер на 3–4 подложенных «вредных»
  скиллах (в т.ч. по-русски и с tag-символами) и на всех наших плагинах
  (ложные срабатывания).
