# freellmapi — кратко для главной сессии

- **Что это:** самохостируемый шлюз (Node/Express/SQLite, MIT), сводит бесплатные
  тарифы ~40 LLM-провайдеров за одним OpenAI/Anthropic-совместимым `/v1`, с
  роутингом и failover. Плюс MCP-сервер (`ask_freellmapi`) и CLI, переписывающий
  конфиги Claude Code и других агентов. Очень активен (1044 коммита за 6 месяцев).
- **Доступ к моделям:** только по API-ключам, реверса веб-интерфейсов и кук нет.
  Но кроме официальных free tiers (Gemini, Groq, Cerebras, Mistral, OpenRouter…)
  есть десятки малоизвестных шлюзов-перепродавцов с «бесплатными» GPT/Claude/Grok
  неясного происхождения.
- **Главные риски:** запрос уходит заранее неизвестному провайдеру; многие free
  tiers обучаются на данных; часть ToS запрещает такое использование (Cohere,
  NVIDIA «только для оценки», Google с оговорками); поддержка нескольких ключей
  + прокси на ключ = инструмент обхода лимитов, риск бана аккаунтов; сервер по
  умолчанию слушает все интерфейсы.
- **Для Claude:** `setup-claude` заменяет Claude на бесплатные модели целиком
  (бессмысленно). Полезен лишь MCP-путь «спросить другую модель», но качество
  ответа случайно.
- **Вердикт:** **отклонить** (10/18, для клиентских данных неприемлемо).
  **Адаптировать идею:** свой маленький MCP/скилл «второе мнение» на одном
  платном провайдере с zero-data-retention.
