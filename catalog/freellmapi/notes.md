### Что установили

- **Механизм доступа:** только API-ключи и официальные API провайдеров/шлюзов.
  Реверса веб-чатов нет. Базовые URL захардкожены, каталог их не меняет.
- **Сетевые вызовы помимо провайдеров:** `api.freellmapi.co/v1/latest` (каталог,
  каждые 12 ч, Bearer лицензии если есть Premium; подпись Ed25519),
  `api.github.com` / `github.com` (проверка обновлений). Поисковые движки и
  «decision»-сервисы (hal-x.ai, aisenseapi.com) — только если настроены.
- **Ключи:** в SQLite, AES-256-GCM, мастер-ключ `ENCRYPTION_KEY` в `.env`.
  Экспорт ключей и бэкап JSON содержат открытые секреты (предупреждение в `.env.example`).
- **Логи:** таблица `requests` — без текста промптов (модель, токены, IP, UA клиента);
  текст — в кэше ответов (опционально) и беседах Playground.
- **Сеть по умолчанию:** вне Docker `HOST=::` (все интерфейсы). Docker публикует
  на 127.0.0.1. Первый аккаунт с удалённой машины требует одноразовый код из лога.
- **Активность:** 1044 коммита с 2026-04-21, 214 коммитов за октябрь 2026, основной
  автор Tashfeen Ahmed (+ бот `tashdroid`, контрибьюторы). Релизы почти ежедневно.
- **Монетизация:** Premium $19/год — «живой» каталог; бесплатный каталог отстаёт
  на 30 дней; модели малоизвестных шлюзов в основном только в платном каталоге.
- **Репозиторий содержит `.claude/settings.local.json` и `.claude/hooks/`** —
  при открытии клона в Claude Code сработают их хуки. Мы клон в Claude Code
  как проект не открывали.

### Риски (подробно)

**1. Условия использования / блокировка аккаунтов**
- Собственный ToS-обзор проекта (май 2026): Cohere ❌ (запрет personal use),
  Google Gemini ⚠️ (с марта 2026 — «только профессиональное/бизнес-использование»),
  NVIDIA NIM ⚠️ («evaluation only, not production»), Z.ai ⚠️ (анти-редирект трафика),
  Cloudflare ⚠️. Остальные «likely OK» при правилах: один аккаунт на провайдера,
  без перепродажи, без расшаривания эндпоинта.
- Код поддерживает несколько ключей на одну платформу с ротацией и отдельный
  прокси на ключ (`lib/key-proxy.ts`, миграция `api_key_proxy`). В связке это
  инструмент для обхода лимитов несколькими аккаунтами — нарушение ToS почти всех
  провайдеров, риск бана. Особенно опасно, если ключ Google создан под рабочим
  Google Workspace-аккаунтом: бан проекта/аккаунта затронет рабочие сервисы.
- Routeway требует подделку браузерного User-Agent для прохождения Cloudflare.

**2. Ключи и токены**
- Хранятся локально и зашифрованы — хорошо. Уходят только своему провайдеру
  (плюс в Fetch Relay / прокси, если пользователь их включил — они видят ключи
  и содержимое).
- Единый ключ `freellmapi-…` — единственная защита API; при `HOST=::` доступен из LAN.
- CLI `setup-*` пишет единый ключ в конфиги агентов (кроме `launch`).

**3. Какие данные уходят третьим лицам**
- Полный текст каждого запроса (промпт, системный промпт, история, вложения,
  вызовы инструментов) уходит провайдеру, выбранному роутером. Какому именно —
  известно только постфактум (`X-Routed-Via`). При failover один запрос может
  побывать у нескольких провайдеров. Fusion шлёт его нескольким сразу.
- Бесплатные тарифы ряда провайдеров (Google AI Studio free, Mistral Experiment,
  Kilo, часть `:free` маршрутов OpenRouter) разрешают использование данных для
  обучения и ревью людьми.
- Малоизвестные шлюзы (api.airforce, ElectronHub, Experiential, apinex.bond,
  kiosapi, kenari и др.) — непрозрачны: неясно, кто реально обрабатывает запрос.
- AI Horde — анонимные машины волонтёров.
- Китайские провайдеры — юрисдикция КНР.
- Сервер каталога промпты и ключи не получает (проверено по коду).

**4. Рабочие/клиентские данные**
- **Не подходит.** Нельзя гарантировать ни получателя, ни неиспользование данных
  для обучения, ни соответствие NDA/GDPR. Для клиентских Odoo-баз, переписки,
  протоколов встреч — однозначно нет.
- Допустимо максимум: личные эксперименты на публичных/синтетических данных, и
  то лучше с белым списком first-party провайдеров.

### Решения

- Вердикт: **отклонить** для работы. Идею MCP «второе мнение» — **адаптировать**
  своей реализацией на одном доверенном платном провайдере с ZDR.
- Не запускали и не тестировали — нужен явный запрос пользователя и, вероятно,
  личные ключи провайдеров.
