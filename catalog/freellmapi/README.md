# FreeLLMAPI

- **Тип:** самохостируемый LLM-шлюз (прокси-роутер) + MCP-сервер + CLI-настройщик агентов
- **Источник:** https://github.com/tashfeenahmed/freellmapi
- **Версия / коммит:** v0.16.16, `21d287ae` (2026-11-01)
- **Дата разбора:** 2026-11-02
- **Вердикт:** **отклонить** для рабочих и клиентских задач. Идею «второго мнения
  через MCP» имеет смысл адаптировать своим минимальным путём (см. ниже).

## Что делает

Локальный сервер на Node.js (Express + SQLite), который собирает бесплатные тарифы
~40 LLM-провайдеров за одним OpenAI-совместимым эндпоинтом `/v1` (плюс
Anthropic `/v1/messages`, Gemini `/v1beta`, эмуляция Ollama). Пользователь сам
регистрируется у провайдеров и вставляет их API-ключи; роутер выбирает «лучшую
доступную» бесплатную модель, при 429/5xx переключается на следующую, считает
RPM/RPD/TPM/TPD по каждому ключу. Есть веб-панель, десктоп-приложение, Docker,
MCP-сервер (`/mcp`, инструмент `ask_freellmapi`) и CLI `npx freellmapi`, который
переписывает конфиги 20+ агентов (Claude Code, Codex, Cursor, Cline…).

## Как получает доступ к моделям

**Только через API-ключи / официальные API-эндпоинты провайдеров.** Поиск по коду
(`cookie`, `sessionKey`, `chat.openai`, `claude.ai`, `puppeteer`, `cf_clearance`…)
не нашёл ни реверса веб-интерфейсов, ни работы с куками браузера. Базовые URL
захардкожены в `server/src/providers/*.ts`; удалённый каталог их менять не может.

Но провайдеры неоднородны (подробно: [`items/gateway.md`](items/gateway.md)):

| Группа | Примеры | Оценка |
|---|---|---|
| Первичные провайдеры с официальным free tier | Google Gemini, Groq, Cerebras, Mistral, Cohere, Cloudflare, NVIDIA NIM, HF, Ollama Cloud, OVH, SEA-LION | Легально, но free tier часто = данные идут на обучение / «только для оценки» |
| Известные агрегаторы | OpenRouter (`:free`), Requesty, Kilo Gateway | Легально; Kilo прямо логирует промпты для обучения |
| Китайские первичные | Zhipu, ModelScope, Qianfan, Volcengine, iFlytek, LongCat | Часть требует верификации личности в КНР; юрисдикция КНР |
| Малоизвестные шлюзы-перепродавцы | api.airforce, ElectronHub, Experiential Labs, Lucidity, DreamPrompting, Waterfall, Logfare, apinex.bond, kiosapi, kenari, router9, septor, navy, xkiro, unorouter, … | **Происхождение доступа к проприетарным моделям не проверяемо**, политики данных непрозрачны |
| Волонтёрские | AI Horde | Запросы исполняют анонимные машины волонтёров |

## Какую слабость Claude закрывает

Почти никакую. Даёт дешёвый доступ к *другим, в среднем более слабым* моделям
(Gemini Flash, DeepSeek, Qwen, Llama, GLM…) для: второго мнения, массовых простых
задач (классификация, перевод, суммаризация), эмбеддингов, STT/TTS. Качество
«плавает»: к концу суток сильные модели исчерпывают лимиты, роутер скатывается к
слабым (признают сами авторы).

## Как устроен

- `server/` — Express 5, SQLite (`better-sqlite3`), ~40 адаптеров провайдеров,
  роутер с «бандит»-скорингом, квоты/кулдауны, сжатие промптов, кэш ответов,
  Fusion (параллельный опрос нескольких моделей + арбитр).
- `client/` — React-панель (60 языков). `desktop/` — Electron. `cli/` — генераторы конфигов агентов.
- Зависимости сервера скромные: express, helmet, cors, zod, ajv, sharp, multer, undici, socks-proxy-agent.
- Ключи провайдеров: SQLite, AES-256-GCM, мастер-ключ `ENCRYPTION_KEY` в `.env`.
- Внешние вызовы помимо провайдеров: `api.freellmapi.co` (каталог моделей, 2 раза в сутки,
  подпись Ed25519; при Premium — Bearer лицензии), `api.github.com` (проверка обновлений).
  Промпты и ключи на сервер каталога не уходят (проверено по `services/catalog-sync.ts`).
- Модель монетизации: открытое ядро MIT + платный «живой каталог» ($19/год); бесплатный
  каталог отстаёт на 30 дней.

## Интеграция с Claude Code

Два пути (подробно: [`items/claude-code-launch.md`](items/claude-code-launch.md),
[`items/mcp-server.md`](items/mcp-server.md)):

1. `npx freellmapi setup-claude` / `launch` — подменяет `ANTHROPIC_BASE_URL`, и
   **весь Claude Code начинает работать не на Claude**, а на бесплатных моделях.
   Для нас бессмысленно: теряем Claude.
2. MCP: `claude mcp add --transport http freellmapi http://localhost:3001/mcp` —
   Claude остаётся главным, а инструмент `ask_freellmapi` позволяет делегировать
   текстовую задачу внешней модели. Это единственный путь, релевантный задаче
   «второе мнение / массовые задачи».

Субагенты Claude Code (Agent tool) всегда работают на моделях Anthropic; повесить
их на FreeLLMAPI можно только через MCP-инструмент, не через выбор модели субагента.

## Проверка

Не запускали (по правилам репозитория код недоверенный; нужен Docker/Node и
регистрация у провайдеров). Разбор статический.

| Задача | Без него | С ним |
|---|---|---|
| Второе мнение по коду/тексту | Субагент Claude (`code-review`, Agent) | Ответ случайной бесплатной модели; качество и провайдер заранее неизвестны |
| Массовая классификация 10k строк | Claude API (платно) | Бесплатно, но лимиты, нестабильная задержка, данные у третьих лиц |

## Оценка

| Критерий | Балл (0–3) | Комментарий |
|---|---|---|
| Прирост | 1 | Модели в среднем слабее Claude; польза только для дешёвых массовых задач и «второго голоса» |
| Частота | 1 | В нашей работе (Odoo, клиентские данные) применимо редко |
| Надёжность | 1 | Free tier без SLA, квоты меняются, к вечеру качество падает |
| Стоимость контекста | 3 | MCP-инструмент компактный, грузится по вызову |
| Безопасность | 1 | Код аккуратный и прозрачный, но данные уходят десяткам третьих сторон, часть малоизвестна; free tier часто обучается на данных; сервер по умолчанию слушает `::` (все интерфейсы) |
| Поддержка | 3 | Очень активен: 1044 коммита с апреля 2026, 214 за октябрь, релизы почти ежедневно, MIT |
| **Итого** | **10/18** | Для клиентских данных — неприемлемо независимо от суммы |

## Риски и заметки

Подробно: [`notes.md`](notes.md), раздел «Риски».

1. **Данные.** Каждый запрос уходит провайдеру, который выбрал роутер, т.е. заранее
   неизвестно кому. Бесплатные тарифы Google AI Studio, Mistral (Experiment),
   Kilo и др. используют данные для улучшения моделей / с ревью людьми. Для
   рабочих и тем более клиентских данных (NDA, персональные данные, Odoo-базы
   клиентов) **не подходит**.
2. **Серые шлюзы.** Часть «бесплатных» GPT-5/Claude/Grok идёт через малоизвестные
   перепродающие шлюзы; откуда у них доступ — не проверить. Даже если сам
   FreeLLMAPI чист, эти шлюзы видят весь текст запроса.
3. **Условия провайдеров.** Сами авторы оценивают: Cohere ❌ (запрет личного
   использования), Google/NVIDIA/Z.ai ⚠️ (NIM — «только для оценки»). Поддержка
   нескольких ключей на провайдера + прокси на каждый ключ технически позволяет
   обходить лимиты несколькими аккаунтами — это прямое нарушение ToS большинства
   провайдеров и риск блокировки аккаунта (в т.ч. корпоративного Google-аккаунта).
4. **Сеть.** По умолчанию `HOST=::` вне Docker — API доступен из локальной сети,
   защищён только единым ключом. Docker по умолчанию привязан к 127.0.0.1.
5. **Установка.** README предлагает `curl … | bash` и автообновление образа `:latest`;
   CLI `setup-*` правит глобальные конфиги агентов.

## Что можно взять

- **Идею**, а не продукт: MCP-инструмент «спроси другую модель» для второго
  мнения. Своя версия на ~30–50 строк, привязанная к **одному** платному
  провайдеру с договором о неиспользовании данных (например, OpenRouter с ZDR,
  Gemini API на платном тарифе, Vertex AI), даст тот же эффект без перечисленных
  рисков.
- Каталог freellmapi.co как справочник «где сейчас есть бесплатные модели» —
  для личных экспериментов на несекретных данных.
