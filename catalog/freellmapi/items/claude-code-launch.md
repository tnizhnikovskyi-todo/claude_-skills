# FreeLLMAPI: CLI `setup-claude` / `launch`

- **Тип:** CLI-генератор конфигов агентов (`cli/`, `npx freellmapi`)
- **Источник:** `cli/src/index.ts`, `cli/src/config-files.ts`, `cli/tools.json`
- **Версия / коммит:** `21d287ae`
- **Дата разбора:** 2026-11-02
- **Вердикт:** отклонить

## Что делает

`npx freellmapi setup-claude --url … --api-key …` записывает в конфиг Claude Code
(с бэкапом) `ANTHROPIC_BASE_URL` = локальный роутер, `ANTHROPIC_AUTH_TOKEN` =
единый ключ, `ANTHROPIC_MODEL` = выбранная бесплатная модель. `npx freellmapi
launch` делает то же через переменные окружения на один запуск, без записи в файлы.
Аналогичные команды есть для Codex, Cline, Roo, Aider и ещё ~15 агентов.

## Почему не подходит

После этого Claude Code — только оболочка: все рассуждения, правки кода и вызовы
инструментов выполняет бесплатная модель (Gemini Flash, DeepSeek, Qwen…),
а не Claude. Это противоположно цели репозитория «сделать Claude умнее».
Кроме того, весь контекст сессии (код, файлы, вывод команд) уходит выбранному
роутером провайдеру.

Субагентам Claude Code нельзя назначить «внешнюю» модель через этот путь:
`ANTHROPIC_BASE_URL` действует на весь процесс, значит и на главный агент тоже.
