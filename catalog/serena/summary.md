# serena: сводка для главной сессии

- **Что это:** MCP-сервер Oraios AI (oraios/serena, v2.1.0, очень активен):
  инструменты уровня IDE через языковые серверы (LSP) — оглавление файла,
  поиск символа/ссылок/реализаций, правка по символу, rename, плюс простая
  память `.serena/memories/`. 40+ языков, Python через pyright.
- **Лучшее:** чтение кода «по методам» вместо целых файлов и атомарный rename
  по ссылкам в типизированном коде. Пины зависимостей, SHA256 для LS,
  сервисы только на 127.0.0.1.
- **Odoo — главный минус:** связи Odoo живут в строках (`_inherit = 'sale.order'`,
  `env['...']`, `depends`, домены) и в XML; LSP их не видит, XML-сервера нет.
  `rename_symbol` в Odoo опасен: пропустит другие модули и вью, а промпт
  велит не перепроверять. Остаётся только экономия токенов при чтении.
- **Поведение Claude:** контекст `claude-code` запрещает Read/Edit для кода;
  рекомендуемые хуки делают deny на Grep/Read; предлагают подменить системный
  промпт CC. Авторы сами пишут, что без этого Opus почти не пользуется Serena.
- **Безопасность 2/3:** телеметрия по умолчанию (анонимная, opt-out
  `SERENA_USAGE_REPORTING=false`), дашборд вкл. (PyPI/news), LS качаются из
  сети. Лицензия приложения GPL-3.0+ (с v2), SolidLSP — MIT.
- **Контекст:** ~5.6k токенов описаний инструментов в CC (отложенные).
