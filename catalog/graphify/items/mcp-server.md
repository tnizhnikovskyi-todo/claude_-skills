# graphify: MCP-сервер

- **Тип:** MCP-сервер (stdio, опционально HTTP)
- **Источник:** `graphify/serve.py`, точка входа `graphify-mcp`, extra `graphifyy[mcp]`
- **Версия / коммит:** `32e5efe`
- **Дата разбора:** 2026-11-02
- **Вердикт:** отложить

## Что делает

Отдаёт готовый `graph.json` агенту как инструменты:
`query_graph`, `get_node`, `get_neighbors`, `get_community`, `god_nodes`,
`graph_stats`, `shortest_path`, `list_prs`, `get_pr_impact`, `triage_prs`;
и ресурсы `graphify://report|stats|god-nodes|surprises|audit|questions`.

## Безопасность

- stdio по умолчанию; `--transport http` слушает `127.0.0.1:8080`, на
  `0.0.0.0` только явно; опциональный API-ключ (`x-api-key` или Bearer).
- Пути к графу ограничены `graphify-out/` (`validate_graph_path`).
- Метки узлов санитизируются перед выдачей (защита от инъекций через имена
  в исходниках). `triage_prs` вызывает настроенный LLM-бэкенд.

## Почему отложить

CLI (`graphify query/path/explain`) через Bash даёт то же самое без постоянного
процесса и без лишних схем инструментов в контексте. MCP имеет смысл, если
граф будет жить на сервере и использоваться из claude.ai/Cowork, где нет
shell — тогда пересмотреть.
