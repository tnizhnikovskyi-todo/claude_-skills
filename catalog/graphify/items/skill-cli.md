# graphify: скилл `/graphify` и CLI

- **Тип:** скилл Claude Code + Python CLI
- **Источник:** `graphify/skill.md`, `graphify/skills/claude/references/*.md`, `graphify/cli.py`, `graphify/__main__.py`
- **Версия / коммит:** `32e5efe`
- **Дата разбора:** 2026-11-02
- **Вердикт:** адаптировать

## Что делает

`/graphify <путь>` строит граф: детект файлов → AST-извлечение кода (локально)
параллельно с семантическим извлечением документов субагентами →
слияние → кластеризация → отчёт и экспорт. Если `graphify-out/graph.json` уже
есть, «быстрый путь»: вопрос сразу идёт в `graphify query`. Также умеет
клонировать GitHub-репо по URL и сливать несколько графов.

CLI отдельно от скилла: `graphify extract . --code-only` (оффлайн, без ключей),
`graphify update .` (инкрементально), `query`, `path`, `explain`, `export
wiki|html|obsidian|graphml|cypher`, `prs` (обзор PR через `gh`).

## Какую слабость Claude закрывает

Первичное ориентирование в большом незнакомом коде и вопросы «как X связан с
Y» без чтения десятков файлов; повторное использование этого знания между
сессиями (граф на диске).

## Как устроен

- Тело скилла 797 строк. Шаги — bash/python-блоки, которые Claude
  копирует и выполняет; интерпретатор запоминается в
  `graphify-out/.graphify_python`.
- Семантический проход: **обязательно** Agent tool, `general-purpose`
  субагенты, по чанку файлов на агента, все в одном сообщении. Промпт
  субагента — `references/extraction-spec.md`. Есть проверка покрытия (субагент
  сообщает, сколько строк прочёл).
- Если задан `GEMINI_API_KEY`/`GOOGLE_API_KEY` — документы уходят в Gemini
  вместо субагентов.
- Ответы `query` ограничиваются бюджетом токенов (`--budget`).

## Как адаптировать

1. Ставить CLI вручную с пином версии: `uv tool install graphifyy==<ver>`.
2. Для кода использовать только `graphify extract . --code-only` и
   `query/path/explain` — это покрывает 90% пользы без LLM и без сети.
3. Свой короткий скилл (~30–50 строк) вместо 797-строчного: когда строить граф,
   три команды запроса, `GRAPHIFY_BACKEND=none`, без автоустановки, с
   описанием, которое триггерится только на явную просьбу или на большой
   незнакомый репозиторий.
