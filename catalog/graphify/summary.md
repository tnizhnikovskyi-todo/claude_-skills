# graphify: сводка для главной сессии

- **Что это:** Python-CLI + скилл `/graphify` (Graphify Labs, YC S26, Apache-2.0).
  Строит из папки граф знаний: код локально через tree-sitter (~40 языков,
  без LLM и сети), документы/PDF/картинки через субагентов текущей сессии.
  Запросы `graphify query / path / explain` вместо grep.
- **Что даёт Claude:** память о структуре большого кода между сессиями и
  связи, невидимые grep (цепочки вызовов, пути между модулями, подсистемы),
  с метками достоверности рёбер `EXTRACTED / INFERRED / AMBIGUOUS`.
- **Лучшая находка:** режим `graphify extract . --code-only` — оффлайн, без
  ключей, детерминированно; три команды запроса закрывают основную пользу.
- **Минусы:** скилл на ~10k токенов с триггером «на любой вопрос о коде»;
  сам ставит непинованный пакет из PyPI; always-on хуки на каждый Grep/Read;
  авто-выбор внешнего LLM по ключам в окружении (Gemini, Kimi, DeepSeek…);
  слабый бенчмарк по коду (n=6, +11 п.п. к grep). Для Odoo, вероятно, не
  видит главного: `_inherit` строкой и XML-вью (нужно проверить).
- **Безопасность:** код аккуратный (нет `shell=True`/`eval`, хуки fail-open,
  SSRF-защита, редактирование секретов, без телеметрии). Оценка 2/3.

- **Пересекается с:** ничем из `inventory/current.md` (там нет инструментов
