# upskill CI-заготовка: выбор по diff и вклад скилла

- **Тип:** библиотечный модуль (команды CLI нет)
- **Источник:** `src/upskill/ci.py` (строки 80–214), `src/upskill/models.py:473-552`, `tests/test_ci.py`, `tests/fixtures/ci_action_repo/` @ `eec8ab4`
- **Лицензия:** Apache-2.0
- **Вердикт:** адаптировать идеи 1–2 (README)

## Что делает

1. **Манифест** `.upskill/evals.yaml`: сценарии `{id, skills: [пути],
   tests: файл кейсов, judge: {enabled, criteria}, include_baseline}`.
2. **Выбор сценариев.** `scope: changed` — `git diff --name-only
   <base>...HEAD`, для каждого файла вверх по дереву до первой папки с
   `SKILL.md`; берутся сценарии, где есть такой скилл. `scope: all` — все.
3. **Отчёт.** Для сценария: вариант `bundle` (все скиллы), `ablation`
   (каждый раз без одного), `baseline` (без скиллов). Таблица вклада:
   `hard_score_delta`, `judge_score_delta`, `passed_without_skill`.
   Markdown в `GITHUB_STEP_SUMMARY`, JSON-отчёт рядом.

На коммите `eec8ab4` сам прогон вариантов не реализован в CLI: есть
планирование, модели и рендер отчёта, покрытые тестами.

## Почему интересно нам

- У `boost` 8 скиллов и общий набор `general/`. Сейчас мы видим вклад
  плагина целиком и каждого скилла на его собственных кейсах, но не
  видим, **не стал ли скилл лишним** (база догнала, или другой скилл
  делает то же). Флаг «прошло и без этого скилла» — прямой сигнал для
  еженедельного ревью: кандидат на вывод из плагина.
- Выбор по diff экономит бюджет ревью: A/B только для скиллов, чьи папки
  изменились относительно ветки по умолчанию.

## Как перенести

- В `weekly-review.md`, шаг A/B: список изменённых скиллов —
  `git diff --name-only origin/main...HEAD -- plugins/boost/skills | cut -d/ -f4 | sort -u`,
  затем `claude plugin eval plugins/boost --case '<скилл>/*' --runs 3`
  для каждого.
- Раз в месяц (или после смены модели): для каждого скилла прогон его
  кейсов в базе; если база проходит не хуже скилла — наблюдение
  `retire-candidate` в `observations/`.
- До этого проверить, поддерживает ли `claude plugin eval` ablation по
  одному скиллу (`--ablation`); если нет — база через копию плагина без
  папки скилла (так уже делаем для кейсов с историей).
