# upskill (Hugging Face)

- **Тип:** CLI-инструмент (Python) для генерации и оценки скиллов агентов
- **Источник:** https://github.com/huggingface/upskill
- **Версия / коммит:** `eec8ab46f970a880e4d21cfd41dff50ac08c6847` (2026-10-14), PyPI `upskill`
- **Лицензия:** Apache-2.0 (сверено по файлу `LICENSE`, «Copyright 2026 Hugging Face»; чужих файлов под другой лицензией в дереве нет)
- **Дата разбора:** 2026-11-03
- **Вердикт:** **адаптировать** (идеи для нашего A/B и еженедельного ревью); инструмент не ставить

## Что делает

`upskill generate "задача"` просит сильную модель («учителя») написать
`SKILL.md` на 200–400 слов, генерирует 3–5 синтетических кейсов с
ожидаемыми подстроками, прогоняет их со скиллом и без, и до двух раз
правит скилл по провалам. `upskill eval/benchmark` меряет прирост на
одной или нескольких моделях («учениках», например haiku), `runs` рисует
матрицу «скилл × модель». Исполнение — через фреймворк fast-agent
локально или в Hugging Face Jobs. Есть заготовка CI с оценкой вклада
каждого скилла в наборе (без команды в CLI).

## Какую слабость Claude закрывает

Напрямую никакую: это инструмент автора скиллов, а не скилл. Его цель —
перенести умение дорогой модели в дешёвую через текст скилла и доказать
это числом. Для нас ценно как источник приёмов измерения.

## Как устроен

| Компонент | Что внутри | Карточка |
|---|---|---|
| `generate` + цикл улучшения | `generate.py`, `agent_cards/skill_gen.md`, `cli.py:709-797` | [items/generate-refine.md](items/generate-refine.md) |
| `eval` / `benchmark` / `runs` | `evaluate.py`, `verifiers.py`, `models.py:455-470` | [items/eval-benchmark.md](items/eval-benchmark.md) |
| CI-заготовка (выбор по diff, ablation) | `ci.py`, `models.py:473-545` | [items/ci-ablation.md](items/ci-ablation.md) |
| `propose-skills.sh` | Майнинг `~/.claude/projects/*.jsonl` → `claude -p` → `~/.claude/skills` | только здесь, ниже |
| HF Jobs | `hf_jobs.py`, `executors/remote_fast_agent.py`, `scripts/hf/*.sh` | только здесь, ниже |

**Права и сеть.** Ставится из PyPI (`uv pip install upskill`), тянет
`fast-agent-mcp>=0.6.7` без верхней границы. Ходит к провайдерам моделей
по ключам (`ANTHROPIC_API_KEY`, `OPENAI_API_KEY`). В режиме `jobs`
(включён в репозиторном `upskill.config.yaml`, в коде по умолчанию
`local`) пробрасывает `HF_TOKEN` и `ANTHROPIC_API_KEY` в контейнер HF
Jobs и загружает скилл, кейсы и ответы в датасет-репозиторий HF.
Верификатор `command` исполняет строку из файла кейсов через
`shell=True`. `propose-skills.sh` отправляет до 50 ваших сообщений из
истории Claude Code за 30 дней в `claude -p` и пишет скиллы в глобальный
`~/.claude/skills`. Телеметрии в коде upskill нет (fast-agent не
проверяли).

уведомления; мы берём только идеи и пересказ своими словами, код не
копируем. Атрибуция — в `references/attribution.md` целевого скилла и
строкой в `PROVENANCE.md` (делает главная сессия).

|---|---|---|---|---|---|

## Риски и заметки

- **Заготовка CI не подключена:** `ci.py` и модели отчёта есть, команды
  `upskill ci` в `cli.py` на этом коммите нет. Идеи 1–2 берём как схему,
  а не как работающий инструмент.
- Файлы кейсов upskill исполняемые (`command`, `shell=True`): чужие
  наборы кейсов не запускать.
- Если когда-то понадобится запуск: только `executor: local`, без
  `--artifact-repo`, с пином версии `fast-agent-mcp`, без
  `propose-skills.sh`.
