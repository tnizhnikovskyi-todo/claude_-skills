## Что делают
Ворота качества (критерии входа/выхода), итоговый отчёт тестирования,
релизный график с Go/No-Go.

## Ценное
- Критерий выхода: обязательство, свежесть доказательства, оператор и
  результат из четырёх: пройдено / не пройдено / заблокировано /
  невідомо. Нет доказательства → невідомо, никогда не «пройдено»
  (fail-closed).
- Исключения отдельно от результатов: объём, кто разрешил, причина, срок
  действия, компенсирующие меры, отзыв. Исключение не переписывает провал.
  Для нас это формализация «прийнято із зауваженнями» в акте.
- Отчёт разделяет: подтверждённые факты (с источником) / выводы / чего не
  хватает / остаточный риск / рекомендации. Если нет ни исполнения, ни
  дефектов — единственный статус «не виконано або доказів недостатньо».
  Нельзя придумывать процент прохождения, «0 дефектов», результаты
  повторной проверки.
- Сроки можно сжать, критерии выхода удалять нельзя; условный Go — только
  с проверяемыми условиями (не «понаблюдаем»). Решение принимает
  уполномоченный человек, скилл даёт рекомендацию.
