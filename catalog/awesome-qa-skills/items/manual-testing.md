## Что делает
План ручного/исследовательского тестирования: «хартии» на тайм-бокс
(риск, среда/сборка, данные, рамки, срок, доказательства), чек-лист сессии,
фокусы исследования, условия остановки/эскалации.

## Ценное (главное для UAT)
- Строка исполнения: предусловие → действие → ожидаемое → факт → ID
  доказательства → статус.
- Отдельные статусы: не начато, прервано, заблокировано средой; список
  проверок без факта — не журнал исполнения.
- Данные для прогона восстанавливаемы; после прогона вернуть аккаунты /
  документы / настройки по политике и проверить остатки; удаление без
  разрешения — не очистка.
- При нехватке времени сначала закрыть критичный риск, незавершённое
  сохранить с владельцем и точкой возобновления; выводы только о том, что
  реально наблюдали.

## Куда
T11: колонки «Факт», «Доказательство» (скрин, номер документа Odoo, ссылка
на запись), «Статус» с украинским словарём (Не розпочато / Перервано /
Заблоковано / Пройдено / Не пройдено); правило: «Пройдено» без факта и
доказательства недопустимо. Блок «Підготовка даних і відновлення» для
тестовой базы клиента.
