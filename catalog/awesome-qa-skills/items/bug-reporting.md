# bug-reporting

Источник: `naodeng/awesome-qa-skills@fc10ba1`, лицензия PolyForm NC 1.0.0 → только идеи своими словами. Ниже пересказ, не цитаты.

- **Файлы:** `skills/en/testing-types/bug-reporting/{SKILL.md,prompts/bug-reporting.md}`
- **Вердикт:** адаптировать (идеи) → `hypercare-tracker`, колонка «Дефект» T11

## Что делает
Короткий воспроизводимый баг-репорт.

## Ценное
Минимум полей: заголовок, окружение (у нас — база/ветка/версия модуля,
компания, пользователь/группа), предусловия, шаги, факт, ожидаемое,
частота воспроизведения, масштаб влияния, серьёзность и приоритет с
обоснованием по бизнес-влиянию, доказательства, открытые вопросы. Факт
отдельно от гипотезы причины; неполное воспроизведение — явно.

## Оценка
Общее место: модель и так пишет такие репорты по просьбе. Ценность только
как фиксированный набор полей для трекера и связка «UAT-строка → ID
дефекта». Сверить с полями `hypercare-tracker`.
