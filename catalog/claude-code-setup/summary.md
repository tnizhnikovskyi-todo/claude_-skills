# summary: claude-code-setup

- **Что это:** официальный плагин Anthropic (`claude-plugins-official`,
  `plugins/claude-code-setup`, v1.0.0, коммит `a7ba5b9`, 195k установок).
  Состоит из одного скилла `claude-automation-recommender` и пяти
  справочников. Скриптов, хуков, MCP и агентов нет.
- **Что делает:** смотрит на репозиторий и печатает отчёт: по 1–2
  рекомендации на категорию (MCP, скиллы, хуки, субагенты, плагины).
  Сам ничего не меняет.
- **Безопасность 3/3:** исполняемого кода нет, только `ls`/`cat` и веб-поиск
  по названиям библиотек.
- **Слабые места:** уклон в JS/фронтенд, Odoo не упомянут; не видит
  установленных плагинов и коннекторов, поэтому предлагает дубли; часть
  справки устарела; про облачные сессии и SessionStart ничего нет.
- **Относительно наших `init` / `update-config` / `fewer-permission-prompts`
  / `session-start-hook`:** не пересекается, но и новой возможности не
  даёт — это шпаргалка-аудит.
- **Оценка:** 11/18 (прирост 1, частота 1, надёжность 2, контекст 2,
  безопасность 3, поддержка 2).
- **Вердикт:** адаптировать. Взять таблицу «признак → автоматизация» и
  справку по frontmatter скиллов, дописать Odoo/Python и сверку с
  `inventory/current.md`, оформить как свой `repo-automation-audit`.

  `/plugin install claude-code-setup@claude-plugins-official`.
