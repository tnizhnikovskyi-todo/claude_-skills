# sdlc-test — оркестрация тестов

- **Тип:** скилл (+ скрипты, шаблон Playwright-раннера)
- **Источник:** https://github.com/TsCarpe/claude-sdlc-skills/tree/49ef0b3/skills/sdlc-test
- **Версия / коммит:** `49ef0b3`
- **Дата разбора:** 2026-11-03
- **Вердикт:** взять одну технику («инварианты редактирования») в чек-листы; остальное отклонить

## Что делает

Подкоманды `cases` (кейсы по 7 техникам, двусторонняя трассировка,
человек подтверждает), `dev` (compile/boot/smoke скриптом),
`static` (правила FR-xx ↔ код через `codegraph`/`mysql` MCP),
`exec` (браузер через `chrome-devtools` MCP, пакетами по 3–5 кейсов
субагентам), `spec` (прошедшие кейсы → Playwright, регресс без токенов),
`report`. Входной сторож `guard_exec.py`.

## Что сверх нашего

- **Техника 7 «инварианты замкнутого редактирования»**
  (`references/cases/design-techniques.md` «编辑闭环不变量»), из реального
  разбора трёх дефектов: для каждой функции «редактировать существующее»
  четыре группы, обязательны при любом уровне риска:
  G1 открыть и сохранить без изменений — в каждом достижимом состоянии
  сохраняется; G2 заблокированное поле в заблокированном состоянии —
  отказ с текстом; G3 незаблокированное поле в том же состоянии — не
  мешает; G4 то, что форма показала, совпадает с тем, что она отправляет
  (ключи не теряются, тип не меняется).
  Для Odoo это прямо `readonly`/`invisible` по `state`, `@api.constrains`
  и `write()`, срабатывающие на неизменённой записи, `onchange`.
- **Независимость:** `cases` запрещено читать дизайн — условие для гейта.
- Анти-рационализации для исполнения («console error, но страница
  нормальная — значит прошло» → нет, «под вопросом»); 4 вида
  доказательств (экран / ответ API / запись в БД / console).

## Сравнение с нашим

- `odoo19-mvp-build:testing` текст не видели. `tr-usecases-acceptance`
  уже требует «нещасливі шляхи», повторы и конкурентность (по сессии nacl).
  Техники G1–G4 явно не названы ни там, ни в `tr-review`.
- `exec`/`spec`/`static` завязаны на Java + MySQL + свои MCP — для Odoo
  не годятся; у Odoo свои `tests/` и тур-тесты.
