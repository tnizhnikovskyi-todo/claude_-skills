# claude-sow-creation: итог для главной сессии

- **Что это:** плагин `sow-creation-v2` (Celebal Technologies, 2 коммита от
  2026-08-24, ★0) — конвейер SOW для presales: MCQ-анкета клиенту → черновик SOW
  (24 раздела) → встраивание архитектуры и BoM → проверка по матрицам рисков;
  оркестратор с журналом и хешами. Коммит `a2c4f18`.
- **Лицензия:** файла нет; в `plugin.json` написано «MIT» без текста, часть
  файлов из чужого внутреннего плагина. Считаем, что лицензии нет: только идеи.
- **Гипотеза** «SOW + анкеты» подтверждена частично: анкета одна, ценность в
  дисциплине черновика.
- **Лучшие находки:** (1) сроки и команда только с названным основанием, иначе
  каркас без чисел; (2) противоречащие источники — обе версии с датой, без
  усреднения; (3) шлюз конфиденциальности: себестоимость и маржа не попадают в
  клиентский документ, сомнительное тоже; (4) заглушки «блокер / подтвердить»,
  коммерция всегда блокер, проверка проваливается при любом блокере;
  (5) блоки «как сделан черновик» и «открытые пункты» в начале документа;
  (6) чек-лист обязательных тем вместо банка вопросов.
- **Сверка с нашими продажами** (`sale_todo_claude@2a7f7c1`): идеи «оценка
  с основанием», «противоречия источников», «нет цены — не КП», «внутреннее не
  уходит клиенту» у нас **уже есть**, местами сильнее (аналоги по таймшитам,
  приоритет источников + `R-N`). Нового для продаж — только MCQ-дозбор
  (рекомендованный вариант, «Другое», «Не решили», блокеры/уточнения, адресат).
- **Безопасность 3/3** (один локальный скрипт, без сети и хуков), итог 10/18.
- **Вердикт: адаптировать узко.** Не ставить. Кандидаты: MCQ-дозбор после
  брифа/демо; для `discovery-sow-builder` — два уровня пропусков, блоки «как
  сделан / открытые пункты», оценка сроков в SOW только с основанием, пара
  «принятый риск = гейт go-live + риск».
- **Блокер сверки:** `discovery-sow-builder` в приватном
  `todoltd/claude-methodology-marketplace`; `add_repo` на чтение отклонён в этой
  сессии. Нужен доступ или текст скилла.
