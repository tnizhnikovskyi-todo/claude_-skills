# constraint-driven-development

- **Тип:** скилл + команда `/constraints` (часть плагина `agent-skills`)
- **Источник:** https://github.com/addyosmani/agent-skills/tree/main/skills/constraint-driven-development
- **Версия / коммит:** 0.6.15 / `301b02b`
- **Дата разбора:** 2026-11-02
- **Вердикт:** **адаптировать** (идея «пола качества» для `odoo19-mvp-build`)

## Что делает

Фиксирует планку качества проекта в `CONSTRAINTS.md` в корне репозитория и
следит, чтобы агент её **тихо не опускал**. Сначала смотрит стек, тесты,
линтеры и CI, потом задаёт ровно 4 вопроса, у каждого есть значение по
умолчанию. Обязательный «пол»: никаких новых `@ts-ignore` / `eslint-disable` /
`# noqa`, заглушек «Not implemented», пустых `catch`, пропущенных или
удалённых тестов без причины, секретов, и сам файл нельзя ослаблять, чтобы
изменение прошло. Есть «храповики»: замерить текущее значение и не давать ему
ухудшаться. Есть таблица исключений со сроком действия.

## Какую слабость Claude закрывает

Типичный срез агента ради зелёного CI: отключить проверку, пометить тест
skip, ослабить assert, понизить порог. Встроенные `code-review` и `simplify`
это не ловят как отдельную политику.

## Как устроен

`SKILL.md`, 319 строк, около 22 КБ (самый тяжёлый скилл). Плюс
`references/floor-guard.md` и `scripts/quality-gate.mjs`. Скрипт только читает
JSON-отчёты semgrep/axe и считает блокирующие находки, без сети и exec.

## Оценка

| Критерий | Балл | Комментарий |
|---|---|---|
| Прирост | 2 | Правила «пола» ценны, интервью и таблица порогов для нас избыточны |
| Частота | 1 | Нужен один раз на проект, дальше работает файл |
| Надёжность | 2 | Зависит от того, читает ли агент `CONSTRAINTS.md` (это строка в CLAUDE.md) |
| Стоимость контекста | 1 | 22 КБ |
| Безопасность | 3 | Скрипт прочитан, безопасен |
| Поддержка | 3 | Активно |
| **Итого** | **12/18** | |

## Как адаптировать

Взять только «Floor» (10–15 строк) и добавить в CLAUDE.md шаблона Odoo-проектов
и в `odoo19-mvp-build` / `pr-review` как проверку диффа: новые `# noqa`,
`skip`, удалённые тесты, ослабленные `ir.model.access`, `sudo()` без
комментария.
