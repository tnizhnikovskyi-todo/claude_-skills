# darwin-skill — кратко для главной сессии

- **Что это:** один скилл (MIT, ★6.8k, один автор, последний коммит 2026-09-18, разобран `8a8b662`): цикл «рубрика 9 измерений → худшее измерение → 1 правка → коммит → 3 свежих судьи парно сравнивают старую/новую версию → большинство ≥ → оставить, иначе `git revert`» с чекпоинтом человека после каждого скилла и PNG-карточкой.
- **Критерий keep/revert:** голос судей по ТЕКСТУ скилла (тесты в этом шаге не перезапускаются); ничья = оставить. Поведение мерится только в базовой оценке на 2–3 синтетических промптах. Слабее нашего A/B по поведению.
- **Защита от переобучения:** отложенных кейсов нет (у SkillOpt есть — это уже в T14). **От раздувания:** лимит 150% размера, запрет новых файлов, стоп после 2 раундов с Δ < 2; но рубрика награждает таблицы и списки.
- **Стоимость:** ~0.3–0.5M токенов на скилл (оценка), скилл ~10k токенов, широкий китайский триггер; тихий `git ls-remote` раз в 30 дней, `npx`/Playwright для карточек. Безопасность 2.
- **Нашёл у нас слабость:** `weekly-review.md` §5 сравнивает новый прогон с числами из прошлого отчёта — это сравнение разных прогонов (автор замерил шум ±8/100 у неизменного текста).
- **Взять (пересказ/идея, MIT, в `weekly-review.md`, приложить к T14):** (1) парное A/B — старая и новая версия скилла в одной серии, тот же судья, нечётное число прогонов, ничья = не сливать; (2) лимит роста `SKILL.md` за правку (~+15 строк / 20%), проверка `wc -l` в gate; (3) режим подтверждения в `resolution`: `eval` / `manual` / `none`; (4) барьер-линт с исключением для справок, где запрещённое перечислено (урок самоссылочного ложного срабатывания; важно для T1/T2); (5, низкий) стоп по убывающей отдаче.
- **Не брать:** скилл целиком, рубрику, «runtime-neutrality» (вычищает Claude Code), линт размытых слов (0 попаданий по нашим 8 скиллам), карточки.
