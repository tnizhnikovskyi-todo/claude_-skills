# Скиллы erpipe `odoo-mcp` (`skills/`)

Источник: https://github.com/erpipe-org/mcp-odoo, `skills/*/SKILL.md@76ec136e0c89c414811a12629eb2903d2dc27357`, лицензия MIT. Пересказ, текст не копировали.

4 SKILL.md по ~55–62 строки: `odoo-data-quality-gate`,
`odoo-migration-copilot`, `odoo-month-end-close`, `odoo-agency-fleet-review`.
Это плейбуки поверх инструментов именно этого сервера (`data_quality_report`,
`preview_write`, `submit_async_task`…), с нашим `odoo-mcp` напрямую не
работают.

Прочитан `odoo-data-quality-gate`: сначала скоуп с человеком, отчёт по
модели, **доказательства с id в таблице**, проверка «сирот» через
`diagnose_access` (не видно из-за прав ≠ висячая ссылка), исправления
партиями с явными id и значениями, исполнение по одной одобренной партии.

Ценное для нас: приём «orphan может быть просто недоступен по правам —
проверь, прежде чем чистить» и «партии с явными id» — годится в правила
наших скиллов дискавери/миграции (`odoo19-implementation`). Ставить сами
скиллы не нужно. Остальные три не читали.
