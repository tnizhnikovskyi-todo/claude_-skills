# ba-skills — итог для главной сессии

**Что это.** uycung/ba-skills (MIT, ★0, один автор, вся история 25–26.10.2026):
11 англоязычных скиллов БА по BABOK v3 — стейкхолдеры, бизнес-кейс,
выявление требований, истории/AC, NFR, моделирование, приоритизация,
трассировка, ревью, тест-кейсы/UAT, сборка BRD/PRD/SRS. Гипотеза подтвердилась.
Только текст + один stdlib-скрипт `fin.py`; сети, хуков, телеметрии нет.

**Лучшие находки.**
1. `requirements-stakeholders`: чек-лист стандартных ролей против пропусков
   («не применимо + причина»), признаки неполного списка, одна A в RACI.
   Приватность, роль в решении и «мотивы только со слов, с источником» у
   нас уже есть (`handover-dossier-builder` Крок 3а) — не дублировать.
2. `requirements-elicitation`: правило «без наводящих вопросов» — дополняет
   наш метод гипотез (гипотеза для уточнения после ответа, не в вопросе);
   «зонды» («покажите последний пример»); черновик письма-подтверждения.
3. `business-case-strategy`: у нас аналога нет (в `odoo19-sales-*` ROI нет); правила «не выдумывать
   числа», «вариант ничего не делать», «считать кодом».
4. Evals с кейсами-**ловушками** и линт одинакового блока соглашений
   («барьер вместо формулировки»).

**Вердикт: адаптировать**, 11/18 (безопасность 3, поддержка 1, прирост 1 —
не измерен). Как есть не ставить: английский, общий BABOK, пересечение с
