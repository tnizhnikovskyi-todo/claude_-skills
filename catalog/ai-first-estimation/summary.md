# ai-first-estimation — кратко для главной сессии

**Что это:** один `SKILL.md` (~1,4 тыс. токенов, MIT, ★1, один день работы
автора) для оценки проектов, где код пишет ИИ. Гипотеза подтверждается:
считает только время человека — постановка, доступы, решения, смоук на
проде, приёмка, надзор за агентом; часы растут с числом «точек касания с
реальным миром», а не с объёмом кода.

**Слабое:** коэффициенты ничем не обоснованы (PM ~15%, «1,5–2x»), ревью кода
сведено к точечному аудиту, «время ИИ бесплатно» без статьи на переделки,
домен — B2C-приложения (App Store, KYC), широкий триггер.

**Почему важно нам:** выход `tr-effort-instruction` в готовых ТР — таблица по
этапам «Розробка / Тестування / …» в люд./год., хотя код пишет Claude
(`odoo19-mvp-build`). Чьи это часы — непонятно.

**Вердикт: адаптировать (11/18), не ставить.** Взять в
`tr-effort-instruction` / `preliminary-estimate`: (1) колонку «що робить
людина» по модулю; (2) свой список несжимаемых блоков для Odoo (миграция,
UAT, обучение, банк/ЕДО/ПРРО); (3) условие «изменение после сборки =
перепроверка = часы»; (4) урезанный вариант под открытый вопрос вместо
отказа от оценки; (5) календарь отдельно от часов.

**Оговорка:** тексты наших скиллов оценки в среде не синхронизированы —
сравнение по форме их выхода; перед правкой сверить с оригиналами. Сначала
стоит собрать факт часов человека по 5–10 AI-собранным ТР.
