# task-observer (ядро: SKILL.md + лог наблюдений)

- **Тип:** скилл (упакован как плагин `task-observer`)
- **Источник:** https://github.com/rebelytics/one-skill-to-rule-them-all/blob/main/SKILL.md
- **Версия / коммит:** 3.8.1 / `ba696b2`
- **Дата разбора:** 2026-11-02
- **Вердикт:** адаптировать (метод и формат), не ставить как есть

## Что делает

Работает фоном в каждой сессии: замечает поправки пользователя, нарушения
правил скиллов, повторяющиеся ручные процессы и пишет по файлу-наблюдению
на каждую находку в `skill-observations/observation-log/NNNN-slug.md`
(YAML-frontmatter + Issue → Suggested improvement → Principle). На старте
сессии сканирует frontmatter лога; при загрузке любого скилла находит
открытые наблюдения по нему и применяет их к текущей задаче (но не правит
файлы). Раз в неделю предлагает ревью (см. `weekly-review.md`).

## Какую слабость Claude закрывает

Память и метод: Claude не учится между сессиями, поправки теряются,
скиллы «замерзают». Здесь поправка становится артефактом с жизненным
циклом (`open → actioned/declined/superseded/parked`) и попадает в скилл
через ревью человеком.

## Как устроен

- `SKILL.md` ~11 тыс. токенов; 7 reference-файлов (~500 КБ) грузятся по
  триггерам. Обязательные шаги Session Start Protocol: probe рабочей папки,
  создание структуры, скан, проверка срока ревью, проверка activation block
  в `CLAUDE.md`, сверка staged-обновлений, предложение backfill.
- Скрипты: `new-observation.sh` (единственный путь создания записи: id =
  max(active, archive, `.id-floor`)+1, noclobber, архивация по пути),
  `session-start-scan.sh`, `skill-load.sh`, `migrate-log.py` (миграция
  со старого формата), `validate-skill-bundle.py` (линтер бандла).
- Обязательные чекпоинты записи: после каждой 3-й закрытой todo, при сдаче
  результата, при отказе записи во внешнюю систему.
- Сеть: нет, кроме ручного feedback pre-flight перед отчётом автору.
- Права: запись только в свою рабочую папку; `mv`, без `rm`.

## Риски и заметки

- В эфемерном облачном контейнере лог потеряется, если не класть его в git.
- Будет предлагать дописать activation block в `CLAUDE.md`, что для
  сессий анализа запрещено нашими правилами.
- Лицензия CC BY 4.0 (не программная): при адаптации нужна атрибуция
  (автор и ссылка на репозиторий).
- Наблюдения пишутся моделью: возможен перенос инструкций из недоверенного
  контента в лог. Автор это осознаёт (`SECURITY.md`, `signals.md`
  «Instructions handed across a boundary»), но гарантий нет.
