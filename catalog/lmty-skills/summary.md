# lmty-skills — итог для главной сессии

- **Что это:** `LMTYdotcom/skills` (MIT, ★84, v1.0.0, 2026-09/10) — 16
  скиллов `competitive-*` для PMM/продаж SaaS + автоматически
  подключаемый сторонний MCP `mcp.lmty.com` (OAuth, только чтение,
  код закрыт). Хуков и исполняемого кода в скиллах нет.
- **Гипотеза подтверждена:** battlecard, win/loss, позиционирование,
  ценообразование есть; ещё 6 скиллов про разведку рынка — нам не нужны.
- **Лучшая находка:** `competitive-win-loss-analysis` — две колонки
  «клиент сказал / продавец записал», счёт N из M с исключениями,
  «цена» как фольклор, no-decision отдельно, порог сегмента 4–5,
  хронология событий, смещения выборки, гипотезы с тестом.
- **Вторая:** `competitive-objection-response` — проверка посылки
  (verified/partly/not supported/unknown), 5 поз, 15-сек ответ,
  «что не утверждать».
- **Плюс:** `poc-rfp-plan` (классы требований, преимущество → событие
  на демо, no-go до старта) и общий `TRUST.md` (факт → интерпретация →
  импликация → действие).
- **Вердикт:** адаптировать, 11/18. Плагин не ставить: сторонний MCP
  получает контекст сделок, ≈10 КБ описаний в каждой сессии, конфликт
  триггеров с `odoo19-sales-*`.
- **Куда:** win/loss → `loss-pattern-analyzer`; возражения →
  блок в `defence-brief`; классы требований и no-go → `demo-build-plan`;
  сжатый TRUST → общий фрагмент `odoo19-sales-*`. Атрибуция MIT.
- **Ограничение:** наши тексты `defence-brief`/`loss-pattern-analyzer`
