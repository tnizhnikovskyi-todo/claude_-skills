- **Дата разбора:** 2026-11-02
- **Вердикт:** взять текст как отдельный скилл (с небольшой адаптацией под Odoo)

## Что делает

Аудит всего репо или папки: сначала карта (README, деплой, зависимости, точки
входа, тесты, ожидаемая нагрузка), затем трассировка основных потоков данных
до конца, глубина там, где ошибка дороже всего. Те же 6 категорий, что у
review, не больше 20 находок, ранжирование, `Verdict` и честный
`Not checked` по непрочитанным частям. Код не меняет.

## Какую слабость Claude закрывает

На «посмотри весь репо» Claude обычно идёт пофайлово и выдаёт плоский список
замечаний без приоритета. Здесь задан метод: карта → потоки → ранжирование →
«что чинить первым».

## Сравнение с тем, что есть

Встроенные `code-review` / `security-review` работают по диффу. Аудита
целого репозитория у нас нет.

## Оценка

| Критерий | Балл | Комментарий |
|---|---|---|
| Прирост | 2 | Закрывает пробел «аудит целого репо» |
| Частота | 1 | При приёме чужого проекта / перед go-live |
| Надёжность | 2 | Явная команда; на больших репо качество зависит от выбора, куда копать |
| Стоимость контекста | 3 | ~1.4 тыс. токенов, только при вызове |
| Безопасность | 3 | Только текст |
| Поддержка | 3 | Активно |
| **Итого** | **14** | |
