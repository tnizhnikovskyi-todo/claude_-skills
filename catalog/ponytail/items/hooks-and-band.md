# Хуки и band (плагинная часть ponytail)

- **Тип:** хуки Claude Code + UI-модуль (`hooks/band/register.tsx`)
- **Источник:** https://github.com/dietrichgebert/ponytail/tree/main/hooks
- **Версия / коммит:** v5.3.3, `96608e0`
- **Дата разбора:** 2026-11-02
- **Вердикт:** отклонить для нас

## Что делает

| Файл | Событие | Действие |
|---|---|---|
| `ponytail-activate.js` | SessionStart (startup/resume/clear/compact) | флаг в `~/.claude/.ponytail-active`; правила + карта кода в скрытый контекст; копирует `ponytail-statusline.sh` в `~/.claude/` и один раз инструктирует модель прописать statusLine в `settings.json` |
| `ponytail-map.js` | из activate | `git ls-files` + regex по 15 языкам → до 2000 символов «что уже есть» |
| `ponytail-subagent.js` | SubagentStart | правила в каждого субагента (фильтр по `PONYTAIL_SUBAGENT_MATCHER`) |
| `ponytail-mode-tracker.js` | UserPromptSubmit | переключение уровней, `/ponytail band [on/off/import]`; `import` запускает фоновый процесс, читающий `~/.claude/projects/*.jsonl` |
| `band/register.tsx` | UI-модуль | плашка стоимости/токенов/времени/reuse/тестов; CSV в `~/.config/ponytail/band/`, `board.html`; опц. POST на webhook (https, Bearer из keychain) |

## Безопасность

- Код прочитан выборочно (grep по сети/exec/записи файлов + ключевые функции).
  Сетевой вызов один: опциональный webhook, по умолчанию выключен, только https.
  `eval`/`new Function`/внешних CDN нет.
- Пишет в домашний каталог (`~/.claude`, `~/.config/ponytail`), копирует свой
  скрипт рядом с настройками Claude Code.
- Скрытая инструкция модели изменить `settings.json` пользователя: мелкий, но
  неприятный паттерн (модель меняет конфиг по указанию плагина, а не человека).
- `band import` читает все прошлые транскрипты сессий (локально).

## Оценка

| Критерий | Балл | Комментарий |
|---|---|---|
| Прирост | 1 | Карта кода полезна для «reuse first»; метрики band для человека, не для Claude |
| Частота | 3 | Каждая сессия |
| Надёжность | 2 | Много платформенных веток, обильные тесты |
| Стоимость контекста | 1 | Always-on в сессию и каждого субагента |
| Безопасность | 2 | Прозрачно, но запись в `~/.claude` и правка `settings.json` руками модели |
| Поддержка | 3 | Активно (но band сырой: много фиксов в последних коммитах) |
| **Итого** | **12** | |

## Почему отклонить

Band не работает в облачных сессиях, а мы работаем в них. Автоинъекция в
каждого субагента неявно меняет поведение наших процессных плагинов. Идею
карты кода можно повторить отдельно, если понадобится.
