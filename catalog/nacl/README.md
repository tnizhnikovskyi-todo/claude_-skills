## Что делает

Фреймворк поставки ПО «граф прежде документов»: бизнес-анализ (`nacl-ba-*`,
14), системный анализ (`nacl-sa-*`, 10), тимлид от плана до релиза
(`nacl-tl-*`, 26), утилиты, миграция Markdown → граф. Процессы, сущности,
роли, правила, UC, формы, требования, задачи и доказательства хранятся
узлами Neo4j: для каждого проекта отдельный Docker-контейнер. Скиллы читают
и пишут граф через `mcp__neo4j__*`, валидаторы — это Cypher-запросы.
Целевой стек — новые веб-приложения на TS (BE/FE, TDD, Docker-деплой).

Гипотеза «57 скиллов полного цикла BA → архитектура → код» подтверждается:
в корне 59 скиллов. Оговорка: без живого Neo4j почти ни один из них не
работает.

## Какую слабость Claude закрывает

- Дыры между слоями: шаг процесса без UC, правило без требования, роль без
  прав. Ловятся валидаторами L1–L13 и XL1–XL5.
- «Готово», которое ничем не подтверждено: строгий режим, где `UNVERIFIED`,
  `NOT_RUN`, `BLOCKED` и `FAILED` не дают закрыть задачу.
- Классы багов из реальных постмортемов автора: гонки и рестарты в
  очередях, недостижимый UI, фейковые «новые падения» тестов.

## Как устроен

- `SKILL.md` огромные: от 300 до 2909 строк (`nacl-sa-validate`,
  ~18 тыс. слов), `nacl-sa-uc` ~15 тыс. слов, `nacl-goal` с references
  ~25 тыс. слов. Оркестраторы (`*-full`, `nacl-tl-conductor`) запускают
  субагентов по фазам, после каждой фазы спрашивают «yes / redo / stop».
- Хуки (`plugin/hooks/hooks.json`, `SessionStart` на startup|resume):
  `graph-doctor.mjs --hook` (вне NaCl-проекта молчит; в remote-режиме сам
  перезапускает SSH-sidecar; если граф лежит, подмешивает контекст) и
  `check-coexistence.sh`. Монитор `graph-doctor --watch` работает
  постоянно (experimental).
- `nacl-init` поднимает Docker-стек Neo4j, скачивает с GitHub бинарь
  `neo4j-mcp` с проверкой чексуммы, пишет пароль в `graph-infra/.env`
  (0600) и правит `.mcp.json`. Всё это после явного подтверждения.
- Сеть: GitHub, Docker-образы, опционально Docmost и YouGile. Своего
  бэкенда нет, `NEO4J_TELEMETRY=false` выставлен явно (`PRIVACY.md`
  подтверждён grep-ом).
- Ничего не запускалось, только чтение.

  переехала в приватный репозиторий` (2026-08-05).
