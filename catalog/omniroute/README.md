# OmniRoute

- **Тип:** самохостируемый AI-шлюз (прокси/роутер LLM) + CLI + MCP-сервер + десктоп (Electron)
- **Источник:** https://github.com/cheaper-inference/OmniRoute (ранее `diegosouzapw/OmniRoute`)
- **Версия / коммит:** `omniroute` 3.8.53, `075d6e5` от 2026-11-02
- **Дата разбора:** 2026-11-02
- **Вердикт:** **отклонить** (безопасность 0). Взять можно только идеи, см. ниже.

## Что делает

Локальный сервер на `localhost:20128`, который даёт один OpenAI/Anthropic/Gemini-совместимый
эндпоинт `/v1` и раскидывает запросы по «380 провайдерам». Модель выбирается «комбо»:
цепочкой целей с одной из 20 стратегий (priority, round-robin, cost-optimized, quota-weighted,
auto с 16-факторным скорингом, fusion/pipeline с несколькими моделями). Если у провайдера
кончилась квота или он упал, запрос уходит дальше по каскаду
«Подписка → API-ключ → дешёвый → бесплатный». Плюс 12 движков сжатия промптов (RTK, Caveman,
LLMLingua-2 и др.), дашборд, MCP на 110 инструментов, A2A, память, guardrails.

Догадка из задачи подтверждается: это маршрутизация ради экономии. Но экономит он в первую
очередь за счёт **чужих подписок и бесплатных тарифов**, в том числе через неофициальный
доступ: OAuth-токены потребительских подписок (Claude Pro/Max, ChatGPT/Codex, Copilot,
Cursor, Antigravity, Kiro…), выдача себя за официальные CLI, подделка TLS-отпечатка браузера,
MITM-перехват трафика IDE и автоматизация веб-чатов через браузер.

## Какую слабость Claude закрывает

Никакую. Claude не становится умнее: шлюз меняет только то, **кто и за чьи деньги**
отвечает на запрос. Для Claude Code это значит одно из двух: либо подменить Claude
другой моделью (`omniroute run claude --model glm/glm-5.2`), либо гнать запросы Claude Code
через подписку в обход API, что нарушает условия Anthropic (см. риски).

## Как устроен

- Next.js + Node (TypeScript), SQLite, 101 runtime-зависимость, `postinstall`-скрипт,
  нативные модули (`wreq-js` на Rust для TLS-имитации, ONNX для LLMLingua).
- `open-sse/`: ядро прокси (executors на каждого провайдера, трансляторы форматов,
  сжатие, MCP-сервер). `src/lib/oauth/providers/`: 28 OAuth-флоу под подписки чужих
  продуктов. `src/mitm/`: MITM-сервер с корневым сертификатом и правкой `/etc/hosts` через sudo.
- Ключи и OAuth-токены лежат в SQLite; шифрование AES-256-GCM включается **только** если
  задан `STORAGE_ENCRYPTION_KEY`, по умолчанию в `.env.example` он пуст (passthrough).
- Сеть: напрямую к выбранным провайдерам; телеметрия по умолчанию выключена; есть
  опциональный облачный каталог `radar.omniroute.online`.
- Интеграция с Claude Code: (1) `ANTHROPIC_BASE_URL` на шлюз / `omniroute run claude`;
  (2) MCP `claude mcp add-server omniroute --type http --url …/api/mcp/stream`;
  (3) MITM-перехват `api.anthropic.com` (цель `claude-code`, opt-in);
  (4) провайдер `claude` через OAuth подписки, притворяющийся `claude-cli`.
- В `skills/` 47 `SKILL.md`, но все они про управление самим OmniRoute; без шлюза бесполезны.

## Оценка

| Критерий | Балл (0–3) | Комментарий |
|---|---|---|
| Прирост | 1 | Claude не умнее; только цена/доступность, и то через рискованные пути |
| Частота | 1 | Нам не нужен ежедневно: работаем через свой тариф Claude |
| Надёжность | 1 | Неофициальные интеграции ломаются при любом обновлении клиента; ~2,4 тыс. коммитов за октябрь |
| Стоимость контекста | 1 | Сам прокси контекст не ест, но MCP на 110 инструментов тяжёлый; сжатие меняет промпт |
| Безопасность | **0** | Имитация Claude Code CLI и других клиентов, MITM с корневым CA и sudo, обфускация client_id от сканеров, ключи без шифрования по умолчанию, данные уходят случайным провайдерам |
| Поддержка | 3 | Очень активен (~84 тыс. звёзд, 12 тыс. коммитов с февраля 2026), но ~50% коммитов от одного автора |
| **Итого** | **7 / 18** | Безопасность 0 → **отклонить** |

## Риски и заметки

1. **Условия Anthropic.** Провайдер `claude` берёт OAuth-токен подписки (scope
   `user:sessions:claude_code`, публичный client_id Claude Code) и шлёт запросы с
   `User-Agent: claude-cli/…`, подделанными заголовками Stainless SDK и «формой» запроса
   настоящего CLI (`open-sse/executors/claudeIdentity.ts`: «everything in this module exists
   to produce that shape»). Есть отдельные модули `claudeCodeFingerprint`, `claudeCodeObfuscation`.
   Использование подписочного токена вне Claude Code у Anthropic не разрешено, это прямой путь к
   блокировке рабочего аккаунта. Сам проект помечает это `riskNotice.oauth`.
2. **Других провайдеров то же касается:** Copilot, Codex/ChatGPT, Cursor, Antigravity, Kiro
   (Kiro и ещё 11 провайдеров в собственном каталоге помечены `tos: avoid`, 322 записи `caution`).
   Есть детектор «account banned» в ответах: авторы ожидают баны.
3. **MITM.** Ставит свой корневой сертификат, правит `/etc/hosts` через sudo (кеширует пароль
   на сессию), перехватывает `api.anthropic.com`, `api.githubcopilot.com`, `chatgpt.com`,
   `cloudcode-pa.googleapis.com` и др. На рабочей машине недопустимо.
4. **Данные.** При `auto` запрос с кодом/данными клиента уходит провайдеру, которого выбрал
   скоринг: часть бесплатных тарифов логирует или обучается на запросах (пример из их же
   документации: Logfare «every request is logged»). Для клиентских данных неприемлемо.
5. **Хранение секретов.** OAuth refresh-токены и API-ключи в SQLite; без
   `STORAGE_ENCRYPTION_KEY` в открытом виде. Встроенные чужие client_id/secret
   XOR-замаскированы, чтобы «не тригерить сканеры».
6. **Качество.** Fallback меняет модель посреди сессии (Opus → бесплатная GLM), а сжатие
   (Caveman, Aggressive, Ultra, LLMLingua) переписывает промпт и вывод инструментов. Claude Code
   рассчитан на конкретную модель и полный контекст; результат становится непредсказуемым.
   Сжатие по умолчанию `off`, но пресеты рекламируются как «daily coding».
7. **Поверхность атаки.** 101 зависимость, `postinstall`, нативные бинарники, веб-дашборд,
   remote mode, webhooks, A2A. Огромный и быстро меняющийся код, полный аудит нереален.
