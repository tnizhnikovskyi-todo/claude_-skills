# OmniRoute: сжатие промптов (RTK, Caveman и др.)

- **Тип:** подсистема шлюза (`open-sse/services/compression/`)
- **Источник:** https://github.com/cheaper-inference/OmniRoute
- **Версия / коммит:** 3.8.53, `075d6e5`
- **Дата разбора:** 2026-11-02
- **Вердикт:** отклонить как прокси; идею фильтрации вывода инструментов (RTK) можно изучить отдельно

## Что делает

Прозрачно переписывает каждый запрос по пути к провайдеру. 12 движков по порядку:
Session-Dedup, CCR (вынос больших блоков за маркеры), Lite, RTK (фильтрация вывода
shell/test/git), Responses Tool Output, Headroom (табличная упаковка JSON), Relevance
(отбор предложений под последний вопрос), Caveman (правила «пещерного» сокращения прозы),
Aggressive (суммаризация старых ходов), LLMLingua-2 (ONNX MobileBERT), Ultra, OmniGlyph
(контекст как картинка, экспериментально). Заявленная экономия 15–95 %; по умолчанию
`defaultMode: "off"` (`open-sse/services/compression/types.ts`).

## Какую слабость Claude закрывает

Длинный вывод инструментов (логи тестов, `git`, сборка) быстро съедает контекст Claude Code.

## Оценка

| Критерий | Балл | Комментарий |
|---|---|---|
| Прирост | 1 | Экономия реальная на логах, но ценой точности |
| Частота | 2 | Логи в агентной работе каждый день |
| Надёжность | 1 | Лоссовые движки (Relevance, Caveman, Aggressive, Ultra) меняют смысл; «код и JSON защищены» проверить без запуска нельзя |
| Стоимость контекста | 3 | Ровно это и экономит |
| Безопасность | 0 | Только внутри шлюза OmniRoute, отдельно не поставить |
| Поддержка | 3 | |

## Риски и заметки

- Сжатие, которое Claude не видит, хуже, чем сжатие, о котором он знает: модель не понимает,
  что строки выброшены, и делает выводы по урезанному логу.
- Идея RTK взята из отдельного проекта [rtk-ai/rtk](https://github.com/rtk-ai/rtk), Caveman из
  [JuliusBrussee/caveman](https://github.com/JuliusBrussee/caveman). Если интересна экономия
  контекста, разумнее разобрать их отдельно (как PreToolUse/PostToolUse-хук или CLI-обёртку
  с явной пометкой «вывод сокращён»), чем тянуть весь шлюз.
