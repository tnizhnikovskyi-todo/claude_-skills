# OmniRoute: шлюз и комбо-роутинг

- **Тип:** локальный LLM-шлюз (OpenAI/Anthropic/Gemini/Responses-совместимый `/v1`)
- **Источник:** https://github.com/cheaper-inference/OmniRoute
- **Версия / коммит:** 3.8.53, `075d6e5`
- **Дата разбора:** 2026-11-02
- **Вердикт:** отклонить (наследует безопасность 0 всего продукта); идея каскада полезна как образец

## Что делает

Принимает запрос на `localhost:20128/v1`, переводит формат (Anthropic ⇄ OpenAI ⇄ Gemini ⇄
Responses) и отправляет его по «комбо» — упорядоченной цепочке целей. Виртуальные комбо
`auto`, `auto/coding`, `auto/fast`, `auto/cheap`, `auto/subscription`, `auto/thrifty`,
`auto/smart`, `auto/chaos` строятся из подключённых провайдеров со скорингом по 16 факторам
(здоровье, квота, цена, задержка, «пригодность к задаче», качество…). 20 стратегий, в том
числе `cache-optimized` (привязывать префикс к одному аккаунту ради prompt cache),
`fusion` (панель моделей + судья) и `pipeline`.

Устойчивость в три слоя: circuit breaker на провайдера, cooldown на ключ, блокировка модели.

## Как выбирается модель

- Явно: `provider/model` в поле `model`.
- Через комбо: стратегия выбирает цель; при 408/5xx/429 и исчерпании квоты переход дальше.
- `auto*`: скоринг; провайдеры с `tos: avoid` по умолчанию исключены (`excludeTosAvoid`),
  `caution` (322 записи каталога) не исключены.

## Что можно взять как идею

- `auto/subscription` с «fail closed»: никогда не переходить на платный fallback молча.
- `cache-optimized`: держать один префикс на одном аккаунте, чтобы не терять prompt cache.
- Явное разделение «подписка → API → дешёвый → бесплатный» полезно как ментальная модель,
  но для рабочих данных допустимы только первые два уровня у проверенных провайдеров.

Если нам когда-нибудь понадобится роутинг между моделями, разумнее смотреть на зрелые
шлюзы только с API-ключами (LiteLLM и т.п.) или облачные (Bedrock/Vertex), а не на этот.

## Оценка

| Критерий | Балл | Комментарий |
|---|---|---|
| Прирост | 1 | Только цена/отказоустойчивость, не качество |
| Частота | 1 | |
| Надёжность | 1 | Огромная поверхность, каждый релиз меняет поведение |
| Стоимость контекста | 2 | Прокси не тратит контекст Claude |
| Безопасность | 0 | Неотделим от подписочного OAuth/MITM и «бесплатных» провайдеров неясного происхождения |

## Риски и заметки

- Тихая смена модели посреди сессии Claude Code: агентный цикл рассчитан на одну модель,
  смена на слабую ломает tool use и качество, и это не видно пользователю.
- `auto/chaos` и `fusion` отправляют один и тот же запрос сразу пяти провайдерам: данные
  утекают в пять мест вместо одного.
