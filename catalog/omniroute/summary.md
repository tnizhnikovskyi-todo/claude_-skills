# omniroute — кратко для главной сессии

- **Что это:** самохостируемый AI-шлюз (Next.js/Node, SQLite, MIT) на `localhost:20128/v1`,
  «380 провайдеров», 20 стратегий роутинга, каскад «подписка → API → дешёвый → бесплатный»,
  12 движков сжатия промптов, MCP на 110 инструментов, CLI, Electron. Очень популярен
  (~84 тыс. звёзд) и гиперактивен (12 тыс. коммитов с февраля 2026, ~половина от одного автора).
- **Как экономит:** не только API-ключи и free tiers, но и **OAuth-токены потребительских
  подписок** (Claude Pro/Max, Codex/ChatGPT, Copilot, Cursor, Antigravity, Kiro…) с имитацией
  официальных клиентов: подделка `claude-cli` UA и заголовков SDK, TLS-отпечаток Chrome,
  XOR-маскировка чужих client_id от сканеров, MITM с корневым CA и `/etc/hosts` через sudo,
  веб-чаты через headless-браузер, детектор банов аккаунтов.
- **Риски:** нарушение условий Anthropic и других провайдеров → бан рабочих аккаунтов;
  запросы с данными клиента уходят случайному провайдеру (часть логирует/обучается);
  ключи и токены в SQLite без шифрования по умолчанию; тихая смена модели и лоссовое сжатие
  ухудшают работу Claude Code.
- **Для Claude:** умнее не делает. Варианты: заменить Claude другой моделью или гнать
  подписку через сторонний прокси. Оба нам не подходят.
- **Вердикт:** **отклонить** (7/18, безопасность 0). Для рабочих/клиентских данных неприемлемо.
- **Что взять:** только идеи — `auto/subscription` (fail closed, без молчаливого платного
  fallback), `cache-optimized` роутинг. Сжатие вывода инструментов стоит смотреть в
  первоисточниках (`rtk-ai/rtk`, `JuliusBrussee/caveman`) как хук, а не через шлюз.
- **Пересечение с freellmapi:** та же ниша, но OmniRoute строго рискованнее (у freellmapi
  только API-ключи). Детали в `notes.md`.
