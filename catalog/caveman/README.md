# Caveman

- **Тип:** скилл + плагин Claude Code (хуки) + CLI/локальный прокси/движок сжатия + облачный сервис
- **Источник:** https://github.com/JuliusBrussee/caveman
- **Версия / коммит:** v4.0.1 (плагин), `main` @ `2e068f73` от 2026-11-01
- **Дата разбора:** 2026-11-02
- **Вердикт:** **адаптировать** (правила стиля ответа и контракт сжатого вывода субагентов); рантайм (прокси, Auto, Cloud) **отклонить**

## Что делает

Начинался в апреле 2026 как шуточный скилл «говори как пещерный человек», чтобы
модель отвечала короче. К версии 4.0 вырос в «шесть камней»: (1) **Say less**:
скилл стиля ответа `/caveman` (+ `/ultracave`, `/megacave` на 文言文);
(2) **Read less**: локальный прокси, который сжимает логи, JSON, CSV, YAML, вывод
тестов перед отправкой модели, с сохранением оригинала и «ручкой» для
восстановления; (3) **Auto**: облачный роутер модели и effort под каждый запрос;
(4) **Blocks**: библиотека переиспользуемых скриптов для code mode;
(5) поиск «утечек токенов» и прогрев кэша; (6) **Browse**: сжатые веб-страницы.
Плюс скиллы-утилиты: `caveman-commit`, `caveman-review`, `caveman-compress`
(сжатие `CLAUDE.md`), `cavecrew` (субагенты со сжатым отчётом).

## Какую слабость Claude закрывает

- Многословие ответов: преамбулы, пересказ, «надеюсь, помог», болтовня между
  вызовами инструментов.
- Раздувание основного контекста: длинный вывод инструментов и прозаичные отчёты
  субагентов.
- Раздутые memory-файлы (`CLAUDE.md`), которые читаются в каждой сессии.

## Что именно сжимается

| Что | Чем | Механизм | Лоссовое? |
|---|---|---|---|
| Ответы модели (output) | скилл `caveman` / `ultracave` / `megacave` | правила стиля, инжектятся хуком `SessionStart` и `SubagentStart` | да, но код/команды/пути/ошибки дословно |
| Отчёты субагентов в основной контекст | `cavecrew-*` агенты | контракт вывода `path:line`, ultracave-голос | да |
| Вывод инструментов, файлы, логи (input) | Engine + локальный прокси (`ANTHROPIC_BASE_URL` → loopback) | детектор формата + компрессор под тип, оригинал в CCR | да, с восстановлением |
| Вывод shell-команд | `caveman shrink -- <cmd>` | «RTK parity», байт-точное восстановление | да, с восстановлением |
| Каталоги MCP-инструментов | `caveman-shrink` | вырезает примеры, сокращает описания | да |
| Memory-файлы | `/caveman-compress` | переписывает файл через модель, бэкап оригинала | да |
| **Промпт пользователя** | — | **не трогается намеренно** (по данным Adobe, это ухудшает ответы) | — |

## Как устроен

**Скилл `caveman`** (`skills/caveman/SKILL.md`, ~4.7 КБ, ~1160 токенов): 9 правил
(ответ первым; без церемоний; короткие слова без самодельных сокращений; артикли
можно, отрицания и числа нельзя; одна мысль на предложение по ASD-STE100, до
20 слов; payload дословно; между вызовами инструментов молчать; язык пользователя
не менять; «не играть в пещерного человека»), 7 случаев, когда правила
отключаются (предупреждения о безопасности, необратимые действия, растерянный
пользователь, всё, что сохраняется вне чата: код, коммиты, доки, PR), и
pre-send чек-лист. Это хорошо написанный стилевой гайд, а не «ломаная грамматика».

**Плагин Claude Code** (`.claude-plugin/plugin.json`): 4 хука на Node.js:
`SessionStart` и `SubagentStart` (`caveman-activate.js` — выбирает режим и
инжектит правила), `UserPromptSubmit` (`caveman-mode-tracker.js` — ловит
`/caveman`, `stop caveman`, запускает stats), `SessionEnd` (`caveman-stats.js`).
~3200 строк JS, сеть в хуках не используется (проверено grep: нет http/fetch,
единственный `execFileSync` запускает локальный stats-скрипт).

**Рантайм** (Go + TypeScript, ~1800 файлов): CLI `@caveman-ai/cli` переписывает
`ANTHROPIC_BASE_URL` агента на локальный прокси; Engine с десятками
компрессоров; CCR-хранилище оригиналов; MCP-сервер для восстановления;
SQLite со статистикой; Supabase-функции облака. **CLI шлёт телеметрию по
умолчанию** (команды, счётчики токенов, install ID, OS, IP) на Supabase;
выключается `caveman telemetry off` / `DO_NOT_TRACK=1`. **Auto** (после логина)
отправляет в Caveman Cloud последний запрос с вложениями (`CLAUDE.md`, память,
файлы) и хвост ответа; на Free-плане их могут хранить.

Подробно: [items/caveman-skill.md](items/caveman-skill.md),
[items/runtime.md](items/runtime.md), [items/cavecrew.md](items/cavecrew.md).

## Сколько экономит и чем подтверждено

Автор отдельно ведёт [`docs/HONEST-NUMBERS.md`](https://github.com/JuliusBrussee/caveman/blob/main/docs/HONEST-NUMBERS.md) — редкая честность:

| Что | Цифра | Качество доказательства |
|---|---|---|
| Скилл vs контроль «Answer concisely.» (output) | caveman **−3%**, ultracave **−35%**, megacave −9% по медиане | n=10, один прогон, правила 3.1.0, не перепроверено |
| Скилл vs без инструкции (output) | 6983 → 4119 токенов | те же 10 вопросов; но главный выигрыш даёт уже «be concise» |
| Входная стоимость правил | ~1160 токенов на сессию + на каждого субагента | не измерена в биллинге |
| LemonCrow (внешний, 300 прогонов, opus-4-8) | output **−44%**, общая стоимость **+0.06%** | сырые данные опубликованы |
| edubraqd (662 сессии Claude Code) | output = 0.3% всех токенов, эффект на счёт ±0.2% | внешний отзыв |
| JetBrains (86 задач, A/B) | output −8.5%, потерь качества не найдено (p=0.82) | блог, не проверял |
| Read less (прокси), 6 типов файлов | −33.2% input на сессию, 18/18 ответов верны | свой бенчмарк, старый движок, синтетика «одна запись в 61–72 КБ шума»; HTML +9.9% хуже |
| Auto vs Opus xhigh | −54% стоимости, 43.7% vs 44.3% решённых | прогон наполовину, разница в пределах шума (±7) |
| `/caveman-compress` | −33% по 5 memory-файлам | только размер, без проверки эквивалентности |

**Главный вывод:** стилевой скилл почти не экономит деньги в агентной работе:
счёт складывается из input и кэш-чтений, а output — доли процента. Его польза —
читаемость и скорость чтения, а не токены. Реальную экономию даёт сжатие
input (прокси), но это совсем другой класс риска.

## Влияние на качество и понятность

- Правила явно защищают payload (код, команды, ошибки, числа, отрицания) и
  выключают сжатие там, где оно опасно. Это сделано лучше, чем в большинстве
  «be concise»-инструкций.
- `ultracave`/`megacave` для человека читать тяжело; `megacave` (文言文) для
  русскоязычной команды бесполезен.
- Правило 8 сохраняет язык пользователя, поэтому с русским работает, но все
  замеры на английском (tiktoken o200k), для русского экономия не измерена.
- Fidelity-eval (`evals/score_fidelity.py`) есть, но проверенных результатов
  нет: автор сам не публикует claim о качестве.

## Оценка

Оцениваем то, что реально можно взять: скилл + плагин с хуками. Рантайм
оценён отдельно в [items/runtime.md](items/runtime.md).

| Критерий | Балл (0–3) | Комментарий |
|---|---|---|
| Прирост | 1 | Против «отвечай кратко» +3% у `caveman`, +35% у `ultracave`; польза в читаемости, а не в деньгах |
| Частота | 2 | Применимо в каждой сессии, но для нашей работы (документы для людей, русский) уместно не везде |
| Надёжность | 2 | Хуки зрелые (сотни закрытых issue), но правила ~1.1k токенов, модель может «дрейфовать» |
| Стоимость контекста | 1 | ~1160 токенов в каждую сессию и каждого субагента, всегда |
| Безопасность | 2 | Скилл и хуки прозрачны, без сети. CLI: телеметрия по умолчанию, подмена `ANTHROPIC_BASE_URL` |
| Поддержка | 3 | Очень активен (1040 коммитов за октябрь 2026), Apache-2.0, честные замеры |
| **Итого** | **11/18** | |

## Риски и заметки

- Установка «одной командой» (`npx @caveman-ai/cli`) ставит гораздо больше, чем
  скилл: прокси, телеметрию, правку настроек агентов. Если брать, то только
  `skills/caveman/SKILL.md` или плагин, не CLI.
- Скилл в `when to break` уже исключает всё, что пишется вне чата (код, доки,
  коммиты) — важно для нашего репозитория, где почти весь результат это файлы.
- Внешние ссылки (Adobe arXiv 2606.24083, JetBrains, Elastic) не проверены.
- Сравнение с `rtk`: см. [notes.md](notes.md#пересечения-с-rtk).
