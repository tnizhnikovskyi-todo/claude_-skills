# Caveman runtime: CLI, прокси, Engine, Auto, Blocks, Browse

- **Тип:** CLI (`@caveman-ai/cli`, TypeScript) + локальный прокси и Engine (Go) + облако
- **Источник:** `packages/cli/`, `proxy/`, `engine/`, `shrink/`, `browse/`, `mem/`, `mcp/`
- **Вердикт:** **отклонить** как установку; идеи отметить

## Что делает

- `caveman claude` запускает агента с `ANTHROPIC_BASE_URL`, указывающим на
  локальный прокси. Прокси пропускает запросы через Engine: тот определяет тип
  содержимого (лог, JSON, CSV, YAML, вывод тестов, код, HTML/axtree) и сжимает.
- Каждое лоссовое сжатие: оригинал в CCR (Caveman Context Recovery) на диске,
  модели — сжатая версия + «ручка» для восстановления через MCP-инструмент.
  При сбое парсинга оригинал проходит без изменений.
- `caveman shrink -- <cmd>`: сжатие вывода команды (в документации прямо
  «RTK parity»).
- `caveman-shrink`: сжатие каталогов MCP-инструментов.
- `caveman browse <url>`: сжатая страница (121 токен вместо 15 704 на таблице
  из 200 строк, на маленьких формах проигрывает в 2.3 раза).
- **Auto**: облачный роутинг модели/effort. Требует логина; отправляет в
  Caveman Cloud последний запрос с вложениями.
- **Blocks**: переиспользуемые скрипты (`test-summary`, `json-peek`, …),
  отдельный репозиторий `caveman-ai/blocks`, pre-release.
- Прогрев prompt cache во время паузы пользователя.

## Почему отклонить

1. **Подмена `ANTHROPIC_BASE_URL`** на локальный прокси: весь трафик, включая
   код и секреты в контексте, идёт через стороннюю программу. В нашей облачной
   среде Claude Code это ещё и не наш контроль над сетью.
2. **Телеметрия CLI по умолчанию** (Supabase, с IP).
3. **Auto** отправляет содержимое в сторонний облачный сервис.
4. Огромная поверхность (~1800 файлов, бинарники скачиваются при запуске).
5. Замер −33% input синтетический (одна нужная запись в 60–70 КБ шума); на
   HTML хуже на 9.9%.

## Что интересно как идея

- Схема «сжать, но сохранить оригинал и дать ручку восстановления» — правильная
  защита от потери информации при сжатии вывода инструментов.
- Сжатие делается по типу содержимого, а не одной эвристикой.
- Честная бухгалтерия: каждая цифра помечена `measured / inferred / verified`.

## Оценка

| Критерий | Балл | Комментарий |
|---|---|---|
| Прирост | 2 | Реальная экономия input на шумных логах/данных |
| Частота | 1 | У нас мало сессий с гигантскими логами |
| Надёжность | 1 | Активно меняется (1000+ коммитов в месяц), бенчмарки частичные |
| Стоимость контекста | 3 | Сам по себе экономит контекст |
| Безопасность | 1 | Прокси на весь трафик, телеметрия по умолчанию, облако |
| Поддержка | 3 | Очень активно |
| **Итого** | **11/18** | при безопасности 1 — не ставить |
