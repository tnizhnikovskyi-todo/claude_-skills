# caveman / ultracave / megacave (скилл стиля ответа)

- **Тип:** скилл (+ хуки плагина для автоактивации)
- **Источник:** `skills/caveman/SKILL.md`, `skills/ultracave/SKILL.md`, `skills/megacave/SKILL.md`
- **Версия:** v4.0.1, коммит `2e068f73`
- **Вердикт:** **адаптировать** (взять правила, без хуков и без `megacave`)

## Что делает

Делает ответы модели короче: сначала ответ, без церемоний, одна мысль на
предложение, payload (код, пути, ошибки, числа, отрицания) дословно. Остаётся
включённым до «stop caveman». Три уровня: `caveman` (умеренно), `ultracave`
(фрагменты; `disable-model-invocation: true`, только вручную), `megacave`
(классический китайский, максимум сжатия).

## Сильные стороны текста правил

1. **Явный приоритет ясности над сжатием.** «A dropped negation costs more than
   every token saved.» Запрет выкидывать not/never/no/only/except, числа и единицы.
2. **ASD-STE100** как нижняя планка: 20 слов, активный залог, один термин на
   одну вещь, местоимение только с очевидным референтом.
3. **Нет самодельным сокращениям** (cfg, impl, fn): «те же токены, читать хуже».
4. **Bounded status для tool runs:** одна строка перед многошаговой работой,
   одна на смену фазы, одна с результатом.
5. **Когда выключаться:** безопасность, необратимые действия, порядок шагов,
   растерянный пользователь, вопросы пользователю, всё, что сохраняется вне чата.
6. **Pre-send check** из 4 пунктов.
7. **Анти-театр:** запрет на «me think», префиксы, «caveman mode on».

## Слабые стороны

- ~1160 токенов правил грузятся всегда, если активировать хуком.
- Измеренный выигрыш над простым «Answer concisely.» всего 3% (n=10).
- Для `ultracave` 35%, но читаемость падает.
- Никаких замеров на русском.

## Что взять себе

Короткий (≤30 строк) русскоязычный блок стиля для `CLAUDE.md` или output style:
правила 1, 2, 4, 6, 7, 8 + «когда выключаться» + pre-send check. Без хуков,
без режимов, без пещерной стилизации. Ожидаемый эффект: читаемость ответов в
чате, а не экономия денег.
