# Caveman: итог для главной сессии

- **Что это:** `JuliusBrussee/caveman` (Apache-2.0, v4.0.1, очень активен:
  1040 коммитов в октябре 2026). Начинался как скилл «отвечай как пещерный
  человек», теперь это продукт: скилл стиля + плагин с хуками + CLI с
  локальным прокси, сжимающим input + облачный роутер Auto + Caveman Cloud.
- **Что сжимается:** ответы модели (скилл), отчёты субагентов (`cavecrew`),
  вывод инструментов/логи/JSON (прокси, оригинал сохраняется), memory-файлы
  (`/caveman-compress`). Промпт пользователя не трогается намеренно.
- **Экономия честно:** против «Answer concisely.» скилл даёт −3% output
  (`ultracave` −35%), n=10. Внешний A/B на 300 прогонов: output −44%, общая
  стоимость +0.06%. Output в агентных сессиях ≈ 0.3% токенов, так что на счёт
  стиль почти не влияет. Прокси: −33% input на синтетике, HTML хуже.
- **Лучшие находки:** (1) текст правил `caveman`: ответ первым, ASD-STE100,
  payload дословно, отрицания и числа неприкосновенны, явный список «когда
  выключаться»; (2) идея `cavecrew`: субагенты возвращают `path:line`-таблицы,
  экономя основной контекст; (3) `HONEST-NUMBERS.md` как образец честных замеров.
- **Вердикт:** **адаптировать.** Скилл+плагин 11/18, `cavecrew` 15/18.
  Рантайм (прокси через `ANTHROPIC_BASE_URL`, телеметрия по умолчанию,
  облачный Auto) **отклонить**, безопасность 1.
- **Что взять:** русский блок стиля на ~30 строк в `CLAUDE.md`/output style
  (без хуков и стилизации) и требование сжатого формата отчёта в промптах для
  субагентов. Оба проверить A/B.
- **С rtk:** `caveman shrink` заявлен как «RTK parity»; для сжатия вывода
  команд первоисточник rtk, caveman ценен стилем ответа. Детали в `notes.md`.
