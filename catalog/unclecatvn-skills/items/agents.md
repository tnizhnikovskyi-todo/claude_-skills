# Агенты odoo-code-review и odoo-code-tracer

- **Тип:** субагенты Claude Code
- **Источник:** https://github.com/unclecatvn/agent-skills/tree/82ebbae/agents
- **Версия / коммит:** 1.0.20, `82ebbae`
- **Дата разбора:** 2026-11-03
- **Вердикт:** отдельные правила взять в наши ревью, агентов не ставить

## Что делает

`odoo-code-review` (274 строки): определяет версию (6 шагов, при
расхождении источников останавливается), находит пак, читает
`api-highlights.md` и нужные гайды, проверяет зависимости диффа через
`odoo_trace` и выдаёт отчёт с весами критериев. `odoo-code-tracer`
(340 строк): трассирует поток вызовов с переопределениями по тем же правилам.

## Сравнение с нашим

Наши `odoo19-mvp-build:pr-review` и `security-review` (с переносом Strix
и ponytail, см. `proposals/odoo19-mvp-build/`) уже дают формат находок и
калибровку. Нового у агентов:

- правило «версия неизвестна — стоп и вопрос, никакой версии по умолчанию»
  с порядком источников (аргумент → `CLAUDE.md` → `release.py` → манифест);
- проверка «def, на который опирается дифф, из модуля вне `depends`» как
  блокирующая находка;
- `sudo()`: суффикс `_sudo`, не возвращать из публичного метода, у каждого
  обоснование.

Пути к пакам захардкожены под их плагин (`~/.claude/plugins/cache/unclecat-agent-skills/…`).
