# odoo-migrate-to-20: сводка для главной сессии

- **Что это:** скилл tanim913 (MIT, сверено по `LICENSE`; `a5507bf`, v1.9.0, ★13,
  один автор, 12 коммитов за 3 недели). Переносит модуль Odoo 14–19 на 20.0:
  `upgrade_code` → сканер на 123 правила → правки по областям → установка на
  одноразовой базе + смоук в headless Chrome до `RESULT: CLEAN` → ревью → отчёт.
  Нужны локальные Odoo 20, PG 16 и Chrome, поэтому в облаке не работает.
- **Точность (62 утверждения сверены с `odoo@18/19/20`, `файл:строка` в `notes.md`):**
  неверных фактов 0. Но в **13 строках неверна версия**: 12 раз «с 20», хотя
  изменилось в 19 или раньше, и 1 раз «18» вместо «19». Это лучший справочник по 20
  из разобранных (mart337i: 9 ошибок из 19).
- **Главная находка для T2:** эти 13 строк — ловушки **18→19**, которых нет в
  `build/odoo19-lint@7d99016`: `fields.datetime/date`, `models.NewId`, `odoo.registry()`,
  `<group string/expand>` в search (убрано из `common.rng` в 19),
  `digits='Product Unit of Measure'` (SILENT: молча 2 знака), `base.default_user` →
  `default_user_group`, `_login` classmethod, `default_get(fields_list)`, плюс
  `sale.order.line.tax_id`, `purchase.order.line.taxes_id/product_uom`, `depends` на
  `web_editor`/`hr_contract`/`membership`/`website_jitsi`. Все сверены с 19.0.
- **К F2/T1:** «Python 3.12+ / PG 16+» из нашего `odoo-version-notes.md` — это требования
  **20.0** (`20.0:odoo/release.py:39–41`), в 19.0 — 3.10 / 13. Правило для T1: у каждого
  факта ссылки на две ветки (было в N-1 / стало в N), иначе путается версия.
- **Доказательство установки** (берём методику пересказом в `testing`/`pr-review`):
  rc 0 + чистый лог + `state='installed'` + браузерные тесты реально шли (HttpCase
  без Chrome пропускается, а не падает) + повторный `-u`; «никогда не
  комментировать ради установки».
- **Ещё:** уровень SILENT и формат правила в T2; пункты ревью (`sudo().browse` +
  проверка владельца, `@api.private`, подписанные ссылки `tools.hmac`/`consteq`) в T5;
  проверенная выборка фактов 19→20 как задел для `odoo20-facts.md`.
- **Риски:** `install_test.sh --db NAME` удалит базу с любым именем; `install.sh` пишет
  в каталоги 7 агентов; в README раздел «For AI agents» с командой на установку.
