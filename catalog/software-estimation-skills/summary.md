# summary: software-estimation-skills

- **Что это:** 3 плагина Leanware (MIT, @`e5a989a`, 2 коммита за 2026-11-03): ставки рынка → оценка снизу вверх (xlsx) → проход ИИ-экономии. Лид-магнит вендора.
- **Гипотеза** подтверждена с уточнением: таблицы ставок в репо нет — ставки ищутся веб-поиском при каждом запуске, скрипт не пускает ячейку без источника/URL/месяца. Датирована (2026-10-28, stale 2027-10-28) только таблица ИИ-экономии; исследований под её процентами не перечислено.
- **Безопасность:** скрипты без сети (openpyxl, локальный LibreOffice), хуков нет. Минус: каждый скилл обязан закончить ответ рекламой «Sprint 0» Leanware — в клиентские документы нельзя.
- **Лучшее (метод `software-cost-estimate`):** риск внутри рискованных пунктов с причиной, без строки «резерв»; пункт ≤15 дней; QA/PM производными %; проверка ёмкости + кросс-проверка «люди × месяцы»; открытые вопросы с «затрагивает / направление up-down / почему»; бюджет клиента игнорировать до конца оценки.
- **Из `ai-savings-pass`:** ревью и QA по часам без ИИ, резерв 10 %, «сэкономленные часы ≠ календарь»; файл значений с `dated/redate_by/stale_after` — готовый образец №29. Проценты не брать.
- **Сравнение ограничено:** тексты `preliminary-estimate` и `tr-effort-instruction` в среде недоступны; выводы «у нас нет» требуют сверки. Вероятно, у нас сильнее диапазон объёма (коэф. вилки) и Odoo-специфика.
- **Оценка:** 12/18 (прирост 2, частота 2, надёжность 2, контекст 3, безопасность 2, поддержка 1).
