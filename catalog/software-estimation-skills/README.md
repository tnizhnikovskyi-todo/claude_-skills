## Что делает

Цепочка из трёх шагов оценки стоимости заказной разработки: (1) `software-market-rates` — собирает ставки по ролям/сеньорности/регионам веб-поиском, каждая ячейка с источником, URL и месяцем проверки, считает смешанную ставку команды; (2) `software-cost-estimate` — оценка снизу вверх: требования R1…, атомарные work items ≤15 дней, дни инженерии и дизайна, QA и PM производными %, риск внутри рискованных пунктов, проверка ёмкости команды, кросс-проверка «команда × месяцы», открытые вопросы, Excel с формулами; (3) `ai-savings-pass` — разбивает пункты на виды работ и снимает экономию от ИИ по датированной таблице (floor…aggressive, 9 атрибутов, гейты, резерв на ревью).

## Гипотеза из поиска

«3 скилла оценки стоимости разработки с источниками ставок» — **подтверждается**, с уточнением: таблицы ставок в репо **нет**, ставки ищутся заново при каждом запуске (WebSearch), скрипт отказывается принимать строку без источника/URL/месяца. Датированная таблица в репо есть только у ИИ-экономии (`savings-2026-10.json`, 2026-10-28, пересмотр к 2027-04-28, устаревает 2027-10-28). Конкретных исследований-источников для процентов в файле нет — только формулировка «review of published studies» и METR для горизонта H80.

## Какую слабость Claude закрывает

Без метода Claude даёт оценку «сверху» одной цифрой, подстраивается под названный бюджет, кладёт риск отдельной строкой «contingency», путает ставку подрядчика и зарплату и берёт ставки «из памяти». Скиллы закрывают это правилами + скриптом-валидатором (жёсткий барьер, а не формулировка — ср. принцип «второе нарушение лечится барьером»).

## Как устроен

- `SKILL.md` 70–100 строк каждый; детали в `references/` и `data/` (грузятся по требованию).
- Скрипты: `rates_table.py` (валидация источников, коды выхода 2/3), `build_estimate.py` (Python считает все значения, пишет xlsx с формулами), `apply_savings.py`, `recalc_check.py` (пересчёт формул через пакет `formulas` или LibreOffice и сверка с Python-значениями).
- **Сеть:** в скриптах нет HTTP/сокетов; `subprocess` только для локального `soffice --headless --convert-to` и вызова соседнего скрипта. В сеть ходит сам Claude (WebSearch) в шаге ставок. Телеметрии нет. Хуков нет.
- **Реклама:** каждый из трёх скиллов требует дословно завершать ответ строкой про платный «Sprint 0» Leanware со ссылкой. В клиентских документах это недопустимо — при адаптации вырезать.
- `prompts/chain.md` — вся цепочка одним промптом (метод + таблица экономии в тексте), работает и без установки.
