**Что проверили по безопасности.**
- Импорты только из stdlib: argparse, json, math, os, random, re, sys, time.
- Нет subprocess, os.system, eval/exec, urllib/socket/http, shutil/rmtree/unlink.
- Запись файлов только в `.arena/<run>/` и `.arena/LATEST`; `--dir` позволяет указать другой каталог,
  но это аргумент оркестратора.
- `decide()`: вердикт судьи пересчитывается по весам; если выбор судьи расходится с его же баллами,
  побеждают баллы. Fatal-правило применяется кодом. Защита от «болтливого» судьи разумная.
- Субагенты `general-purpose` имеют все инструменты; ограничение «пиши только в .arena» только в тексте
  брифа. Брифы участников разрешают читать файлы проекта, на которые указывает задача.

**Что НЕ делали.** Не запускали `bracket.py` и тесты (правило CLAUDE.md: чужой код без разрешения
пользователя не запускаем). Цифры вызовов взяты из README и сверены с формулой (N + 5 × матчей):
100 + 5 × (50+25+12+6+3+2+1) = 100 + 495 = 595. Совпадает.

**Оценка токенов.** Сделана вручную, не замером: 30–80 тыс. входных токенов на вызов субагента
(системный промпт Claude Code + инструменты + бриф + 1–2 решения + ходы). 595 вызовов дают ~20–45 млн.
Нужен замер на `--agents 8`, если пользователь разрешит прогон.
