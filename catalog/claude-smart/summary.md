# claude-smart: итог для главной сессии

- **Что это.** Плагин ReflexioAI (Apache-2.0, сверено по `LICENSE`;
  @ `6cff4fe`, движок reflexio @ `49659eb`; очень активен). 7 событий
  хуков пишут каждый промпт и вывод каждого инструмента в буфер; локальный
  бэкенд reflexio (`:8071`) через `claude -p` извлекает правила в SQLite
  (`~/.reflexio`) и подмешивает их индекс (до 8000 символов) перед каждым
  промптом и Edit/Write/Bash. «Скиллы» — записи в базе, не `SKILL.md`.
- **Поправка ловится** не хуком-регэкспом, а LLM-гейтом на сервере по
  всему ходу сессии; явно — `/claude-smart:learn`.
- **Минусы.** В облаке не работает (README прямо). Промпты не маскируются,
  вывод MCP (Odoo, Gmail) пишется, маскировка только `KEY=value`.
  Always-on цена + фоновые `claude -p`. Установщик `curl`→`sh` (uv), Node,
  npm, два демона, дашборд без аутентификации. Правила меняются сами, без
  человека, A/B и барьеров. Managed-режим отправляет всё на reflexio.ai.
- **Лучшее** — промпты извлечения reflexio: (1) триггер = предшествующая
  ситуация, тест точки решения, правило AND/OR, тест тавтологии;
  (2) расширенные сигналы поправки (частичная поставка, застой при данном
  разрешении, непроверенное утверждение, пропущенная параллельная
  поверхность); (3) не писать запрет на ошибку, которой не было;
  (4) гейт «поправка ИЛИ неочевидный путь успеха»; (5) формат пути успеха
  Применимо/Делать/Ограничения/Избегать/Проверка.
