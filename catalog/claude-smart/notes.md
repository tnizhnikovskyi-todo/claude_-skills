**Как ловится поправка.** Не скиллом и не по триггеру: хуки пишут
КАЖДЫЙ промпт пользователя, КАЖДЫЙ вызов инструмента (вход + вывод до
4096 символов) и ответ в JSONL-буфер `~/.claude-smart/sessions/`.
На `Stop` буфер публикуется в локальный бэкенд reflexio
(`localhost:8071`). Там LLM-гейт `playbook_should_generate` решает,
есть ли сигнал (поправка/трение или «путь успеха»), затем экстрактор
пишет правило `{trigger, content, rationale}` с цитатами-доказательствами.
Явная команда `/claude-smart:learn [заметка]` форсирует извлечение.
Утверждение ARCHITECTURE.md про «эвристическую пометку поправок» в
`UserPromptSubmit` в коде плагина не нашли (`user_prompt.py` только
буферизует и ищет); распознавание фактически делает LLM-гейт на сервере.
Отметка: «не нашёл» здесь значит только «не нашёл в плагине» (№28).

**Куда пишется.** SQLite reflexio в `~/.reflexio/`, буферы и `.env` в
`~/.claude-smart/`. Три коллекции: preferences (по проекту = basename
git-toplevel), project skills, shared skills (общие для всех проектов).
Это НЕ `SKILL.md`-файлы: «скилл» тут — запись в базе, которая
подмешивается в контекст как строка индекса `[cs:ID]` при совпадении
поиска. Полный текст грузится командой `cli.sh load`.

**Как избегает мусора.** В промптах reflexio: гейт «две дорожки»
(поправка / неочевидный путь успеха из ≥3 действий), отказ от петель
инфраструктурных ошибок, правило «триггер — предшествующая ситуация, а
не реакция», тест точки решения, правило AND/OR, тест тавтологии,
запрет превентивных запретов на ошибку, которой не было, обязательные
ссылки на доказательства, текст от внутренних источников не считается
словами пользователя, дедупликация/консолидация/архивация правил.
Это лучшая часть проекта.

**Секреты.** Слабо. `post_tool.py` маскирует только шаблон
`UPPER_KEY=значение` длиной ≥20 со смешанным регистром и цифрами.
Не ловит JSON (`"password": "..."`), строки подключения, нижний регистр,
пароли короче 20, вывод MCP (Odoo, Gmail, Unitalk — PostToolUse на `*`).
Промпты пользователя не маскируются вовсе. Всё это уходит в
`claude -p` (на подписке) для извлечения, а в managed-режиме — на
`https://www.reflexio.ai`. Тега `<private>` нет.

**Сеть и установка.** `npx claude-smart install` → `smart-install.sh`:
скачивает uv с `astral.sh` (`curl` → `sh`), при необходимости Node.js с
`nodejs.org`, `uv sync` (reflexio-ai, litellm, onnxruntime для локальных
эмбеддингов), `npm ci` для дашборда Next.js. Запускает два фоновых
демона: бэкенд `:8071` и дашборд `:3001` (README: доверяет всем
локальным пользователям ОС). Явной телеметрии (PostHog/Sentry) в коде
плагина не нашли; «telemetry» в коде — локальный журнал хуков.
Установка из GitHub-маркетплейса не работает: вендорного рантайма нет
в репозитории, нужен `npx`.

**Облако.** README прямо: «Not supported: … claude.ai/code web».
Даже если поставить: Setup-хук тянет uv/Node и пакеты при каждом новом
контейнере (таймаут 300 с), база `~/.reflexio` умирает с контейнером,
managed-режим — отправка всех сырых данных стороннему облаку.

**Цена.** Always-on: поиск и подмешивание индекса (до 8000 символов) на
каждый промпт и на каждый Edit/Write/Bash (дедуп на сессию снижает
повторы). Фоновое извлечение — несколько вызовов `claude -p` (по
умолчанию `sonnet`) на каждую опубликованную порцию: гейт, извлечение,
дедуп/консолидация, оценка успеха. Точное число вызовов не считали.

**Бенчмарк автора** (`EXPERIMENT.md`): 32 синтетических сценария,
заглушки ответов, recall 0–3: claude-smart 2.84 против claude-mem 1.91,
на поправках 3.00 против 0.88. Меряет захват правила, а не изменение
поведения в следующей сессии; проведён автором. Независимой проверки нет.

**A/B не делали.** По правилам запуск чужого кода требует разрешения;
к тому же инструмент в облаке не работает. Для переносимых идей A/B
должна делать сессия реализации на наших eval-кейсах `skill-feedback`.
