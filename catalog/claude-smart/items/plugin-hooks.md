# claude-smart: плагин (хуки, бэкенд, дашборд)

- **Тип:** плагин Claude Code / Codex / OpenCode
- **Источник:** `ReflexioAI/claude-smart@6cff4fe`, `plugin/`
- **Лицензия:** Apache-2.0
- **Вердикт:** отклонить

## Что делает

Автоматически пишет весь ход сессии и превращает его в правила, которые
подмешивает в следующие сессии.

## Устройство (по коду)

| Событие | Что делает | Файл |
|---|---|---|
| `Setup` | `smart-install.sh`: uv (`astral.sh`, `curl`→`sh`), Node (`nodejs.org`), `uv sync` (reflexio-ai, litellm, onnxruntime), `npm ci` дашборда | `plugin/scripts/smart-install.sh` |
| `SessionStart` | корень плагина, пометка сессии (сброс дедупа после compact), старт бэкенда `:8071` и дашборда `:3001` | `events/session_start.py`, `backend-service.sh`, `dashboard-service.sh` |
| `UserPromptSubmit` | промпт целиком в буфер; поиск и подмешивание индекса правил | `events/user_prompt.py`, `context_inject.py` |
| `PreToolUse` (Edit/Write/NotebookEdit/Bash) | поиск по первой строке вызова, подмешивание индекса | `events/pre_tool.py` |
| `PostToolUse` (`*`) | вход и вывод инструмента (до 4096 символов) в буфер, маскировка `KEY=value` | `events/post_tool.py` |
| `Stop` | публикация буфера в reflexio | `events/stop.py`, `publish.py` |
| `SessionEnd` | дописать остаток, остановить службы | `events/session_end.py` |

- Подмешивание: индекс по строке на правило `[cs:ID] когда применять →
  ссылка`, бюджет 8000 символов (Claude Code), до 6 правил на поиск
  (`CLAUDE_SMART_MAX_INJECTED_ITEMS`), дедуп на стороне сервера по
  `session_id` — одно правило не подмешивается дважды за сессию.
  Полный текст правила — по `cli.sh load` из локального реестра.
- Извлечение: в бэкенде через `claude -p` (`sonnet`) — LLM-провайдер
  LiteLLM вызывает CLI хоста; внутренние вызовы фильтруются от
  повторного захвата (`internal_call.py`).
- Режим `--read-only`: только подмешивать, не публиковать.

## Почему отклоняем

1. **Облако.** Не поддерживается (README). База в `~/.reflexio` умирает с
   контейнером; Setup на каждом новом контейнере качает uv/Node/пакеты.
2. **Секреты и клиентские данные.** Промпты не маскируются; вывод любых
   инструментов, включая MCP Odoo/Gmail/Unitalk, пишется до 4096
   символов; маскировка ловит только `UPPER_KEY=длинное_значение`.
3. **Always-on цена.** Поиск+подмешивание на каждый промпт и каждое
   Edit/Write/Bash; фоновые вызовы `claude -p` на подписке.
4. **Нет человека и гейта.** Правила создаются и переписываются сами;
   нет A/B, нет барьера при повторе.
5. **Дублирует** `cloud-memory`, `skill-feedback`, claude-mem.

## Что можно было бы взять (не берём сейчас)

- Дедуп подмешивания по сессии и сброс после compact — полезно, если у
  `cloud-memory` появится подмешивание не только на старте. Сейчас не
  нужно.
- Индекс «строка на правило + загрузка полного текста по запросу» —
  у нас уже так (`memory/INDEX.md`).
