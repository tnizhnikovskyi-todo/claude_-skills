# ivnvxd/mcp-server-odoo — итог для главной сессии

- **Что это:** Python MCP-сервер для Odoo 16–20 (MPL-2.0 — сверено по `LICENSE`, ★411,
  v0.9.0 от 2026-10-10, `@64b52df`, активен, ~1550 тестов). 16 инструментов + опц.
  `call_model_method`. Телеметрии нет, сеть только к Odoo.
- **Главное про безопасность:** настоящие проверки — **на стороне Odoo**, в
  отдельном модуле `mcp_server` (apps.odoo.com, **OPL-1**, much. Consulting, код не
  читали): allowlist модель × read/write/create/unlink, флаг методов, группа MCP User,
  ключ со scope «MCP only», OAuth 2.1, аудит каждого вызова, rate limit. Без модуля —
  режим YOLO (`read` или `true` = всё, включая `ir.cron`).
- **Чего нет:** подтверждения человеком, preview/diff, dry-run, локального аудита;
  одна база на процесс (хуже нашего `odoo-mcp` с `connection_id`).
- **Лучшее для T3 / `odoo-connector` (F1), своими словами:** (1) политика «модель ×
  операция» + флаг методов, fail-closed, «не смог проверить» ≠ «отказ»; (2) x2many-команды
  проверять как операции на связанной модели; (3) права на каждой модели пути домена/`order`/
  `groupby`, несбалансированный домен — ошибка; (4) вложения/сообщения — по документу-владельцу;
  (5) delete — 1 id, create/update ≤ 100 атомарно (закрывает пробел erpipe: unlink без предела);
  (6) блок-лист `ir.actions.*`/`ir.cron`/`run`/`method_direct_trigger`/`web_*`/ORM-примитивы для
  `odoo_execute`; (7) скрывать поля-секреты при массовом чтении.
- **Дополняет erpipe:** erpipe — процедура (гейт, токен, elicitation, JSONL-аудит);
  mcp-server-odoo — модель прав и связи. Вместе дают полную картину для T3.
- **Odoo 19:** JSON-2, `web_save_multi`, `formatted_read_group` сверены по `odoo@19.0` — верно.
  Попутно: XML-RPC в 19 устарел, удаление в 22 (`addons/rpc/controllers/__init__.py:6–8`) —
  `odoo-connector` стоит перевести на JSON-2.
- **Вердикт: адаптировать, 13/18.** Сервер не ставить; модуль у клиентов не ставить без
  отдельного решения (OPL, сторонний вендор).
- **Не проверено:** код модуля, A/B, текущее состояние T3 и код `odoo-connector`
  (доступ к приватному маркетплейсу отклонён).
