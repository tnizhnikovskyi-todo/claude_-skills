# declawed

- **Тип:** скилл + `scripts/scan.py` · **Источник:** https://github.com/kevinlin/skills/tree/main/declawed · v1.2.2
- **Вердикт:** идея на потом (для Humizer)

Убирает «следы ИИ» в тексте. Главная мысль: свой «слоп» модель не видит
при перечитывании, а переписывание порождает новый («не X, а Y» → «это
меньше про X, чем про Y»). Поэтому поиск **механический**: regex по
каталогу `references/slop-patterns.md` (178 строк, 7 семейств), затем
переписывание по смыслу, повторный скан и так до чистого результата,
в конце проверка регистра по жанру (`tones.md`). `scan.py` — stdlib,
только regex, без сети.

Для нас: в `meeting-protocol-builder` / `kickoff-survey-protocol` есть шаг
Humizer. Каталог англоязычный, для украинского/русского его надо
составлять заново. Переносимы архитектура «скан → переписать → повторный
скан» и правило «детекция только механическая». Проверить на 3–4
протоколах, есть ли у Humizer эффект повторного «слопа».
