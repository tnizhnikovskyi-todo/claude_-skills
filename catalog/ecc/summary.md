# ECC — итог для главной сессии

- **Что это:** `affaan-m/ECC@b38be6a` (v2.2.3, MIT; внутри CC BY-SA 4.0 у
  `osint-investigation`, Apache-2.0 у 8 скиллов логистики, MIT © Matt Pocock
  у `context-and-decisions`). 314 скиллов, 71 агент, 98 команд, 28 хуков,
  правила 20 языков. Про Odoo — ничего.
- **Звёзды настоящие** (4321 коммит, 517 авторов, 1345 PR, форки 15%), но
  это вирусность, а не польза: 90% — справочники веб-фреймворков.
- **Always-on дорого:** ≈33 тыс. токенов описаний в каждой сессии
  (скиллы 25.6 тыс. + агенты 4 + команды 3.5), правила ≈6 тыс. при
  установщике, `SessionStart` ≤2 тыс., 6–8 node-хуков на каждый
  Bash/Edit, gateguard — лишний ход на каждый новый файл. Самый дорогой из
  разобранных.
- **Безопасность:** сети из хуков нет, телеметрия локальная; но по
  умолчанию вход/выход всех инструментов (до 5000 символов) пишется в
  `~/.local/share/ecc-homunculus/` — для нас это данные клиентов.
- **Вердикт:** установку отклонить (7/18). Адаптировать 6 вставок
  (пересказом, MIT):
  1. `tr-usecases-acceptance`: строки AC «Не повинно (Must not)» и
     «Перевірка: метод» (intent-driven-development) — у нас их нет.
  2. Журнал дискавери: реестр `G-N` «термины клиента → объект Odoo»,
     «требует подтверждения» (context-and-decisions, атрибуция Matt Pocock).
  3. `evals/README.md`: кейс «конкурирующий промпт» (skill-comply).
  4. `skill-feedback`: `confidence` + доказательства; в общее правило
     только при повторе в 2+ проектах («инстинкты»).
  5. Правила `boost` + `templates/CLAUDE.md`: вопросы перед правкой
     SKILL.md/CLAUDE.md и перед разрушительной командой (gateguard).
  6. `pr-review`: сверка scope ТР/SPEC с фактическим диффом (change-impact).
- **Отложено:** хук `config-protection` для конфигов линтеров Odoo —
  только после 2-го нарушения «Пола качества» в `observations/`.
- **Отклонено:** `santa-method`/`council` = наш отклонённый
