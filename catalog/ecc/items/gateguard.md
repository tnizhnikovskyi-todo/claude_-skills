## Что делает

Отклоняет первую правку каждого файла и каждую «разрушительную» команду
Bash, пока модель не перечислит факты: кто импортирует файл, какой
публичный API затронут, формат данных, дословная цитата текущей просьбы
пользователя. После ответа повтор разрешается. Вопросы зависят от класса
файла (code / test / prose / config / **instruction** — `CLAUDE.md`,
`SKILL.md`). Для `rm -rf`, `git reset --hard`, `push --force`, `drop
table`: «что изменится или удалится; откат одной строкой; цитата просьбы».

## Какую слабость закрывает

Правка «вслепую» без поиска вызовов и дубля. Принцип верный: вопрос
«ты уверен?» не работает, а вопрос «перечисли всех, кто импортирует
файл» заставляет выполнить Grep.

## Проверка

A/B автора: 2 задачи, 9.0 против 6.75 по 10-балльной шкале — на двух задачах
и без описания рубрики; не доказательство. Сами не прогоняли (запрет на
запуск чужого кода).
