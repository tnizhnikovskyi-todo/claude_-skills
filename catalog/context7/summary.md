# context7: итог для главной сессии

- **Что это:** удалённый MCP-сервер Upstash (`https://mcp.context7.com/mcp`)
  с двумя инструментами: `resolve-library-id` и `query-docs`. Отдаёт свежие
  фрагменты документации библиотек с кодом и ссылками. В репозитории есть
  плагин для Claude Code (это просто `.mcp.json`), CLI `ctx7` со скиллом и
  SDK. Бэкенд закрыт, открыт только тонкий клиент.
- **Главная находка:** в индексе есть **Odoo 19** (`/websites/odoo/19.0`,
  обновлён 2026-10-22). На проверке Context7 вернул правильный новый API
  `models.Constraint` вместо `_sql_constraints`. Это прямо закрывает пробел
  «нет MCP для документации» и подходит для `tr-odoo-tech-design` и
  `odoo19-mvp-build`.
- **Безопасность (2/3):** локально ничего не исполняется, наружу уходят
  только `query` и `libraryName`, которые пишет модель, плюс ключ. Риски:
  модель может вставить в запрос наш код; документацию добавляет сообщество
  (зеркала, возможные инъекции). Смягчение — правило в `CLAUDE.md`.
- **Цена:** бесплатно 1000 вызовов в месяц на ключ; Pro $10 за место.
- **Оценка:** 14/18. **Вердикт: взять.** Подключать удалённый MCP с
  `Authorization: Bearer ${CONTEXT7_API_KEY}` (облако/CI) или плагин с
  OAuth (локально). `npx ctx7 setup` и скилл `find-docs` с
  `npx ctx7@latest` отклонить (supply-chain).
- **Взять дополнительно:** правило для `CLAUDE.md` (текст в `README.md`).
- **Открыто:** политика приватности, коннектор claude.ai для всей
  организации, A/B-тест на реальной задаче Odoo 19.
