# context7-mcp (`packages/mcp`)

- **Тип:** MCP-сервер (stdio или streamable HTTP); публичный экземпляр `https://mcp.context7.com/mcp`
- **Источник:** https://github.com/upstash/context7/tree/master/packages/mcp
- **Версия / коммит:** `@upstash/context7-mcp` 4.4.4, `18d6f5d`
- **Дата разбора:** 2026-11-02
- **Вердикт:** **взять** (удалённо, через HTTP; локально не запускать, незачем)

## Что делает

Тонкий прокси между MCP-клиентом и закрытым REST API Context7. Регистрирует
два инструмента и пересылает их аргументы в `https://context7.com/api`.

| Инструмент | Аргументы | Куда идёт |
|---|---|---|
| `resolve-library-id` | `query`, `libraryName` | `GET /api/v2/libs/search` |
| `query-docs` | `libraryId`, `query`, `language?` | `GET /api/v2/context` |
| `submit-docs-feedback` (только research preview) | `libraryId`, `score`, `comment`... | `POST /api/v2/feedback` |

Ответ `query-docs` — это markdown: заголовок фрагмента, `Source: <url>`,
описание и блок кода. Около 3–6 КБ на вызов.

## Как устроен (по коду)

- `src/lib/api.ts`: три `fetch` с таймаутом 60 с; уважает `HTTPS_PROXY` и
  `NODE_EXTRA_CA_CERTS`; при 429 советует взять ключ или сменить тариф.
- `src/lib/encryption.ts` `generateHeaders`: заголовки
  `X-Context7-Source`, версия сервера, `Authorization: Bearer <ключ>`,
  IDE и версия клиента, `mcp-session-id`, транспорт. На hosted-сервере IP
  клиента передаётся в бэкенд зашифрованным (AES-GCM).
- `src/index.ts`: инструкции сервера (см. README папки: «use even when you
  think you know the answer»), описания инструментов с просьбой «не включать
  в query секреты и проприетарный код», лимит «не более 3 вызовов на вопрос».
- Телеметрия: OpenTelemetry/Prometheus на стороне **их** сервера;
  `OTEL_SDK_DISABLED=true` отключает её при локальном запуске. Для удалённого
  подключения это не наша сторона.
- Аутентификация на hosted: API-ключ в заголовке **или** OAuth (Clerk,
  `clerk.context7.com`), плюс enterprise SSO (Okta/Entra).

## Что уходит наружу

Только аргументы вызова, которые сформировала модель, и метаданные клиента.
Сервер не читает файлы, не запускает команды, хуков нет. Главный риск — сама
модель, которая может вставить в `query` кусок нашего кода. Закрывается
правилом в `CLAUDE.md` (текст в README папки).
