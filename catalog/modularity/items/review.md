# review + document (ревью существующего кода)

- **Тип:** скилл `/modularity:review` + невызываемый `document` (формат отчёта, MD + HTML)
- **Источник:** `skills/review/SKILL.md@bcdca9a` (88 строк), `skills/document/SKILL.md@bcdca9a` (153), `skills/document/assets/template.html@bcdca9a`
- **Лицензия:** CC BY-NC-SA 4.0 — только идеи своими словами
- **Вердикт:** адаптировать (линзу — в `odoo-model-map`/`pr-review`; формат — нет)

## Как устроен (пересказ)

1. Спросить область; **сначала прочитать** требования и код (LSP, Grep,
   Glob — «не угадывать»); показать синтез — компоненты, паттерны
   интеграции, догадку о классификации **с уровнем уверенности**,
   допущения о командах — и подтвердить. Вопросы только по пробелам,
   которые изменят оценку; привязка к найденному в коде.
2. На каждую пару: какое знание общее, уровень силы, явное/неявное,
   расстояние (включая команды и синхронность), изменчивость (для
   типового — функциональная vs реализационная).
3. Правило баланса; флажить только **несбалансированное И изменчивое**.
4. Отчёт: резюме, таблица связей, на каждую проблему — утечка знания /
   влияние на сложность / сценарии каскадных изменений / рекомендация с
   компромиссом. Обязательные ссылки на coupling.dev и фиксированный
   футер с атрибуцией.

Сильные запреты: не судить по структуре без чтения точек интеграции;
не смотреть одну ось; не советовать «развязать всё»; лучше 5 важных
находок, чем 30 мелких.

## Для Odoo

- Шаг 2 «что за знание общее» требует карты связей. У нас её даёт
  `boost:odoo-model-map` (строковые `_inherit`, `env['…']`, `depends`,
  `inherit_id`). Значит, не новый скилл, а **раздел оценки поверх
  карты**: карта отвечает «кто с кем», линза — «здорова ли связь».
- Вопрос «флажить только изменчивое» полезен для `pr-review`: вторжение
  в стандартный модуль (переопределение `_private` без `super()`, XPath
  по позиции) — всегда изменчиво из-за апгрейдов Odoo.
- Формат находки из 4 частей похож на уже взятый 4-частный формат
  ponytail (`synthesis.md`, п.5) — второй формат не вводить, добавить
  только поле «уровень силы / расстояние».
