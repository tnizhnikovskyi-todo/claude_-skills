# ai-presales-skills: итог для главной сессии

- **Что это:** плагин `presales` автора *The PreSales Handbook* (43 скилла,
  54 команды, v2.5.0): пресейл от квалификации до передачи, вендор-нейтрально.
  Гипотеза подтвердилась. **Лицензия есть:** MIT на скиллы, но `references/`
  (пересказ книги, плейбук, шпаргалки) — «All rights reserved».
- **Безопасность:** хуков, MCP, телеметрии нет; `uv run` с закреплёнными
  пакетами, unpkg для рендера диаграмм; запись в CRM/папку только с
  подтверждением. Балл 2.
- **Минусы как плагина:** ≈ 8–9 тыс. токенов описаний всегда, широкие
  триггеры против наших `odoo19-sales-*`, всё под SaaS-лицензии и ARR, нет
  оценки трудозатрат внедрения. Один автор, ★5.
- **Лучшие находки:** (1) таблица соответствия требований Стандарт /
  Настройка / Доработка / Разрыв с вето обязательного; (2) неусредняемый
  шлюз «вкладываться / условно / пауза» со стоп-листом перед демо;
  (3) теги 🟢/🟡/🔴 + чистая копия для клиента; (4) правила сценария демо и
  проверка прогона; (5) бизнес-проблема против симптома/хотелки, риск
  «ничего не делать», сила чемпиона; (6) стресс-тест бизнес-кейса.
- **Вердикт:** адаптировать выборочно, 8/18. Плагин не ставить; методы
  своими словами в `odoo19-sales-prep` (1–3, 5), `odoo19-sales-demo` (4),
  `odoo19-sales-offer` (3, 6). Для `boost` — идея CI-бюджета описаний
  (`desc_budget.py`).
- **Оговорка:** наши тексты `odoo19-sales-*` недоступны, сравнение по
  описаниям; A/B не проводили. Варианты A/B — в `README.md`.
