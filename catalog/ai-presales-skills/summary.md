# ai-presales-skills: итог для главной сессии

- **Что это:** плагин `presales` автора *The PreSales Handbook* (43 скилла,
  54 команды, v2.5.0, `ab0752b`): пресейл от квалификации до передачи,
  вендор-нейтрально. Гипотеза подтвердилась. **Лицензия есть:** MIT на
  скиллы, но `references/` (пересказ книги, плейбук) — «All rights reserved».
- **Безопасность:** хуков, MCP, телеметрии нет; `uv run` с закреплёнными
  пакетами, unpkg для диаграмм; запись в CRM только с подтверждением. Балл 2.
- **Минусы как плагина:** ≈ 8–9 тыс. токенов описаний всегда, широкие
  триггеры против наших `odoo19-sales-*`, всё под SaaS/ARR, нет оценки
  трудозатрат. Один автор, ★5.
- **Сверка с текстами `odoo19-sales-*`** (`sale_todo_claude@2a7f7c1`): наш
  набор сильнее в таблице соответствия (`G-N`), клиентском регистре, сценарии
  демо по снимку стенда, межа торгу, возражениях из истории потерь.
- **Что реально новое (по приоритету):** (1) проблема ≠ симптом ≠ хотелка +
  событие-срок, риск «ничего не делать», сила чемпиона →
  `brief-transcript-analyzer`, `deal-revival-check`; (2) явный вердикт
  «вкладываться в демо / условно / пауза» поверх `ST-N` и `[КО]`;
  (3) стресс-тест экономики и позиции по переменным → `defence-brief`;
  (4) первое лицо персоны, пауза-вопрос, репетиция → `demo-runbook`.
  Мелочи: «обязательное» у `G-N`, теги на болях, CI-бюджет описаний для `boost`.
- **Вердикт:** адаптировать выборочно, 7/18. Плагин не ставить. Всё —
  пересказом или только идеей, источники в README «Что взять». A/B не
  проводили.
