## Что делает

Методичка пресейла (Solution Consultant) в виде плагина, независимого от
вендора: скиллы спрашивают продукт, возможности и конкурентов у
пользователя. Покрывает весь путь сделки: квалификация (MEDDPICC, TFQ),
дискавери (коммерческое и функционально-техническое), карта бизнес-проблем,
демо (Tell-Show-Tell, персона, Picture Pitch, прогон), ценность (ROI,
стресс-тест бизнес-кейса), сделка (PoC, возражения, цена, переговоры,
чемпион, план закрытия), RFX и анкеты безопасности, передача во внедрение
(OSD, архитектура), разбор выигрышей и проигрышей, плюс личный «второй мозг»,
LinkedIn, генераторы PPTX/DOCX/Excalidraw и инструменты руководителя.
Опирается на книгу и явно помечает, что из книги, а что практика кита.

## Какую слабость Claude закрывает

**Метод** (п. 2): дисциплину, которую модель сама держит нестабильно.
Сильнейшие приёмы:

- **«Отсутствие ≠ прохождение».** Каждое утверждение помечается 🟢/🟡/🔴;
  нехватка данных блокирует положительный вердикт, а не округляется вверх.
- **Неусредняемые шлюзы.** Высокий средний балл не выкупает проваленный
  обязательный критерий; есть стоп-лист для мгновенной паузы.
- **Чистая копия для клиента.** Из внутреннего документа с тегами
  собирается клиентский: неподтверждённое убирается или превращается в
  вопрос клиенту.
- **«Потребляй, не извлекай заново».** Одна схема итогов звонка, все
  следующие скиллы читают её, а не сырой транскрипт.

Знаний (п. 1) почти не даёт: справочник по книге закрыт лицензией, а
вендорных знаний нет по замыслу.

## Как устроен

- Корень репозитория = корень плагина. `skills/<имя>/SKILL.md` с
  `version`/`last_updated`, шагами, разделом «Connected Tools» (CRM,
  база знаний, почта; всё опционально), «Handoff» и чек-листом качества.
- Тонкие команды-обёртки в `commands/<фаза>/`; маршрутизатор
  `/presales:guide`.
- `DEAL_TEMPLATE.md`: папка сделки с нумерованными файлами
  (`01_account-brief.md` … `08_competitive-read.md`), запись в неё только
  с подтверждением.
- Скрипты: python-docx/python-pptx/openpyxl через `uv run --with <пин>`;
  рендер Excalidraw через Playwright + unpkg; `.tsx`-артефакты для claude.ai.
- Поддержка качества: CI проверяет JSON манифестов и frontmatter;
  `scripts/desc_budget.py` считает бюджет описаний (лимит 1024 на скилл,
  цель 16 000 символов на всё) и имеет `--self-test`.
- Сеть и права: подробно в `notes.md`. Телеметрии нет.
