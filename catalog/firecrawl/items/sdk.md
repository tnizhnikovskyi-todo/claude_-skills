# Firecrawl SDK

- **Тип:** клиентские библиотеки
- **Источник:** монорепо `apps/*-sdk` (Python `firecrawl-py`, JS `firecrawl`,
  Go, Rust, Java, .NET, PHP, Ruby, Elixir)
- **Версия / коммит:** JS 4.51.0, монорепо `6b02a6c`
- **Дата разбора:** 2026-11-02
- **Вердикт:** вне задачи «дать Claude веб»; полезно, если будем строить
  свои сервисы/скрипты сбора данных

## Что делает

Тонкие обёртки над REST v2: `scrape`, `search`, `crawl` (с ожиданием и
вебхуками), `map`, `batch_scrape`, `agent` (в Python — со схемой Pydantic),
`interact`, `parse`. Лицензия MIT (в отличие от AGPL ядра). JS SDK
используется внутри MCP-сервера.

## Когда пригодится

- Скрипт в репозитории, который регулярно собирает данные с сайтов
  (например, тарифы конкурентов) и складывает JSON — через SDK проще, чем
  через Claude.
- Свой узкий MCP/скилл поверх Firecrawl с одним-двумя инструментами
  вместо 27.

## Оценка

Для Claude напрямую не оценивается: это не инструмент агента, а
библиотека для кода. Поддержка — та же, что у монорепо (3).
