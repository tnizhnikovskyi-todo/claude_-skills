# Firecrawl Cloud API (v2)

- **Тип:** облачный сервис (REST API)
- **Источник:** https://api.firecrawl.dev, https://docs.firecrawl.dev, цены https://www.firecrawl.dev/pricing
- **Версия / коммит:** API v2, монорепо `6b02a6c` (v2.11.645)
- **Дата разбора:** 2026-11-02
- **Вердикт:** основа всех остальных компонентов; использовать через MCP

## Что делает

Эндпоинты v2: `/scrape` (форматы markdown, html, links, screenshot, json по
схеме, branding, `onlyMainContent`, `actions`, `redactPII`), `/search` (веб,
news, images + опционально полный текст), `/map`, `/crawl` (асинхронно,
`includePaths`/`excludePaths`, лимиты), `/batch/scrape`, `/scrape/{id}/interact`
(промпт или код в живом браузере, live view), `/parse` (PDF/DOCX),
`/agent` (автономный поиск и сбор данных, `effort` low/medium/high, схема),
`/extract` (предшественник agent), мониторинг, индексы developer / gov /
research, каталог «Alexandria» (готовые коннекторы к провайдерам данных).

## Стоимость и лимиты (на 2026-11-02, с сайта)

| План | $/мес | Кредитов/мес | Параллельно | scrape/map/search в мин; crawl/agent в мин |
|---|---|---|---|---|
| Free | 0 | 1 000 | 2 | 10; 2 |
| Hobby | 19 | 5 000 | 5 | 100; 20 |
| Standard | 99 | 100 000 | 25 | 500; 100 |
| Growth | 399 | 500 000 | 50 | 5 000; 1 000 |
| Scale | 749 | 1 000 000 | 100 | 10 000; 2 000 |

Цены кредитов: scrape 1/страница, JSON-формат +4/страница (итого 5),
crawl 1/страница, map 1/вызов, search 2 за 10 результатов (+ scrape за
каждую выкачанную страницу), agent — 5 бесплатных запусков в день, далее
по токенам. Страницы с 403/404 тоже стоят 1 кредит. Кредиты Free не
переносятся.

Ориентир: 1000 кредитов Free ≈ 1000 простых страниц или ≈ 200 извлечений
JSON по схеме. Для еженедельного ресёрча команды хватит Free/Hobby.

## Ключ и авторизация

- API-ключ `fc-…` в `Authorization: Bearer`. OAuth-токены `fco_…` для MCP.
- Keyless: scrape, search, parse, interact работают без ключа с дневным
  лимитом (по IP/сессии), остальное требует аккаунт.

## Какие данные уходят наружу

URL, поисковые запросы, промпты, JSON-схемы, действия браузера, загруженные
файлы (parse). Скачанный контент хранится у Firecrawl по их политике;
параметр `zeroDataRetention` есть в API, но доступен только на Enterprise
(«approved use cases»). DPA — с Standard. Компания в США.
