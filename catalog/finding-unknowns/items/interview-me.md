## Сравнение

| Что | Их | Наш `boost:interview-me` |
|---|---|---|
| Один вопрос за ход | да, «one means one» | да, плюс «одно предложение — один «?»» |
| Гипотеза задачи с % уверенности | нет | да |
| Догадка к каждому вопросу | рекомендация среди 2–3 вариантов | догадка обязательна, иногда «против шерсти» |
| Порядок вопросов | по **радиусу поражения**: архитектура/модель данных → поведение (края, ошибки, дефолты, права) → полировка (**не спрашивать, предложить и идти дальше**) | кто → зачем → успех → ограничения |
| Варианты ответа | 2–3 конкретных + рекомендация в **каждом** вопросе | только когда «как считаете нужным» |
| «Решайте сами» | валидный ответ, агент берёт решение на себя | НЕ согласие → два варианта на выбор |
| Промежуточный итог | **чекпоинт каждые несколько вопросов**: список уже решённого | нет; только финальный пересказ |
| Критерий остановки | **оставшееся дешевле выяснить при реализации — сказать это вслух** | могу предсказать ответы на 3 следующих вопроса; 5–6 без роста — шаг назад |
| Противоречие с прежним ответом | **флаг сразу**, не брать молча новый | нет явного правила |
| Не спрашивать то, что видно в коде | да | «читать проект можно и нужно» (мягче) |
| Пересказ с Out of scope, явное «да», стоп | нет | да |

## Что взять в наш (по убыванию пользы)

1. **Флаг противоречия** (шаг 2 нашего): «ответ противоречит уже
   сказанному → назови обе версии и спроси, какая в силе, не бери молча
   последнюю». Совпадает с правилом противоречий из `requirement-engineer`
   — делать одним пунктом.
2. **Чекпоинт**: после 3–4 ответов — 3–5 строк «уже решили», чтобы дрейф
   умирал рано. Для встреч дискавери это и есть промежуточное «зачитать
   и подтвердить».
3. **Радиус поражения** как правило порядка: внутри «кто/зачем/успех/
   ограничения» сначала то, что меняет модель данных / scope / оценку.
   В дискавери это уже есть (блок A.5 «ризик»), в boost — нет.
   «Полировку не спрашивать — предложить» — снижает число вопросов.
4. **Остановка «дешевле выяснить потом»**: дополнить наш тест «предскажу
   3 ответа» второй веткой — «не предскажу, но ошибка дешёвая и
   обратимая → не спрашивать, записать как допущение».

**Не брать:** «you decide = агент решает» — противоречит нашему правилу,
проверенному A/B (+1.00 на 3 кейсах). Варианты в каждом вопросе — не
брать как обязательные: догадка + один вопрос короче и уже проверены.

**Как взять:** перевод/адаптация 4 правил с атрибуцией MIT Neeeophytee в
`plugins/boost/skills/interview-me/references/attribution.md`.
