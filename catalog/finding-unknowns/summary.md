# finding-unknowns — итог для главной сессии

- **Что это:** Neeeophytee/finding-unknowns-skills @ `ca5696a` (1.5.0, MIT по
  файлу `LICENSE` — подтверждено; ★361, один автор, июль–сентябрь 2026).
  14 коротких (23–29 строк) скиллов по эссе Thariq Shihipar «Finding Your
  Unknowns» и о контекст-инжиниринге. Только markdown: хуков, MCP, сети,
  телеметрии нет. Безопасность 3.
- **Главная находка — рамка 2×2 и техника на клетку.** Вопрос лечит только
  «известное неизвестное». «Неизвестное известное» (вкус, узнают на глаз) —
  показывать 3–5 вариантов со ставкой и выводить критерий из реакции.
  «Неизвестное неизвестное» — разведка (`blindspot-pass`): мины, скрытый
  контекст, как выглядит хорошо, вопросы эксперта с догадкой + переписанный
  запрос. Весь наш цикл дискавери (`Q-N`, опросники, `interview-me`) работает
  только с первой клеткой.
- **Их `interview-me` слабее нашего** (нет гипотезы с %, Out of scope, явного
  «да»; одинаковое имя — ставить рядом нельзя). Сверх нашего 4 правила:
  флаг противоречия, чекпоинт «уже решили», порядок по радиусу поражения
  (полировку предлагать, не спрашивать), стоп «дешевле выяснить потом».
