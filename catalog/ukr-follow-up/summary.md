# Summary: ukr-follow-up

**Что это.** `s1vanov/follow-up` — один украиноязычный промпт-скилл (★2, один
автор, 08–09.2026): транскрипт встречи → короткий plain-text follow-up по рамке
ARCV+ (один владелец, глагол совершенного вида, решения/действия/вопросы
раздельно). Сети, хуков, телеметрии нет. **Лицензия есть: CC BY 4.0** (не «не
указана»). Гипотеза подтверждена.

**Лучшие находки** (у нас их нет):
1. Проверка перепутанных меток спикеров по содержанию реплик + строка-предупреждение.
2. Блок «сомнительные места» вне документа: цитата с таймкодом → как прочитано → вопрос да/нет.
3. Лестница даты встречи с пометкой «припущення» и запретом пересчитывать «до пятницы» от допущения.
4. Срок только произнесённый, без подстановок; ровно один владелец, иначе `[уточнити власника]`.
5. Plain text как контракт на всю сессию; гомоглифы в чек-листе; порог ~40 слов для humanizer.

**Минусы.** 12–15 тыс. токенов на срабатывание, широкие триггеры пересекаются с
нашими `*-followup-writer`, нет фильтра чувствительного, нет файла и журнала,
мелкие противоречия в примере.
