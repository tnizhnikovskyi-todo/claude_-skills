# Headroom Desktop

- **Тип:** десктоп-приложение (Tauri: Rust + React) = локальный перехватывающий прокси для Claude Code / Codex / OpenCode / Grok Build, плюс установщик хуков, MCP-серверов и плагинов
- **Источник:** https://github.com/gglucass/headroom-desktop
- **Версия / коммит:** `4390af7b` от 2026-10-31 (теги до `v0.9.9-rc.5`; закреплён `headroom-ai` 0.41.0, `rtk` 0.48.0)
- **Дата разбора:** 2026-11-02
- **Вердикт:** **отклонить** само приложение (для нас неприменимо и рискованно); отдельно **разобрать** входящие в него инструменты `rtk` и `context7` как самостоятельных кандидатов

## Что делает

Трей-приложение, которое прописывает `ANTHROPIC_BASE_URL=http://127.0.0.1:6767`
в `~/.claude/settings.json` и в профиль шелла, и пропускает весь трафик Claude
Code через двухступенчатый локальный прокси: Rust-перехватчик (:6767) →
Python-бэкенд `headroom-ai` (:6768), который сжимает вывод инструментов, логи
и JSON в запросе (обратимо: модель может запросить оригинал), а потом шлёт
запрос в `api.anthropic.com`. Обещает ~50 % экономии входных токенов.
Дополнительно ставит PreToolUse-хук, который переписывает Bash-команды через
`rtk` (сжатый вывод CLI), строку статуса со счётчиком экономии, функцию
`headroom learn` (пишет «выученные» правила в `CLAUDE.local.md` / `MEMORY.md`)
и одним кликом — аддоны: markitdown, serena, codebase-memory-mcp, context7,
ponytail, caveman, chisle.

**Платный продукт:** без аккаунта на extraheadroom.com и подписки (от $3–4/мес,
7 дней пробно) не работает. Открыт только десктоп-клиент (MIT), бэкенд
аккаунтов закрыт.

## Какую слабость Claude закрывает

Стоимость контекста и лимиты подписки: длинные выводы инструментов (логи, JSON,
`git log`, тесты) съедают окно и недельный лимит. Это категория 4
(«память и контекст / экономия»).

## Применимо ли к нашим облачным сессиям

**Нет.** Мы работаем в облачных сессиях Claude Code: контейнер управляется
Anthropic, трей-приложения и `~/.claude/settings.json` пользователя там нет,
API-соединение и исходящий трафик идут через управляемый агент-прокси.
Приложение рассчитано только на локальную машину (macOS / Windows / Linux с
keyring) и подписочный Claude Code. В облаке не запускали и не пытались
(запуск чужого кода не разрешён).

## Как устроен

Сводка, подробности в `notes.md` и `items/`.

| Компонент | Что делает | Где в коде |
|---|---|---|
| Rust-перехватчик :6767 | MITM всего трафика клиента, маршрутизация, статистика, захват bearer-токена | `src-tauri/src/proxy_intercept.rs` (10 тыс. строк) |
| Python-бэкенд `headroom-ai` | Само сжатие (SmartCrusher JSON, извлечение HTML, LLMLingua для текста, ~2 ГБ модель) | PyPI `headroom-ai`, закреплён по SHA-256 в `tool_manager.rs` |
| Правки клиентов | env в `~/.claude/settings.json`, блоки в `.zshrc`, `~/.codex/config.toml`, конфиг OpenCode; с бэкапом и откатом при выходе | `client_adapters.rs` (23 тыс. строк) |
| `rtk` PreToolUse-хук | Переписывает Bash-команды на `rtk …`, для «тихих» режимов сам выдаёт `allow` | `client_adapters.rs`, `RTK_HOOK_VERDICT_PY` |
| `headroom learn` | Учится на ошибках агента из трафика, пишет правила в `CLAUDE.local.md` и память проекта | `lib.rs`, `memory_scrubber.rs` |
| Аккаунт и биллинг | extraheadroom.com: вход по magic-link, токен сессии в Keychain, пейволл | `pricing.rs` |

### Данные и сеть

- **Весь трафик Claude Code** (промпты, код, выводы) проходит через локальный
  прокси и сторонний Python-пакет. Наружу, по коду, уходит только в
  `api.anthropic.com` (как и без прокси).
- **OAuth-токен Claude** перехватывается из проходящих запросов
  (`bearer.rs`, TTL 1 ч) и используется самим приложением для запросов
  `api.anthropic.com/api/oauth/usage` и `/api/oauth/profile` (тариф,
  остаток лимита). Читает также `~/.claude.json` (`oauthAccount`) и
  `~/.codex/auth.json`. Отправки токена на свой бэкенд в коде не нашёл.
- **Свой бэкенд** (`extraheadroom.com/api/v1`): вход, статус подписки,
  `desktop/milestones` (число сэкономленных токенов + снимок экономии),
  `desktop/weekly_limit` (статус и % недельного лимита), `desktop/config`.
- **Телеметрия:** Aptabase (белый список событий: запуск, биллинг, аддоны) и
  Sentry (ошибки; тела ответов провайдера намеренно не отправляются, только
  структурная сводка; при неизвестном тарифе уходят поля организации Anthropic
  — тип, rate-limit tier, seat tier, billing type). Отключается в настройках.
- **Загрузки:** Python standalone (~3 ГБ на диске), колёса с PyPI, бинарники
  rtk / codebase-memory с GitHub — всё с закреплёнными SHA-256.

### Права на машине

Пишет в `~/.claude/settings.json`, `~/.claude/hooks/`, профили шелла (PATH),
`~/.codex/config.toml`, конфиг OpenCode, `CLAUDE.local.md`/`MEMORY.md` в
проектах, Keychain, опционально LaunchAgent. Хук `rtk` выдаёт
`permissionDecision: allow` для переписанных read-only команд, то есть
частично обходит запросы разрешений Claude Code. Всё это честно описано в
README и откатывается при выходе/удалении.

| Критерий | Балл (0–3) | Комментарий |
|---|---|---|
| Прирост | 1 | Локально может заметно экономить лимит; для наших облачных сессий 0 |
| Частота | 1 | Работала бы на каждом запросе, но только на локальной машине |
| Надёжность | 2 | Зрелый CI, тесты, откаты, watchdog; но огромная сложность и много обходов багов клиентов |
| Стоимость контекста | 3 | Ровно на это и нацелен, сам контекст не тратит |
| Безопасность | 1 | Код открыт и аккуратен, всё раскрыто, но: MITM всего трафика, перехват OAuth-токена, авто-`allow` в хуке, правки профилей, 3 ГБ загрузок, телеметрия, закрытый платный бэкенд |
| Поддержка | 3 | Очень активен: ~2160 коммитов за 7 мес., 688 за октябрь 2026, релизы |
| **Итого** | **11/18** | Для нас: отклонить (неприменимо в облаке + риск для корпоративной машины) |

## Сравнение с тем, что есть

В `inventory/current.md` нет ничего для экономии контекста и нет MCP для
актуальной документации библиотек. Headroom это не закрывает для облака, но
показывает два кандидата, которые закрывают: `rtk` (сжатие вывода CLI через
хук) и `context7` (документация библиотек). Их стоит разобрать отдельными
сессиями.

## Риски и заметки

- Все промпты и код идут через сторонний Python-пакет, обновляемый вместе с
  приложением (самообновление через Tauri updater из GitHub Releases).
  Компрометация релиза = доступ ко всему трафику и OAuth-токену.
- Сжатие может выкинуть нужное: автор сам пишет, что LLMLingua добавляет
  задержку, а на коротком контенте ничего не даёт.
- `headroom learn` автоматически дописывает правила в `CLAUDE.local.md` и
  память; автор уже чистит «вредные» выученные правила (`memory_scrubber.rs`).
- Корпоративная политика: на рабочей машине такой прокси с перехватом токена
  требует согласования с безопасностью.
