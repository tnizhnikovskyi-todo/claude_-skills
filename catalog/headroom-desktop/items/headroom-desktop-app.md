# Headroom Desktop (приложение)

- **Тип:** десктоп-приложение / локальный прокси
- **Источник:** https://github.com/gglucass/headroom-desktop
- **Версия / коммит:** `4390af7b` (2026-10-31)
- **Дата разбора:** 2026-11-02
- **Вердикт:** отклонить

## Что делает

Трей-приложение на Tauri. Ставит управляемый Python-рантайм, поднимает прокси
на 127.0.0.1:6767, перенаправляет туда Claude Code (`ANTHROPIC_BASE_URL`),
Codex, OpenCode, Grok Build; показывает дашборд экономии; ставит аддоны.
Требует платный аккаунт extraheadroom.com.

## Какую слабость Claude закрывает

Перерасход контекста и лимитов на шумных выводах инструментов.

## Как устроен

- Rust: `lib.rs` (19,5 тыс. строк), `state.rs` (19 тыс.), `client_adapters.rs`
  (23 тыс.), `tool_manager.rs` (28 тыс.), `proxy_intercept.rs` (10 тыс.),
  `pricing.rs` (8,6 тыс.). Всего ~126 тыс. строк Rust; фронт на React.
- Сеть: `api.anthropic.com` (основной трафик + `/api/oauth/usage`,
  `/api/oauth/profile` с перехваченным токеном), `extraheadroom.com/api/v1`
  (аккаунт, вехи экономии, статус недельного лимита), Aptabase, Sentry,
  GitHub Releases (обновления), PyPI/GitHub (загрузка компонентов).
- Права: правки `~/.claude/settings.json`, хуки, профили шелла, Keychain,
  LaunchAgent (опционально). Бэкап перед правкой, откат при выходе.
