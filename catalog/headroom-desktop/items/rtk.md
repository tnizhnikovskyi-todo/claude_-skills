# rtk (token-optimized CLI proxy)

- **Тип:** CLI-бинарник (Rust) + PreToolUse-хук для Claude Code
- **Источник:** https://github.com/rtk-ai/rtk
- **Версия:** 0.48.0 (закреплена в Headroom, SHA-256 на платформу)
- **Дата разбора:** 2026-11-02 (только то, как его использует Headroom; репозиторий rtk не читали)
- **Вердикт:** кандидат — разобрать отдельной сессией

## Что делает

Обёртка над частыми командами (`git status`, `ls`, `grep`, тесты и т. п.),
выдающая компактный вывод. Headroom ставит хук `PreToolUse` на `Bash`,
который через `rtk rewrite` переписывает команду агента на `rtk <команда>`.

## Какую слабость Claude закрывает

Шумный вывод Bash-команд, который съедает контекст. Это единственная часть
Headroom, которая **в принципе применима к облачным сессиям**: хук и бинарник
можно поставить в репозиторий / setup-скрипт окружения, без прокси и без
аккаунта.

## Как устроен (в Headroom)

- Хук `~/.claude/hooks/headroom-rtk-rewrite.sh` + встроенный Python
  (`HOOK_RULES_PY`, `RTK_HOOK_VERDICT_PY` в `client_adapters.rs`).
- Хук учитывает правила `permissions` пользователя (`ask`/`deny`) и в режимах
  `default`/`acceptEdits`/`dontAsk`/`bypassPermissions` возвращает `allow`
  для переписанных read-only команд. Это обход запросов разрешений — при
  адаптации надо решить, нужно ли нам такое.
