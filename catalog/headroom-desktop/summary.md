# Summary: headroom-desktop

- **Что это:** платное (от $3–4/мес) десктоп-трей-приложение (Tauri, MIT-клиент, закрытый бэкенд), которое перенаправляет Claude Code / Codex / OpenCode через локальный прокси 127.0.0.1:6767 и сжимает tool-выводы библиотекой `headroom-ai`. Обещает ~50 % экономии токенов.
- **Для облачных сессий неприменимо:** нужен локальный трей, `~/.claude/settings.json` пользователя и контроль над API-эндпоинтом.
- **Безопасность 1/3:** MITM всего трафика, перехват OAuth-токена Claude (использует для `api.anthropic.com/api/oauth/usage|profile`), правки профилей шелла и `settings.json`, PreToolUse-хук с авто-`allow`, ~3 ГБ загрузок, телеметрия Aptabase/Sentry, самообновление. Всё честно раскрыто, есть бэкапы и откат.
- **Поддержка 3/3:** ~2160 коммитов за 7 месяцев, очень активен.
- **Оценка:** 11/18. **Вердикт: отклонить** само приложение.
- **Что взять:** список аддонов как источник кандидатов —
  1) `context7` (MCP актуальной документации библиотек — закрывает пробел из `inventory/current.md`);
  2) `rtk` + PreToolUse-хук (сжатие вывода Bash; единственная часть, применимая в облаке через setup-скрипт/хук, но без авто-`allow`);
  3) `serena`, `codebase-memory-mcp` (навигация и память по коду).
- **Рекомендация хабу:** завести отдельные сессии анализа для `upstash/context7` и `rtk-ai/rtk`.
