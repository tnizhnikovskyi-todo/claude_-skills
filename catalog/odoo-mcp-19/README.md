## Что делает

MCP-сервер, который даёт агенту 3 инструмента — `execute_method` (любой метод
любой модели), `batch_execute`, `read_resource` — плюс 38 ресурсов `odoo://`
(компактные схемы, workflow, справка по JSON-2 и ORM 19) и 12 промптов. Все
вызовы идут в `POST /json/2/<model>/<method>` с Bearer API-ключом. Перед
записью работает слой безопасности: классификация риска, 40 заблокированных
моделей, проверка связанных записей, одноразовый токен подтверждения,
режим `locked`. Есть многопользовательский HTTP-режим с реестром от
companion-приложения CLORAG.

## Какую слабость Claude закрывает

- **Действия:** доступ к Odoo 19+ — у нас он уже есть (`odoo-connector`, MCP
  Odoo), прироста нет.
- **Проверка / безопасность записи:** серверные барьеры, которых у нашего
  коннектора нет (F1), и которых не хватает даже ветке T3. Здесь основная
  ценность.
- **Знания:** ресурсы «version drift», JSON-2 контракт — полезно, но
  частично про saas-19.x и не проверено нами.

## Как устроен (права, сеть, что ставится)

- **Ставится:** Docker-образ (`python:3.12-slim`, non-root uid 1001) или venv/pip
  из GitHub; зависимости `fastmcp[tasks]>=4.1.5,<5`, `requests`,
  `python-dotenv`, `cryptography`, `anyio`. Мастер `--setup` пишет `.env` и
  конфиг Claude Desktop.
- **Сеть:** только `ODOO_URL` (`/json/2/*`, `/doc-bearer/*`). Телеметрии,
  `subprocess`, `eval` нет (поиск по `src/`). Ссылки на GitHub Odoo — только
  строки документации.
- **Права:** права пользователя Odoo, чей API-ключ указан. HTTP-режим требует
  `MCP_API_KEY` или реестр; по умолчанию bind `0.0.0.0` (кроме `locked`).
- **Мелочи:** `.env` читается из текущего каталога с `override=True`;
  `run-docker.sh` делает `source .env`.
- **Активность:** 158 коммитов с 2026-01-26, последний 2026-11-02; ~95%
  от одного автора; ★11; CI pytest py3.10–3.13 (433 тест-функции, офлайн;
  мы не запускали).

## JSON-2 против XML-RPC и стоит ли переходить

Подробная сверка с `файл:строка` — в [`notes.md`](notes.md) (19 пунктов).
Коротко:

- **Права и транзакции те же.** Один вызов = одна транзакция (commit/rollback,
  до 5 повторов при конфликте), цепочки в одной транзакции нет; ACL и record
  rules пользователя. XML-RPC тоже принимает API-ключ вместо пароля.
- **Что лучше в JSON-2:** именованные аргументы с проверкой подписи (422),
  HTTP-коды по типу ошибки (422/403/404/409/500) и JSON-тело ошибки, `None`
  в ответе без `cannot marshal None`, приватные методы → 403, только API-ключ
  (пароль не пройдёт), stateless, `@api.readonly` → реплика.
- **Срок:** `/xmlrpc` и `/jsonrpc` в 19.0 deprecated, удаление в Odoo 22.
- **Помеха:** в 18.0 JSON-2 нет, а дефолт `odoo-connector` — `o18-artel-prod`
  (Odoo 18). Поэтому **переход «вместо» сломает основной ERP.**

**Рекомендация:** в `odoo-connector` добавить JSON-2 как второй транспорт,
выбирать по версии сервера (для 19+ — JSON-2, для ≤ 18 — XML-RPC), барьеры
(T3) держать общими над обоими. Не срочно: до Odoo 22 XML-RPC работает,
приоритет — закрыть дыры T3 (ниже).

## Проверка

Живой прогон не делали: чужой сервер запускать без разрешения нельзя, и
нужна база Odoo 19 с ключом. Проверка — чтение кода и сверка каждого
утверждения об API с исходниками Odoo.

| Задача | Без него | С ним |
|---|---|---|
| Запись `res.partner.write({'user_ids': [[0,0,{…}]]})` | наш коннектор и T3 пропустят | заблокировано (по коду `safety.py:458-501`) |
| `sale.order.line.default_get` c контекстом `sale_project` | T3 считает чтением, без аудита | требует подтверждения |
| Вызов с лишним позиционным аргументом | XML-RPC — другой вызов или ошибка Odoo | ошибка до отправки (`arg_mapping.py:232-235`) |

## Риски и заметки

- Комментарий «`res.users.apikeys.generate` с 19.1+» неточен: метод есть в 19.0
  (`odoo/addons/base/models/res_users.py:1636-1637`), за флагом
  `base.enable_programmatic_api_keys`. Модель всё равно заблокирована.
- Утверждения о saas-19.1…19.4 (`ir.access`, обязательный scope `rpc`,
  удаление `toggle_active`/`get_param`) не проверены — у нас нет этих веток.
- «На `*.odoo.com` `X-Odoo-Database` даёт 404» — утверждение автора, в
  исходнике не проверить.
- Из приватного маркетплейса ничего не скопировано; T3 описан своими словами.
