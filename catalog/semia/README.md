## Что делает

Статический аудит скилла «до установки»: скрипт склеивает все текстовые
файлы скилла, LLM (внешний провайдер или текущая сессия агента) пишет
Datalog-факты о поведении с цитатами из источника, детерминированная
часть проверяет схему и «заземление» цитат, затем 11 правил выводят
находки (выполнение скачанного, утечка секретов, косвенная инъекция,
неогороженные необратимые действия, обфускация, «рубильники»,
расхождение заявлений с поведением). Отчёт в Markdown/SARIF/JSON.
Ничего из цели не исполняет. Основа — статья arXiv:2605.00314.

## Какую слабость Claude закрывает

Наш критерий «Безопасность» сейчас делается вручную и по-разному в
каждой сессии анализа. Semia предлагает **механику**: закрытый словарь
эффектов × происхождение данных, находка — их пересечение. Это делает
проверку повторяемой. Но главное для скиллов — **инструкции, меняющие
поведение агента**, хуки, MCP, права — Semia не покрывает.

## Как устроен

- **Плагин:** `plugin.json` без хуков и MCP; один `SKILL.md` (290 строк)
  и `bin/semia.pyz` (zipapp, запускается `python3` ≥ 3.11). Пишет в
  `.semia/runs/<slug>/` текущего каталога.
- **Сеть:** только LLM-провайдер (OpenAI по умолчанию, Anthropic,
  локальные `claude`/`codex`); в режиме плагина — никакой. Телеметрии нет.
- **Подпроцессы:** `claude --print --tools ""` (без инструментов),
  `codex exec --sandbox read-only`, опционально `souffle`.
- **Граница доверия:** цель — данные; nonce-ограда в промпте; совет
  делать синтез в субагенте с правом записи одного файла.
- **Слепые зоны:** `dist/`, `build/`, `vendor/`, `out/`, `node_modules/`,
  `package.json` не читаются вовсе; файлы без известного расширения и
  бинари не читаются; пропуски LLM-синтеза не обнаруживаются; все
  находки с `severity="warning"`.

## Риски и заметки

- **Условия, если всё же ставить плагин:** только по SHA, `--out` в
  scratchpad, режим плагина (без внешнего провайдера), синтез в
  субагенте без `Bash`; отчёт считать подсказкой, а не вердиктом.
- **Отклонённые подозрения:** `claude --print` с `dontAsk` — инструменты
  выключены (`--tools ""`), `cwd` — каталог прогона, не цель; `semia.pyz`
  — совпадает с исходниками; `PRIVACY.md` о телеметрии подтверждён грепом.
- **Не проверено:** сама работа инструмента и его точность на наших
  задачах (не запускали); `repair` (LLM переписывает чужой `SKILL.md`)
  читали только по описанию; парсеры `parsers/*.py` — бегло.
- При клонировании репозитория в корпусе лежат живые дропперы — не
  открывать ссылки, не копировать фрагменты в рабочие файлы.
