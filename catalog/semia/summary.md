# Semia — summary для главной сессии

**Что это.** Статический аудит скиллов до установки (Apache-2.0, ★615,
RiemaLabs, статья arXiv:2605.00314; `379bc25`, v0.1.3, тишина с 2026-06-05).
LLM пишет Datalog-факты «эффект × происхождение данных» с цитатами,
11 детерминированных правил выводят находки. Плагин для Claude Code и CLI;
телеметрии нет, сеть только к LLM-провайдеру; бандл `semia.pyz` сверен с
исходниками.

**Главное.** Сильная механика потока данных, но **нет класса «прямая инъекция
в инструкциях скилла»**, хуков, MCP, прав и социальной инженерии. Опись слепа к
`dist/`, `build/`, `vendor/`, `package.json` (npm `postinstall`). Пропуски
LLM-синтеза не ловятся, у всех находок `severity=warning`. Точность только из
статьи: recall 97.7 %, F1 90.6 % → точность ≈ 84.5 %.

**Лучшие находки** (идеи, пересказ, Apache-2.0):
1. «Эффект × данные»: находка — пересечение, а не наличие эффекта.
2. Снимает находку только одобрение человека после показа входов; чтение
   секрета — находка лишь при канале наружу; секрет + недоверенный ввод в
   одном вызове.
3. Новые признаки умысла: «рубильник» по внешнему условию, мёртвый
   закодированный код, **заявление против поведения** (README «read-only»
   против записи/сети).
