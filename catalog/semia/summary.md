# Semia — summary для главной сессии

**Что это.** Статический аудит скиллов до установки (Apache-2.0, ★615, RiemaLabs, arXiv:2605.00314; `379bc25`, тишина с 2026-06-05): LLM пишет Datalog-факты «эффект × происхождение данных», 11 правил выводят находки. Телеметрии нет, сеть только к LLM; `semia.pyz` сверен с исходниками.
**Дыры.** Нет класса «прямая инъекция в инструкциях», хуков, MCP, прав, социальной инженерии; опись не видит `dist/`, `build/`, `vendor/`, `package.json`; пропуски LLM не ловятся; все находки `warning`. Точность только из статьи: recall 97.7 %, F1 90.6 % → точность ≈ 84.5 %.
**Лучшие идеи** (пересказ): находка — пересечение «эффект × данные»; снимает её только одобрение человека после показа входов; чтение секрета — находка лишь при канале наружу; секрет + недоверенный ввод в одном вызове; «рубильник» по внешнему условию; мёртвый закодированный код; **заявление против поведения** («read-only» в README против записи/сети).
**Сверх разбора:** наш stdlib-префильтр `items/skill_prescan.py`: на их корпусе 20/21 вредоносов → BLOCK, 0 ложных BLOCK; на `plugins/boost` 0 BLOCK, сразу виден `hooks/hooks.json`. HIGH шумит на текстах о безопасности; правила подстроены на том же корпусе.
