# Предложение: дополнения к чек-листу «Безопасность скилла/плагина»

База — `catalog/repo-security-review/items/proposed-checklist.md` (ещё
не влит в `criteria.md`). Ниже только то, чего там нет. Текст наш; идеи
из Semia @379bc25 (Apache-2.0), источник каждого пункта указан.
Вставлять должна главная сессия.

---

**Шаг −1 (новый). Префильтр.** `python3 -I skill_prescan.py <клон>` в
scratchpad. BLOCK → безопасность 0, разбор можно закончить с записью
находки. HIGH → каждую строку прочитать и закрыть как «находка» или
«отклонённое подозрение». Поверхности исполнения из вывода — обязательно
прочитать целиком. Чистый вывод ничего не доказывает.

**К п. 0 (инвентаризация):**
- Файлы в `dist/`, `build/`, `vendor/`, `out/`, `node_modules/`,
  `package.json` (скрипты `pre/postinstall`) читаем отдельно: многие
  сканеры их пропускают (Semia — `prepare.py`, `_SKIP_DIRS_ALWAYS`,
  `_SKIP_FILES_ALWAYS`).
- Бинарь или zipapp в плагине: распаковать **без запуска** и сверить с
  исходниками на том же SHA; не сходится или нет исходников — HIGH.
- Инструкции «до использования скачай и запусти X» (zip с паролем,
  страница со «скопируй в терминал») — признак умысла, сразу 0.

**К п. 2 (граница доверия) — механика вместо интуиции** (Semia,
`skill_dl_static_analysis.dl`):
- Для каждого действия с эффектом выписать строку: эффект (чтение/запись
  файла, сеть наружу/внутрь, запуск процесса, eval, env, БД, вызов
  агента) × откуда входы (литерал / параметр / недоверенное / секрет /
  чувствительное локальное).
- Находка — пересечение: недоверенное → запуск/eval/сеть наружу;
  секрет/чувствительное → сеть наружу или вызов агента; **секрет и
  недоверенный ввод в одном вызове**; скачанное → запуск.
- Чтение секрета без канала наружу в том же скилле — не находка, а
  «отклонённое подозрение» с причиной.

**К п. 3 (права и действия):**
- Ворота различаются: снимает находку только явное одобрение
  пользователем **после показа входов**. Allowlist, лимит, «спроси,
  если не уверен» — не снимают.

**К п. 6 (умысел), новые признаки:**
- «Рубильник»: опасное действие выполняется при условии, которое
  приходит извне (ответ сервера, флаг в файле из сети).
- Закодированный или обфусцированный кусок, на который ничего не
  ссылается (ждёт подключения другим путём).

**Новый п. 7. Заявление против поведения** (Semia,
`label_behavior_claim_contradiction`): выписать, что README и
`description` обещают («только чтение», «без сети», «локально», «без
записи»), и сверить с найденными эффектами. Расхождение — находка,
даже если сам эффект безобиден.

**Граница покрытия (№26)** — в карточку: «Префильтр не видит поток
данных и семантику; ручной разбор п. 2–3 обязателен».

## Для проверки наших плагинов перед публикацией

1. `skill_prescan.py plugins/<плагин>` (без `evals/`): 0 BLOCK; каждое
   HIGH закрыто комментарием в PR.
2. Поверхности исполнения из вывода совпадают с заявленными в README
   плагина (у `boost` — только `hooks/hooks.json` `cloud-memory`).
3. Хосты из вывода — только документация/GitHub; новый хост объяснён.
4. П. 7 к самим себе: README плагина обещает «без сети, без
   установщиков» — сверить с эффектами скиллов.
