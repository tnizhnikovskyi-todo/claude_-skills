# Плагин `semia` для Claude Code (+ CLI `semia-audit`)

- **Источник:** `packages/semia-plugins/claude-code/@379bc25` (`plugin.json`,
  `skills/semia/SKILL.md`, `bin/semia.pyz`), CLI в `packages/semia-cli/@379bc25`
- **Лицензия:** Apache-2.0; имя «Semia» — товарный знак (`TRADEMARKS.md`):
  в названии наших производных его использовать нельзя
- **Вердикт:** **отклонить** как инструмент для постоянного использования (9/18)

## Что делает

Скилл `semia` (290 строк) ведёт агента по циклу: `semia scan --prepare-only`
склеивает все текстовые файлы цели в `prepared_skill.md` → агент пишет
Datalog-факты с цитатами → `semia synthesize --facts` проверяет схему и
«заземление» цитат → цикл правок (до порога 0.9 или 5 неудач) → `detect`
→ `report` (md / SARIF / JSON). В режиме CLI синтез делает внешний LLM
(по умолчанию OpenAI `gpt-5.5`); есть `semia repair` (LLM переписывает
`SKILL.md` цели) и рекомендатель «использовать / с осторожностью / нет».

## Безопасность самого инструмента

| Что | Как есть |
|---|---|
| Код | Прочитаны `prepare.py`, `schema.py`, правила `.dl`, промпт, `llm_providers.py`, `detector.py`, `evidence.py`, `report.py`. Исполнение цели нет |
| Бинарь | `bin/semia.pyz` (zipapp) распакован без запуска: 33 файла, побайтно = исходникам на `379bc25`; бандлы claude-code и codex идентичны |
| Сеть | Только выбранный LLM-провайдер (OpenAI/Anthropic по `urllib`) или локальные `claude`/`codex`. Телеметрии нет (`PRIVACY.md` и греп) |
| Подпроцессы | `claude --print --permission-mode dontAsk --tools ""` (инструменты выключены), `codex exec --sandbox read-only`, `souffle`, если есть. `cwd` — каталог прогона, не цель: хуки цели не подхватываются |
| Куда уходят данные | В режиме CLI весь склеенный текст цели (до 4 МБ) уходит провайдеру. В режиме плагина — в текущую сессию |
| Что пишет | `.semia/runs/<slug>/` в текущем каталоге (в нашем репо будет мусор, нужен `--out` в scratchpad) |
| Хуки, MCP | Нет |
| Граница доверия | Хорошая: цель — данные, nonce-ограда `<<<SEMIA_HOSTILE_INPUT id=…>>>`, рекомендация запускать синтез в субагенте только с `Read` и записью одного файла |

Балл безопасности **2**: всё прочитано, сеть понятна, но плагин просит
запускать непрочитанный пользователем бинарь (мы сверили только этот
SHA) и в режиме CLI отправляет весь чужой скилл внешнему провайдеру.

## Проблемы, найденные в коде

1. **Слепые зоны `prepare.py`.** Не попадают в анализ вообще (даже в
   опись): `build/`, `dist/`, `vendor/`, `out/`, `target/`,
   `node_modules/`, `coverage/` и `package.json` (значит, npm
   `postinstall` не виден). Файлы без известного расширения
   (`.ps1`, `.bat`, `.cjs`, `Dockerfile`, исполняемые без расширения,
   бинарники) только перечисляются как `excluded` и не читаются.
   Вредонос в `dist/payload.js`, на который ссылается `SKILL.md`,
   анализатор не увидит.
2. **Нет класса «прямая инъекция в инструкциях»** (см. `rules-taxonomy.md`).
3. **«Заземление» слабое.** Цитата засчитывается при Жаккаре ≥ 0.1–0.2
   по токенам (`evidence.py`, ослабление порога для длинных строк).
   Проверка ловит выдуманные факты, но **не пропуски**: если LLM (в том
   числе под влиянием инъекции в цели) не записала вызов, находки нет, и
   ничто это не заметит. Детерминированная оболочка защищает от ложных
   срабатываний, а не от промахов.
4. **Серьёзности нет.** Все находки создаются с `severity="warning"`
   (`artifacts.py`, `detector.py`); README обещает «ranked by severity».
5. **Мелочи:** `plugin.json` = 0.1.2 при CHANGELOG 0.1.3; в
   `tests/fixtures/` лежат 50 чужих скиллов без указания их лицензий,
   среди них живые дропперы (base64 → `curl http://<IP>` → `bash`) —
   при клонировании антивирус может сработать.

## Точность

Своих чисел в репо нет: корпус в `tests/fixtures` — smoke-тест «не
падает», без разметки. Статья (arXiv:2605.00314): 13 728 скиллов,
на 541 размеченном экспертами — recall 97.7 %, F1 90.6 %, значит
точность ≈ 84.5 % (вычислено). «Больше половины скиллов имеют хотя бы
один критический риск» — для нас это значит: почти каждый скилл с
`Bash` получит `ungated_irreversible_operation`. Мы инструмент не
запускали (запрет на запуск чужого кода), поэтому своего замера нет.

## Почему не берём

- Цена: агент читает весь склеенный плагин и пишет десятки–сотни
  фактов с цитатами, затем до 5+ итераций правок. Для плагина вроде
  нашего `boost` (354 файла, с `evals/`) это дороже, чем ручной разбор
  по чек-листу.
- Главный для нас класс (инструкции, которые меняют поведение агента)
  и поверхности Claude Code (хуки, MCP, права) не покрыты.
- Python ≥ 3.11 и запуск бинаря из кэша плагинов; поддержка: 59
  коммитов за май–июнь 2026, после 2026-06-05 тишина 5 месяцев.
