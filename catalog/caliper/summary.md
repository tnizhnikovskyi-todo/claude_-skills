# caliper — кратко для главной сессии

- **Что это:** CLI `caliper-eval` (MIT, `89ab3b0`, v0.21.0, очень активен, ★229) + скиллы `grill-skill`/`evaluate-skill`. Гоняет настоящего агента (Claude Code/Codex/Pi/Hermes) k раз в чистом HOME, скилл ставится в `.claude/skills/`, судья LLM или Python-`assert`, `--ablate <skill>|mcp:<server>`, `compare` по задачам с токенами и временем.
- **Сильнее нас:** (1) активация отдельным табло, пробы «молчания» и «задача соседа» с чужими скиллами; (2) четыре вопроса: срабатывает / работает / окупается / держится, и таблица «сигнал → чинить description / тело / задачу / окружение»; (3) контроль без скилла сохраняется и не перезапускается, пока задачи те же; (4) шум типизирован: таймаут/лимит/ошибка судьи вне знаменателя, 429 повторяется; (5) шапка окружения (версия CLI, судья, что загрузилось) и предупреждение при разных судьях; (6) ablation MCP одной командой; (7) `forbidden_files` против утечки ответа.
- **Слабее/так же:** доверительных интервалов нет (признано в `compare.py:356`), регрессия = любое падение; денег не считает (только токены); нет негативного/позитивного контроля грейдеров, который есть у нас.
- **Наша проверка:** интервал Уилсона на наших числах — при 3 кейсах × 3 прогона различим только сдвиг ≳0.4. `interview-me` +1.00 и `skill-feedback` +0.45 устойчивы; `odoo-model-map` +0.11 и `repo-audit` +0.23 — в пределах шума.
- **Безопасность 1/3:** `--dangerously-skip-permissions` в каждой попытке + по умолчанию грузит коннекторы пользователя (Gmail/Drive) — скилл действует на реальном аккаунте без запросов; судья исполняет свой Python на хосте; телеметрия PostHog opt-out (без содержимого).
