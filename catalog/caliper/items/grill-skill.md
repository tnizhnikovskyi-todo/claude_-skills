# grill-skill (+ evaluate-skill)

- **Тип:** скиллы (Agent Skills, `skills/grill-skill/`, `skills/evaluate-skill/`)
- **Источник:** https://github.com/edonadei/caliper @ `89ab3b0`
- **Лицензия:** MIT
- **Вердикт:** адаптировать (метод в правила `evals/README.md`; скилл не ставить)

## Что делает

`/grill-skill [путь к SKILL.md]` проводит интервью по одному вопросу и строит
спеку, потом ведёт цикл до готовности:

1. **Понять:** пересказ скилла, ждёт подтверждения.
2. **Режим:** нет спеки → новые задачи (счастливый путь, краевой случай,
   враждебный ввод, соседи + обязательная проба молчания); есть спека →
   поиск пробелов по четырём вопросам, сначала спросить, что не покрыто.
3. **Первый прогон k=1:** вычистить ошибки окружения до оценки.
4. **Нужен ли скилл задачам:** контроль без скилла и полный прогон, оба
   k=3. Если скилл не сработал в полном прогоне — чинить `description`. Если
   контроль так же хорош — чинить задачу, а не скилл. Контроль сохранить и
   не перезапускать, пока не поменялись задачи или соседи.
5. **Диагноз и цикл:** таблица «сигнал → где чинить»; после правки
   сравнивать дважды (с прошлым полным прогоном и с контролем). «При k=3 одна
   попытка = 33 п.п., спорную победу подтверждай на k≥5».

Правила написания задач: промпт не называет скилл; ожидание наблюдаемо;
`assert` там, где результат проверяем; `activates:` на задачах исполнения;
агент однократный, поэтому скилл, который сначала спрашивает, оценивается
по первому ходу («спросил» + «ничего не сделал»).

`evaluate-skill` — тонкая обёртка над командами CLI (`validate`, `run`,
`compare`, сводка) из чата.

## Чем ценно для нас

- **Четыре вопроса** (срабатывает / работает / окупается / держится) дают
  структуру нашему правилу «минимум 3 кейса»: у нас нет «держится»
  (сравнение с прошлой версией скилла) и нет проб соседей.
- **Таблица диагноза** — прямо в наш шаблон отчёта: каждая неудача кейса
  должна быть отнесена к `description`, телу, задаче или окружению.
- **Однократный агент** и скилл-«спрашивающий»: у нас то же для
  `interview-me` (грейдер «вопрос задан до правок»), совпадает.
- Похоже на наш `interview-me` по форме (по одному вопросу, подтверждение).

## Почему не ставим

Требует `Bash` и сам ставит `caliper` (`pipx install caliper-eval if
missing`), работает только поверх CLI Caliper. У нас то же делает
`skill-creator` + `claude plugin eval`; переносим метод текстом.
