# dooservice/odoo-skills: сводка для главной сессии

- **Что это:** скиллы Odoo для 16.0–20.0 (LGPL-3, ★2, 1 автор, 162 коммита за 3 недели,
  очень активно). Marketplace Claude Code: плагин на версию (`odoo-19` и др.).
  Только Markdown: без хуков, MCP, сети и телеметрии.
- **Гипотеза о происхождении подтверждена частично.** 5 скиллов (`guidelines`,
  `web-guidelines`, `security`, `review`, `git`) взяты из `odoo/odoo@20.0:skills/`
  от Odoo S.A. (сверено клоном: каталог есть в 20.0, в 19.0 нет) и перегенерированы под
  каждую версию. `odoo-reference` (генерируется из исходников),
  `odoo-functional` (70 рецептов) и `odoo-upgrade` написал dooservice. Автор
  честно пишет «not affiliated with Odoo S.A.».
- **Точность по 19.0:** ~20 фактов сверены с `odoo/odoo@19.0` (файл:строка в
  notes.md), расхождений 0.
- **Наш мини-A/B (4 задачи из их evals, 1 прогон):** без скиллов модель знает
  имена 19.0 (4/4), но в 3 из 4 пишет подстраховки под старые версии
  (`if 'account.fiscal.position.tax' in env`). Со скиллами код только под 19.0,
  с проверкой и откатом (4/4). Цена +26% токенов. По их замерам у Haiku на 19.0
  +18.5 п., у Sonnet +5.6 п.
- **Оценка 14/18, вердикт: адаптировать.** Взять: (1) свою таблицу фактов
  19.0 с источниками → `source-check/references/`; (2) правило «одна версия,
  без подстраховок» → `code-dev`/`lean-change`; (3) 8–10 пунктов `odoo-security`
  (Markup-XSS, field groups, публичные методы = RPC, `file_open`, getattr,
  тайминг…) → `security-review`; (4) шаги review (файл → раздел правил, «код,
  которого diff не показывает», merits pass) → `pr-review`; (5) метод `connect.md`
  (dry-run с rollback, «да» до записи, архив вместо удаления) → implementation/
  odoo-connector; (6) regex-evals «нет имён чужой версии».
- **Опционально:** плагин `odoo-19` разработчикам как справочник (reference +
  рецепты) с пином коммита, но после прогона вместе с `odoo19-mvp-build` на конфликт
  триггеров. Текст в `boost` (MIT) не копировать: LGPL.
- **Не проверено:** оригиналы `code-dev`/`testing`/`pr-review` (в контейнере нет
  synced-плагинов); A/B на Sonnet/Haiku сами не гоняли.
