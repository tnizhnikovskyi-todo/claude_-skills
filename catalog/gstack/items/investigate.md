## Что делает

Отладка с «железным законом»: никаких правок без найденного корня.
Работает свободно, но с тремя ограждениями: после 3 неудачных гипотез
стоп и вопрос пользователю (новая гипотеза / эскалация / логирование);
правка шире 5 файлов → вопрос о радиусе; веб-поиск только по классу
ошибки и версии, без сырого текста ошибки, путей, SQL и данных клиента.
Для флейков, зависимости от порядка тестов, гонок и регрессий метрик
есть отдельные рецепты, «перезапуск, больший таймаут или skip — не
гипотеза». Итог — `DEBUG REPORT` (Симптом, Корень, Правка с `file:line`,
Доказательство, Регрессионный тест, Статус DONE / DONE_WITH_CONCERNS /
BLOCKED) и тест/прогон после последней правки.

Blast radius: «назови один факт, из-за которого правка безопасна», ищи
там, где grep не видит (данные, колонки БД, форматы, другой язык, флаги),
и подними каждый факт по лестнице доказательств: сказал → указал
`file:line` → прошёл отказ по шагам → запустил скрипт/тест → воспроизвёл
в приложении. Подтверждённые и снятые риски — разными списками.

## Какую слабость Claude закрывает

Склонность чинить симптом с первой гипотезы и объявлять «должно
помочь» без прогона; на флейках — поднимать таймаут. По `synthesis.md`
модель сама хорошо находит ошибки, поэтому ценность тут не в поиске, а в
**поведении** (стоп после 3 гипотез, запрет skip/таймаута как «фикса»)
и **формате** (DEBUG REPORT, лестница доказательств). Для Odoo blast
radius особенно уместен: grep не видит `_inherit` по строке, XML-вью с
`inherit_id`, `related`/`depends`, `ir.rule` (ср. наш `odoo-model-map`).

## Как устроен

21 КБ текста + общий преамбул 22 КБ + секции по требованию. Тянет
`gstack-learnings-search`, хук `freeze` в frontmatter (запирает правки в
каталоге модуля на время отладки). Без `bin/` gstack работает урезанно.

## Проверка (план, не делалась)

3–4 кейса в `plugins/boost/evals/debug-root-cause/`: флейкующий тест
Odoo (соблазн `timeout`), баг в `_compute` унаследованной модели (соблазн
чинить симптом во вью), исправление общего хелпера (blast radius:
второй модуль с `_inherit`). Грейдеры: нет skip/таймаута как фикса,
есть DEBUG REPORT, есть прогон после правки, перечислены снятые риски.
Негатив: простая опечатка — скилл не должен раздувать ответ.
