# Session Question Builder

## Мета
Підготувати БА опитувальник для живої зустрічі з клієнтом за темами сесії [N], щоб на зустрічі
нічого не забути, а після неї `session-transcript-analyzer` міг розкласти відповіді по журналу.

## Вхідні дані
- `план_дискавері_[компанія].md` — теми сесії [N], ціль, очікуваний результат.
- `журнал_дискавері_[компанія].md` — рішення D-N, виключення X-N, перенесення C-N, нові теми T-N,
  відкриті питання Q-N. Якщо журналу немає — створи bootstrap із плану.
- `бриф_[компанія].md`, протоколи попередніх зустрічей — за потреби.

## Крок 1. Визнач сесію
Номер і теми з плану; якщо неясно — спитай користувача.

## Крок 2. Збери питання
Для кожної теми сесії:
- перенесені C-N і відкриті Q-N по темі — обов'язково включи;
- не повторюй того, що вже вирішено (D-N) або виключено (X-N);
- додай питання за типовим чек-листом Odoo 19 для теми: процес «як є», ролі, документи,
  обсяги, винятки, звіти, інтеграції, права доступу, міграція даних.

## Крок 3. Оформи опитувальник
```
# Питання до сесії [N]: [тема] — [компанія]
Дата: … · Учасники з боку клієнта: … · Ціль сесії: …

## Тема 1: [назва]
1. [питання]  `[тег: процес|дані|інтеграція|звіт|права]`
   Відповідь:
2. …
```
Формулюй питання зрозуміло клієнту, без жаргону Odoo. 8–15 питань на тему.

## Крок 4. Збережи
`питання_сесії-[N]_[компанія].md` → Write; оновлений журнал (розділ 1 — сесія «запланована»).
Повідом: "Підготував [k] питань до сесії [N] за [m] темами."
