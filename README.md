# Claude Skills & Plugins Lab

Здесь мы ищем, разбираем и проверяем скиллы, плагины и MCP-серверы, которые
делают Claude сильнее в реальной работе. Нас интересуют не красивые описания,
а измеримая польза.

## Что значит «умнее»

Скилл или плагин засчитывается, если он заметно улучшает хотя бы одно из:

1. **Знания.** Даёт доступ к актуальным или закрытым данным: документация,
   базы знаний, веб-поиск, корпоративные системы.
2. **Метод.** Задаёт процесс, который Claude сам выполняет непоследовательно:
   ревью, исследование, планирование, проверка фактов.
3. **Проверку.** Позволяет проверить собственный результат: тесты, браузер,
   линтеры, валидаторы, второй независимый взгляд.
4. **Память и контекст.** Сохраняет знания между сессиями, экономит контекст.
5. **Действия.** Даёт новые инструменты, которых без него нет.

## Процесс

1. **Найти.** Кандидат из [`sources.md`](sources.md) или по задаче.
2. **Прочитать.** Изучить сам `SKILL.md` / код плагина, а не только README.
3. **Проверить безопасность.** Что скилл запускает, куда ходит в сеть, какие
   права просит.
4. **Испытать.** Прогнать на реальной задаче, сравнить с результатом без него.
5. **Записать.** Карточка в `catalog/` с оценкой по [`criteria.md`](criteria.md).
6. **Решить.** Взять / адаптировать / отклонить.
