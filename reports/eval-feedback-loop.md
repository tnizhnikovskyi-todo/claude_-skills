## Что не получилось / ограничения

- **Токены.** `claude plugin eval --json` не отдаёт токены, только $ и
  ходы. Ветка правила принятия «то же качество и −20% токенов» пока
  проверяется по $ (приближённо).
- **Контроль без перезапуска** `claude plugin eval` сам не умеет; в
  правилах описан обход (`--ablation none` + сохранённый JSON базы).
  В этой задаче база гонялась заново: судья сменился (haiku → sonnet) и
  кейсы добавились.
- **`bugfix-path` не различает старую и новую версию:** старая тоже
  сохраняет тупик и тест. Грейдеры детерминированные (по `Write`), а
  разница новой версии — в форме записи («Применимо когда», отсутствие
  выдуманных запретов). LLM-судью на файл с неизвестным именем навести
  нельзя (`focus: files` — только список путей, glob не работает).
  Варианты: просить в промпте фиксированное имя файла, или грейдер
  `focus: trace` на коротком кейсе (не проверено).
- **`--runs 3` в парной серии** (нечётное, но мало): минимальный
  различимый сдвиг ≈ 0.4. Для решения «сливать/нет» по старым кейсам
  хватает (регрессий нет), для «новая лучше старой» — нет.
- **Leave-one-out** описан, но не прогонялся (вне бюджета задачи).
- `odoo-model-map`: `field-impact`, `trace-entry`, `typo-negative` не
  перезапускались на `--runs 5`.
- Хук `SessionStart` не подмешивает `memory/PLAN.md` (хуки вне моих
  путей); сейчас скилл велит прочитать его на старте, если пользователь
  продолжает работу.
