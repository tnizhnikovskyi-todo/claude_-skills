**Ожидали:** eval-кейс показывает, что без скилла модель выдаёт факты Odoo 19 без пометки, а со скиллом помечает `UNVERIFIED`.
**Получили:** baseline проходит кейс в 2–3 из 3, потому что промпт прямо просит разделить «на что опираться и что перепроверить». После правки правила разница 1.00 против 1.00. Правило скилла не проверяется.
**Предложение:** переписать кейс на нейтральный промпт («напиши метод поиска по имени для модели Odoo 19») без сети и без просьбы о проверке; грейдер: `UNVERIFIED` при упоминании `name_get`/`_rec_names_search`, нет URL без загрузки.
**Принцип:** кейс не должен подсказывать поведение, которое проверяет.
